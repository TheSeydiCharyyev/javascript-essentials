# Карта покрытия

Список всего, что курсы должны покрыть (фаза 2 из [ТЗ](../ТЗ_курсы_JavaScript.md)).
Каждая строка — одна страница MDN или один раздел спецификации. В фазе 3 каждой строке назначаются курс, день, урок и глубина.

## Файлы

| Файл | Строк | Что внутри |
|---|---|---|
| `mdn-javascript.csv` | 1341 | все страницы раздела JavaScript на MDN |
| `ecma262.csv` | 2260 | все разделы спецификации ECMAScript (ECMA-262), редакция 2026 |
| `ecma402.csv` | 381 | все разделы спецификации Intl (ECMA-402), редакция 2026 |
| `mdn-webapi.csv` | 8108 | все страницы раздела Web API на MDN; в курс 4 входят 6416 стабильных (см. ниже) |
| `sources.json` | — | точные источники: коммит `mdn/content`, редакции спецификаций |

Язык (курсы 1–3) — первые три файла, 3982 строки, все обязательны.
В спецификациях отдельно назначаются главы и подглавы (уровни 1–3: 928 разделов ECMA-262 и 360 ECMA-402);
раздел уровня 4 и глубже засчитывается, если назначен его родитель (решение 19.09.2026).
Курс 4 — только стабильные страницы Web API: без пометок `experimental`, `deprecated`, `non-standard` в колонке `status`
(решение 19.09.2026). Проверка считает только их; если после `--update` страница потеряет пометку, она войдёт в курс сама.

## Колонки

Страницы MDN: `path` (адрес страницы после `https://developer.mozilla.org/en-US/docs/`), `title`, `page_type`,
`status` (`experimental`, `deprecated`, `non-standard` — пометки MDN), `browser_compat` (ключ таблицы совместимости);
у Web API ещё `group` — группа MDN («Fetch API», «Canvas API»…) из `files/jsondata/GroupData.json`.

Разделы спецификаций: `id` (якорь: адрес раздела = адрес спецификации + `#` + `id`), `number` (7.1.4, B.3.2),
`title`, `level` (глубина раздела: 1 — глава), `type` (например `abstract operation`, `built-in function`),
`flags` (`legacy`, `normative-optional`, `example`; у приложений — `informative` или `normative`).

Заполняются вручную (фаза 3):

| Колонка | Значения |
|---|---|
| `course` | 1–3 для языка; 1–4 для Web API |
| `day` | 1–36 |
| `lesson` | 1–3 |
| `depth` | `подробно` или `кратко` |
| `note` | любой текст |

Пустая строка — ещё не назначено. Строка, где заполнена только часть колонок, считается ошибкой.

## Команды

Из папки курса:

```
node tools\coverage-check.mjs                          сколько покрыто, есть ли ошибки
node tools\coverage-check.mjs --list mdn-javascript    что ещё не назначено (--limit 200 — сколько показать)
node tools\coverage-check.mjs --strict                 код ошибки 1, пока язык и стабильные Web API покрыты не на 100%

node tools\coverage-export.mjs                         пересобрать списки по тем же источникам
node tools\coverage-export.mjs --update                перейти на свежий MDN: новые страницы появятся пустыми строками
node tools\coverage-export.mjs --edition 2027          перейти на новую редакцию спецификаций
```

Выгрузка сохраняет уже заполненные колонки. Страницы, которые исчезли из MDN, она печатает вместе с их назначением.
Нужны Node 22+ и git. Первая выгрузка скачивает около 28 МБ страниц MDN и 8,6 МБ спецификаций в `tools/.cache/`
(в репозиторий не попадает); повторные работают без сети.
