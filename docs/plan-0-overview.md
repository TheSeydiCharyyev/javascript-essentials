# План четырёх курсов: модули

Фаза 3, шаг 1 ([ТЗ](ТЗ_курсы_JavaScript.md)). Здесь каждый курс разбит на модули, и каждая строка карты покрытия
отнесена к одному модулю. Дни внутри модулей расписываются на следующем шаге, по курсу за раз.

- Курс — 36 дней: 30 учебных дней и 6 дней проектов.
- «Страниц MDN» и «разделов спецификаций» — строки карты покрытия, которые модуль должен закрыть.
  Разделы спецификаций считаются только уровней 1–3 (более глубокие закрываются вместе с родителем).
- «В день» — сколько строк приходится на один учебный день. Большая часть строк идёт с пометкой «кратко»:
  строка в таблице или абзаце лекции, пример и ссылка на MDN. Подробно разбирается то, чем пользуются каждый день.
- Все строки разложены: `node tools/plan-modules.mjs` сообщает «rows without a module: 0».
  131 страница MDN с текстами ошибок (`TypeError: "x" is not a function` и т.п.) раздаётся по дням на следующем шаге —
  туда, где такая ошибка впервые встречается.

## Курс 1. Essentials

Основы языка для тех, кто программирует впервые, плюс работа со страницей: DOM, события, таймеры, fetch, хранилище.

|---|---|
| E1 Введение и инструменты | что такое JavaScript, где работает, консоль браузера (`console` — 21 страница), `debugger` |
| E2 Синтаксис, типы и операторы | переменные `let`/`const`/`var`, типы, `typeof`, арифметика, сравнение, логические операторы, `??`, тернарный оператор, `Boolean`, `undefined`, `NaN` |
| E3 Условия и циклы | `if`, `switch`, `for`, `while`, `do...while`, `break`/`continue`, метки, `for...of`, `for...in`, `try...catch`, `throw` |
| E4 Функции | объявления и выражения, стрелочные функции, параметры по умолчанию и rest, `return` |
| E5 Строки, числа и Math | методы строк (кроме регулярных выражений), шаблонные строки, `Number`, `Math`, `parseInt`, `parseFloat` |
| E6 Массивы, объекты и JSON | методы массивов, литералы объектов, `Object.keys`/`values`/`entries`/`assign`, деструктуризация, spread, `?.`, `delete`, `in`, `JSON.parse`/`stringify` |
| E7 DOM и события | поиск и создание элементов, `classList`, атрибуты, `textContent`, вставка и удаление, события мыши и клавиатуры, формы, `alert`/`prompt`/`confirm` |

## Курс 2. Intermediate

Как язык устроен. Здесь студенты впервые читают спецификацию — рядом с темой, которую уже знают по MDN.

| Модуль | Что входит |
|---|---|
| I1 Области видимости, замыкания и this | замыкания, `this`, `call`/`apply`/`bind`, `arguments`, `globalThis`, строгий режим; в спецификации — окружения (Environment Records) и функции |
| I2 Объекты глубже | дескрипторы свойств, `defineProperty`, `freeze`/`seal`, геттеры и сеттеры, перечисляемость, `Object.is` и сравнения, `&&=`/`\|\|=`/`??=` |
| I3 Прототипы и классы | цепочка прототипов, `Object.create`, классы целиком: поля, приватные элементы, `static`, `extends`, `super`, `new.target`, `instanceof` |
| I4 Итераторы и генераторы | протоколы итерации, `Symbol.iterator`, `Iterator` и его методы, генераторы, `yield` |
| I5 Коллекции | `Map`, `Set` (включая операции над множествами), `WeakMap`, `WeakSet`; массивы и коллекции по спецификации |
| I6 Строки и регулярные выражения | `RegExp`, синтаксис регулярных выражений, `match`/`replace`/`split` с регулярками |
| I7 Числа и даты | `Date`, `Temporal` (242 страницы), `BigInt`, основы `Intl` (`NumberFormat`, `DateTimeFormat`), локали в строках и числах |
| I8 Ошибки и асинхронность | `Error` и его виды, все статические методы `Promise`, асинхронные генераторы и итераторы, `for await...of` |
| I9 Модули и JSON | `import`/`export`, динамический импорт, `import.meta`, JSON по спецификации |

`Temporal` — современная замена `Date`, поэтому он здесь, а не в Advanced. Отсюда самая большая нагрузка курса
в I7 — 80 строк в день, в основном краткие страницы методов `Temporal`.

## Курс 3. Advanced

Язык по спецификации: что происходит внутри движка, двоичные данные, память, редкие и устаревшие возможности.

| Модуль | Что входит |
|---|---|
| A1 Как читать спецификацию | устройство ECMA-262, обозначения, грамматика, лексическая грамматика, висячие запятые |
| A2 Типы и абстрактные операции | типы языка и типы спецификации, преобразования (`ToNumber`, `ToPrimitive`…), сравнения, битовые операторы, `void` |
| A3 Как выполняется код | контексты выполнения, реалмы, очереди заданий, агенты, `eval`, модули изнутри, модель выполнения и управление памятью (MDN) |
| A4 Объекты изнутри | внутренние методы (`[[Get]]`, `[[Set]]`…), экзотические объекты, `Proxy`, `Reflect`, встроенные символы, глобальный объект |
| A5 Двоичные данные и модель памяти | `ArrayBuffer`, `SharedArrayBuffer`, типизированные массивы, `DataView`, `Atomics`, модель памяти |
| A6 Управление ресурсами и памятью | `WeakRef`, `FinalizationRegistry`, `using`, `DisposableStack` |
| A7 Intl целиком | все объекты `Intl` и вся спецификация ECMA-402 (кроме NumberFormat и DateTimeFormat из I7), числа и даты по ECMA-262 |
| A8 Наследие и совместимость | устаревшие возможности, приложения B, D, E, F спецификации, `with`, старые методы строк и `RegExp` |
