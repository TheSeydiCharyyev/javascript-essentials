Day 1. What JavaScript is

A short summary of the lecture: reread it before the next lesson.

The main points

JavaScript is a programming language. A program in it is a list of instructions that run in order. In the browser it is responsible for the behavior of the page.
Three layers of a page: HTML is the content, CSS is the appearance, JavaScript is the behavior.
An engine is a program inside the browser that runs code. V8 in Chrome and Edge, SpiderMonkey in Firefox, JavaScriptCore in Safari. The V8 engine also works without a browser — that is Node.js.
ECMAScript is the official standard of the language. A new edition comes out every year: ES2015, ES2016 and so on. Old code keeps working.
Core and environment. The language core — numbers, strings, functions, Math, JSON — is the same everywhere. The environment adds its own things: the browser adds the page (document), windows and events; Node.js adds files and the server (process). 
typeof document;   // "object" in the browser, "undefined" in Node.js
typeof process;    // "undefined" in the browser, "object" in Node.js

Where JavaScript works

  • pages and web apps — in the browser;
  • servers — Node.js;
  • phone apps — React Native;
  • desktop programs — Electron (VS Code, Discord).

The console

The console shows the value of the last expression by itself. console.log prints but returns nothing — that is why the console writes undefined after the output. An unfinished line (function greet() {) does not run on Enter but waits for the rest; to start a new line yourself, press Shift + Enter.

3 + 5;               // 8
console.log(3 + 5);  // prints 8, and below it — undefined
