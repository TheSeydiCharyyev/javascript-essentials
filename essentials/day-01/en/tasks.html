Day 1. Tasks

Lessons 2 and 3, 90 minutes. Warm-up — 20 minutes, main tasks — 50 minutes, starred tasks — 20 minutes. Everything is done in the browser console.

Warm-up

1. The console as a calculator
Easy7 min

open the console and make sure code runs.

Open the console with F12, the Console tab. Calculate:

  • how many seconds there are in a day;
  • how many minutes there are in a school year of 9 months with 30 days each;
  • how much 7 notebooks at 12 manat each and 3 pens at 5 manat each cost.
Multiplication is the star *, addition is +. Parentheses work as in math: (7 * 12) + (3 * 5). You do not need console.log: the console shows the result by itself.
  • each answer is found with one line in the console;
  • the results are written down in the notebook.
2. The first message
Easy6 min

call a function and see the result.

Run three lines in the console: a window with a greeting, your name printed in the console, and the current year printed in the console.

alert("Salam!");
console.log("Murad");
console.log(2026);
Text goes in quotes, a number is written without them. While the alert window is open, the page waits: close it with the “OK” button.
  • the window appeared and closed with the button;
  • both lines are visible in the console.
3. Adding strings
Easy7 min

see the difference between a number and a string.

Run these lines and explain to your neighbor why the results are different:

2 + 3;
"2" + "3";
"Mary" + " " + 2026;
Quotes turn a value into text. Text is not added up but joined.
  • what each line printed is written down;
  • the explanation takes one sentence.

Main tasks

4. Three layers on a live website
Medium15 min

tell HTML, CSS and JavaScript apart on a real page.

Open any website you know and find three things on it:

  1. something described in HTML (text, an image, a button);
  2. something set in CSS (color, size, position);
  3. something JavaScript does (it changes without reloading the page: a menu, a slider, a cart, search).
The sign of JavaScript at work is a change without a reload: the browser’s reload button did not spin, and the page address did not change.
the name of the website, three examples and one sentence on how you understood that this is JavaScript at work.
  • there is an example for each of the three layers;
  • the JavaScript example really changes without a reload.
5. What runs the code
Medium12 min

remember the pair “browser — engine”.

Fill in a table in your notebook: Chrome, Firefox, Safari, Edge, Node.js — and the engine of each. Then answer in writing: why does the same code work in all browsers? And the other way round: why does typeof document give "object" in the browser console, but "undefined" in Node.js?

The answer is connected with the word “standard”. Remember what the standard of the language is called.
  • the table is filled in completely;
  • the answer contains the word ECMAScript;
  • it is explained that document is not part of the language core but something the browser adds.
6. Searching the documentation
Medium13 min

learn to find the answer on MDN, not in a random article.

Find the MDN pages of three functions: alert, prompt, console.table. For each one, write down what it does and what it returns.

The search query: mdn console table. The first link leads to developer.mozilla.org.

  • three pages are found, and the address of each starts with developer.mozilla.org;
  • for each function there is a line “what it does”;
  • it is found that prompt returns text, and null after Cancel.
7. A dialog with the user
Medium10 min

build a small program from two functions.

Write a program in the console: ask for a name, then greet the person by name and say how many letters the name has.

The length of a text is found like this: name.length. Day 16 covers it in detail.
  • the program asks for a name and shows a greeting;
  • the greeting contains the number of letters;
  • for “Cancel”, the text of the red line in the console is written down and explained: prompt returns null after Cancel, and null has no length.

Starred tasks

8. What the browser can and cannot do
Hard10 min

check the limits we talked about in the lecture.

Run these lines in the console and explain what happened in each case:

document.title;
navigator.language;
navigator.geolocation;
The first line reads the tab title. The third one does not ask for the location by itself — it only gives a tool that will ask for permission later.
  • for each line it is written down what it returned;
  • it is explained why the browser did not show your location at once.
9. A mini research: when features were born
Hard10 min

see that the language grows while old code keeps working.

At the bottom of every MDN page there is a browser support table. Find the year when it became possible to write const, and the year for let. Write down in which edition of the standard they appeared.

  • the year and the edition are named (hint: it is the big update of 2015);
  • a conclusion is made: what happens to old code written before that.
