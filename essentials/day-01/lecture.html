1. Что такое JavaScript

JavaScript — это язык программирования. На нём пишут инструкции, которые компьютер выполняет по порядку, сверху вниз. Инструкция может быть простой: «посчитай 2 + 2», «покажи надпись», «возьми текст из поля ввода». Из таких мелких шагов собираются большие программы: интернет-магазин, чат, игра, редактор фотографий.

Главное отличие от HTML и CSS в одном слове: поведение. HTML описывает, что на странице есть. CSS описывает, как это выглядит. JavaScript описывает, что происходит, когда человек нажимает, вводит, прокручивает, ждёт ответа сервера.

Представьте кафе. HTML — это столы, стулья и меню: что физически стоит в зале. CSS — оформление: цвет стен, шрифт в меню, форма официантов. JavaScript — это сам официант: он принимает заказ, уносит его на кухню, приносит еду, считает счёт. Без официанта кафе выглядит красиво, но ничего не происходит.

Вы уже видели работу JavaScript сотни раз, просто не знали, что это он:

  • лента, которая подгружается сама. Вы прокручиваете вниз, и появляются новые записи — страница не перезагружалась, значит, данные запросил код;
  • корзина интернет-магазина. Нажали «купить» — число товаров в углу изменилось мгновенно;
  • проверка формы. Ввели телефон не в том формате и сразу получили красную подпись, ещё до отправки;
  • тёмная тема. Нажали на переключатель — цвета поменялись и запомнились до следующего раза;
  • карта. Тянете её пальцем, она подгружает новые куски и ставит метки.

Общее у всех примеров одно: страница изменилась без перезагрузки. Это самый простой признак, по которому можно узнать работу JavaScript, даже не заглядывая в код.

Вот программа из одной строки. Она показывает окно с надписью:

alert("Привет, Мары!");

А эта программа спрашивает имя и здоровается:

const name = prompt("Как вас зовут?");
alert("Здравствуйте, " + name + "!");

Здесь уже видно три вещи, которые мы будем разбирать весь курс: значение («Мары», имя человека), переменная name — коробочка с именем, куда значение положили, и функция alert — готовая команда, которой пользуются, написав её имя и скобки.

Почему этот язык учат первым

Языков программирования сотни. JavaScript берут первым не потому, что он самый простой или самый правильный, а по трём практическим причинам.

Ничего не нужно устанавливать. Браузер уже стоит на вашем компьютере и на компьютере в классе. Открыли консоль — можно писать код. Для большинства других языков сначала пришлось бы час ставить инструменты.

Результат видно сразу. Написали строку — страница изменилась. Это важно для обучения: когда между действием и результатом одна секунда, ошибки находятся быстрее, а интерес держится дольше.

Это язык, который нужен работе. Любой сайт — это HTML, CSS и JavaScript. Даже если потом вы уйдёте в другие области, знание того, как работает интерфейс, останется полезным.

2. Что значит «язык программирования»

Компьютер не понимает человеческий язык. Он умеет выполнять очень простые операции: сложить два числа, сравнить их, положить значение в память, взять его обратно. Язык программирования — это посредник. Мы пишем понятные нам слова, а программа-переводчик превращает их в операции процессора.

У любого языка есть синтаксис — правила записи. В русском языке после «который» ставят запятую, а предложение заканчивают точкой. В JavaScript строку кода заканчивают точкой с запятой, текст берут в кавычки, а аргументы функции — в круглые скобки. Нарушите правило — программа не выполнится, и браузер скажет об этом сообщением об ошибке. Это не страшно: ошибки видят все, включая тех, кто пишет код двадцать лет.

Второе важное слово — по порядку. Инструкции выполняются сверху вниз, одна за другой. Разберём программу из четырёх строк по шагам:

const price = 12;        // 1
const count = 7;         // 2
const total = price * count;  // 3
console.log(total);      // 4
1

Заводим коробочку с именем price и кладём в неё число 12. Слово const означает «это значение менять не будем».

2

Заводим вторую коробочку count со значением 7.

3

Считаем 12 * 7. Важно: сначала вычисляется правая часть, и только потом результат кладётся в коробочку total. Компьютер к этому моменту уже знает, что лежит в price и count, потому что строки 1 и 2 выполнились раньше.

4

Показываем результат: в консоли появляется 84.

Поменяйте строки местами — и программа сломается. Если написать console.log(total) первой строкой, браузер ответит: total is not defined, то есть «я ещё не знаю такого имени». Это и есть главная мысль: компьютер не догадывается, он выполняет ровно то, что написано, и ровно в том порядке.

Программа — это рецепт. «Налить воду, вскипятить, насыпать чай, накрыть» — порядок важен, шаги простые, и каждый шаг понятен сам по себе. Компьютер — очень быстрый, очень точный и абсолютно бестолковый повар: он не поймёт «ну ты сделай как обычно», зато выполнит подробный рецепт миллион раз без единой ошибки.

Из чего складывается любая программа, независимо от языка:

КирпичикЧто этоПримерКогда разбираем

Эти шесть кирпичиков есть почти в каждом языке программирования. Выучив их один раз на JavaScript, вы будете узнавать их в Python, Java и любом другом языке — поменяются только детали записи.

3. Три слоя страницы: HTML, CSS, JavaScript

Любая веб-страница собрана из трёх слоёв. Они работают вместе, но отвечают за разное.

Слои можно снимать по одному. Выключите CSS — страница станет некрасивой, но текст останется. Выключите JavaScript — страница останется красивой, но кнопки перестанут что-либо делать. Уберите HTML — не останется ничего.

Посмотрим на одну кнопку во всех трёх слоях. HTML создаёт кнопку и место для счётчика:

<button id="btn">Купить</button>
<span id="count">0</span>

CSS решает, как она выглядит:

#btn {
  background: #f59e0b;
  color: white;
  border-radius: 8px;
  padding: 10px 20px;
}

А JavaScript отвечает на нажатие:

let count = 0;

document.getElementById("btn").addEventListener("click", function () {
  count = count + 1;
  document.getElementById("count").textContent = count;
});

Этот код мы разберём построчно на днях 24 и 27, а сейчас обратите внимание на структуру: есть переменная, которая хранит число, и есть реакция на событие — «когда нажали, сделай вот это». Почти любой интерфейс в интернете устроен именно так.

Найдите на любимом сайте элемент, который меняется без перезагрузки: лайк, звёздочку, счётчик корзины. Подумайте, какая переменная за ним стоит и какое событие её меняет. Это и есть мышление программиста.
Новички часто пытаются «сделать всё на JavaScript»: рисуют кнопки кодом, задают цвета кодом. Так тоже можно, но страница становится медленной и непонятной. Правило простое: что можно показать в HTML и покрасить в CSS — делайте в HTML и CSS. JavaScript берите тогда, когда нужно действие.

4. Где выполняется код и кто его выполняет

Написанный код — это просто текст в файле. Чтобы он заработал, нужен исполнитель. В браузере такой исполнитель называется движок JavaScript. Браузер читает HTML, находит в нём код и отдаёт его движку. Движок разбирает текст, превращает его в понятные процессору команды и выполняет.

Как движок понимает код

Внутри движка код проходит три стадии. Знать их наизусть не нужно, но понимать полезно: это объясняет, почему одни ошибки видны сразу, а другие только во время работы программы.

1

Разбор. Движок читает текст и проверяет правила записи. Если забыта скобка, программа не запустится вообще — это синтаксическая ошибка, её видно до выполнения.

2

Перевод во внутренние команды. Текст превращается в набор простых инструкций, понятных движку.

3

Выполнение. Инструкции выполняются по очереди. Здесь вылезают ошибки, которые нельзя было заметить заранее: обратились к имени, которого нет, или вызвали как функцию то, что функцией не является.

Раньше говорили, что JavaScript — «интерпретируемый» язык: код выполняется по строчке, без подготовки. Сегодня это неточно. Современные движки следят, какие куски кода выполняются часто, и на ходу переводят их в машинные команды — такой приём называется JIT-компиляцией. Поэтому один и тот же цикл при втором проходе может работать в десятки раз быстрее, чем при первом.

Движок V8 назвали в честь автомобильного двигателя V8: восемь цилиндров, много мощности. Его писали в Германии, а первая версия вышла вместе с браузером Chrome в 2008 году.

У каждого браузера свой движок, но все они выполняют один и тот же язык:

БраузерДвижок
Chrome, Edge, Opera, Яндекс.БраузерV8
FirefoxSpiderMonkey
SafariJavaScriptCore

Движок V8 умеет работать и без браузера. Так появился Node.js — программа, которая запускает JavaScript прямо в системе. Поэтому сегодня на этом языке пишут не только страницы:

  • сайты и веб-приложения — в браузере;
  • серверы, которые отдают данные этим сайтам, — на Node.js;
  • приложения для телефонов — React Native;
  • программы для компьютера — Electron (так сделаны VS Code, Discord, Slack);
  • скрипты для таблиц, ботов, автоматизации.

Стоит объяснить эти строчки подробнее, потому что за ними стоит ваш будущий выбор профессии.

Браузер. Здесь работает то, что человек видит: страницы магазинов, личные кабинеты, редакторы, игры. Этим занимается фронтенд-разработчик — и именно этому посвящён наш первый курс.

Сервер. Когда страница просит данные — список товаров, сообщения чата, — их отдаёт сервер. На Node.js такой сервер пишут на том же языке. Человек, который умеет и то и другое, называется фулстек-разработчиком.

Телефон. React Native позволяет собрать приложение для Android и iOS из кода на JavaScript, а не писать его дважды на разных языках.

Компьютер. Программы вроде VS Code, Discord и Slack — это, по сути, браузер без адресной строки, внутри которого работает знакомый нам код.

Один язык на всех уровнях — это экономия. Человек, который выучил JavaScript для страницы, может написать и простой сервер к ней, не изучая второй язык с нуля. Поэтому в вакансиях часто ищут именно JavaScript: по ежегодному опросу Stack Overflow он уже много лет держится в самых используемых языках.

5. Откуда взялся язык

История языка объясняет его странности. Некоторые решения, которые сегодня кажутся нелогичными, появились потому, что язык делали в спешке, а потом двадцать лет не могли сломать совместимость с уже написанными сайтами.

1995
Брендан Айк в компании Netscape пишет первую версию языка примерно за десять дней. Название придумали маркетологи: тогда была популярна Java, и слово «JavaScript» помогало продавать.
1997
Язык описывают в стандарте, чтобы все браузеры понимали его одинаково. Стандарт называется ECMAScript: имя JavaScript к тому времени принадлежало одной компании.
1996–2001
«Война браузеров». Microsoft выпускает свой вариант языка — JScript. Один и тот же код работает в Netscape и не работает в Internet Explorer, и наоборот. Разработчики пишут страницы по два раза и вставляют проверки «а какой у вас браузер».
2005–2008
Появляются библиотеки вроде jQuery, которые прячут различия браузеров за одной командой. Тогда же взлетает подход, при котором страница подгружает данные без перезагрузки: почта, карты, ленты новостей начинают работать как настоящие программы.
2009
Появляется Node.js: тот же язык начинает работать вне браузера. С этого момента один человек может написать и страницу, и сервер к ней.
2015
Большое обновление ES2015: современные возможности, которыми мы будем пользоваться весь курс (let, const, стрелочные функции, классы).
Каждый год
Новая редакция стандарта выходит летом: ES2016, ES2017 и так далее. Язык не переписывают заново, а добавляют возможности так, чтобы старый код продолжал работать.

Кто решает, что войдёт в язык? Комитет TC39 — представители браузерных компаний и крупных разработчиков. Любое предложение проходит четыре стадии: идея, описание, черновик с реализацией, готовая возможность. Пока предложение не дошло до последней стадии, им лучше не пользоваться в учебном коде: оно может измениться.

Из-за требования совместимости в языке остались вещи, которые сегодня считаются ошибками дизайна: например, var с его странными правилами видимости или ==, который сравнивает «примерно». Их не убирают, потому что миллионы старых страниц перестали бы работать. Вместо этого добавили правильные замены: let и const вместо var, === вместо ==. Мы сразу будем учиться писать по-современному, а про старое расскажем, чтобы вы понимали чужой код.

Первое имя языка было Mocha, второе — LiveScript, и только третье — JavaScript. Сегодня официальное имя стандарта — ECMAScript, но в жизни все говорят «JavaScript», а версии называют по году: «это появилось в ES2020».

6. JavaScript и Java — разные языки

«JavaScript — это сокращённая Java» — самое частое заблуждение новичков. Общего у них только четыре буквы в названии и немного похожий вид скобок. Это разные языки с разной историей, разными правилами и разными задачами: на Java пишут банковские системы и приложения для Android, на JavaScript — страницы и серверы для них. Спросить на собеседовании «а какая между ними разница» — обычное дело, и ответ «никакой» сразу заметен.

7. Что язык умеет в браузере и что ему запрещено

Код на странице работает не в пустоте: он живёт внутри вкладки браузера. Вкладка даёт ему много возможностей, но держит в рамках — иначе любой сайт мог бы навредить вашему компьютеру.

УмеетНе умеет
менять текст и оформление страницы читать и записывать любые файлы на диске
реагировать на клики, ввод, прокрутку запускать программы на компьютере
запрашивать данные с сервера и показывать их свободно читать данные чужого сайта в другой вкладке
сохранять данные в браузере и помнить их после перезагрузки включать камеру или узнавать место без вашего разрешения

Правая колонка — не недостаток языка, а защита. Всё, что касается вашего компьютера, браузер разрешает только через явный вопрос: «Сайт просит доступ к камере. Разрешить?». Файл с компьютера сайт получит только тогда, когда вы сами выберете его в окне выбора файла.

Проверим это прямо сейчас. Откройте консоль на любой странице и выполните:

document.title;              // заголовок вкладки — читается свободно
document.title = "Мой сайт"; // и меняется: посмотрите на вкладку
navigator.language;          // язык браузера, например "ru"
screen.width;                // ширина экрана в точках

Страница разрешила прочитать и даже изменить свой заголовок. Теперь попробуйте узнать местоположение:

navigator.geolocation.getCurrentPosition(function (pos) {
  console.log(pos.coords.latitude, pos.coords.longitude);
});

Браузер не выдаст координаты молча — сверху появится вопрос «Разрешить доступ к вашей геопозиции?». Пока человек не нажмёт «Разрешить», код не получит ничего. Так же устроены камера, микрофон и уведомления.

Отсюда важное правило безопасности: не выполняйте в консоли код, который вам прислали незнакомые люди «чтобы получить подарок». Вы выполняете его от имени открытой страницы — например, своей почты или банка. Браузер защищает вас от чужих сайтов, но не от вас самих.

Ещё одно ограничение называется «правило одного источника»: код одной страницы не может свободно читать содержимое другой. Иначе вкладка с игрой прочитала бы вашу переписку в соседней вкладке. Данные с чужого сервера страница получает только с его разрешения — разберём это на дне 31, когда дойдём до fetch.

8. Первые строки кода

Подробно про инструменты будет завтра, на дне 2. Сегодня достаточно знать: в каждом браузере есть консоль — окно, где можно написать строку кода и сразу увидеть результат. Открывается клавишей F12, вкладка Console.

Консоль — это черновик программиста. В ней проверяют одну мысль: «а что вернёт этот метод?», «а какой сейчас заголовок у страницы?». Ничего сохранять не нужно, ничего испортить нельзя: закрыли вкладку — всё исчезло.

ДействиеКак
открыть консольF12, затем вкладка Console
выполнить строкуEnter
перенести строку, не выполняяShift + Enter
повторить предыдущую командустрелка ↑
очистить консольCtrl + L или console.clear()

Попробуйте эти строки прямо на лекции:

2 + 2 * 2;                 // 6 — приоритет как в математике
"Мары" + " " + 2026;       // "Мары 2026" — строки складываются
console.log("Работает!");  // выводит текст в консоль
Откройте консоль и посчитайте, сколько минут в неделе. Подсказка: 60 * 24 * 7. Если получилось 10080 — всё верно, вы только что выполнили свою первую программу.

Код можно писать и в файле. Тогда его подключают к странице одной строкой:

<script src="app.js" defer></script>

Файл app.js лежит рядом со страницей, а слово defer говорит браузеру: «сначала покажи страницу, потом выполняй код». Так делают почти всегда.

Полностью маленький проект выглядит так. Два файла в одной папке:

<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Первая страница</title>
  <script src="app.js" defer></script>
</head>
<body>
  <h1 id="hello">Здравствуйте!</h1>
</body>
</html>
// app.js
const title = document.getElementById("hello");
title.textContent = "Салам, Мары!";
console.log("Код выполнился");

Откройте страницу в браузере — заголовок поменяется ещё до того, как вы успеете его прочитать. Разбирать getElementById мы будем на дне 24, сейчас достаточно увидеть связку: HTML создал заголовок, JavaScript его изменил.

Если написать <script src="app.js"> без defer в самом начале страницы, код выполнится раньше, чем появится заголовок, и getElementById вернёт null. Отсюда классическая ошибка новичка: Cannot set properties of null. Лечится одним словом defer.

Кодировка UTF-8 в шапке — обязательна, иначе кириллица и туркменские буквы ä, ň, ö, ü, ý, ž превратятся в набор знаков вопроса.

9. Когда что-то идёт не так

Ошибка — это не наказание, а сообщение. Браузер пишет, что именно он не понял и в какой строке. Научиться читать эти сообщения важнее, чем заучивать методы: ошибки будут сопровождать вас всю работу.

Три сообщения, которые встретятся в первую неделю:

СообщениеЧто значитЧто делать
Uncaught ReferenceError: total is not defined использовано имя, которого нет проверить, объявлена ли переменная и не опечатались ли в имени
Uncaught SyntaxError: Unexpected token нарушены правила записи искать лишнюю или пропущенную скобку, кавычку, запятую
Uncaught TypeError: x is not a function вызвали как функцию то, что функцией не является проверить имя метода и опечатки: consol.log, alrt

Сообщение об ошибке читают с конца: последняя строка говорит, где именно споткнулся движок. В консоли рядом с ошибкой стоит имя файла и номер строки — нажмите на него, и браузер покажет это место.

console.log(summa);   // ReferenceError: summa is not defined
consol.log("тест");   // TypeError: consol.log is not a function
alert("привет);       // SyntaxError: незакрытая кавычка
Не бойтесь сломать код: браузер нельзя испортить неверной строкой. Пробуйте, читайте ошибку, правьте. Копируйте текст ошибки в поиск целиком — чаще всего первый же ответ объясняет причину.

10. Документация: MDN и спецификация

Программист не держит все методы в голове. Он помнит, что метод есть, и умеет быстро найти описание. Главный справочник по языку — MDN Web Docs. Там два больших раздела:

  • Guide — учебник: объясняет темы по порядку, с примерами;
  • Reference — справочник: отдельная страница на каждый метод, свойство и оператор.

Есть ещё спецификация ECMAScript — документ, по которому пишут сами браузеры. Она написана сухим языком для разработчиков движков. Читать её мы начнём в курсе 2, когда появятся вопросы вида «а почему оно работает именно так».

Ищите не в поиске вообще, а так: «mdn» плюс название метода. Запрос mdn array map приведёт прямо на нужную страницу справочника. Английский в документации простой и повторяющийся, привыкаешь за неделю.

11. Как устроен этот курс

Курс идёт три месяца: понедельник, среда, пятница, по три урока в день. Первый урок — лекция, второй и третий — практика. Дома вы перечитываете конспект и делаете домашнее задание.

У каждого дня три страницы, и у них разные задачи:

Обратите внимание на два блока, которые будут в каждой лекции. Справочник дня — таблица со всеми методами темы и ссылками на документацию: по ней удобно искать через месяц, когда вы забудете название метода. Шпаргалка — тот же материал в виде короткого кода, который можно переписать в тетрадь.

Курс Essentials — первый из четырёх. Дальше идут Intermediate (как язык устроен внутри), Advanced (язык по спецификации) и Web APIs (возможности браузера). Всё вместе покрывает документацию целиком, поэтому в лекциях вы часто увидите пометку «подробно разберём в курсе 2» — это не отговорка, а ссылка на конкретное место.

Что понадобится для занятий

  • Браузер — Chrome, Firefox или Edge. Подойдёт любой современный, он уже стоит на компьютере;
  • редактор кода — VS Code, бесплатный. Ставим на дне 2;
  • тетрадь и ручка — да, всерьёз. Схемы, шпаргалки и разбор ошибок от руки запоминаются лучше;
  • папка для работ — заведите одну папку и складывайте туда все файлы курса, по папке на день.

Как спрашивать, чтобы вам помогли

Вопрос «у меня не работает» не имеет ответа. Полезный вопрос состоит из четырёх частей: что вы хотели сделать, какой код написали, что получилось и что ожидали получить. Текст ошибки из консоли копируйте целиком — в нём обычно и есть ответ.

Это правило пригодится не только на занятиях. Ровно так же оформляют вопросы на работе и в сообществах разработчиков: чем точнее описана проблема, тем быстрее приходит помощь.

Главный совет на три месяца: печатайте код руками, не копируйте. Пальцы запоминают синтаксис быстрее головы, а ошибки, которые вы делаете при наборе, — это и есть учёба. Скопированный код учит нулю.

  1. Чем HTML отличается от JavaScript? Ответьте одним предложением.
    Ответ HTML описывает содержимое страницы, JavaScript описывает поведение: что происходит в ответ на действия человека или события.
  2. Что такое движок и назовите любые два.
    Ответ Движок — программа, которая выполняет код JavaScript. Например, V8 в Chrome и SpiderMonkey в Firefox.
  3. Может ли сайт без вашего ведома прочитать файл с рабочего стола?
    Ответ Нет. Браузер запрещает доступ к файлам. Сайт получит файл только если вы сами выберете его в окне выбора файла.
  4. Java и JavaScript — это один язык или разные?
    Ответ Разные. Общее у них только часть названия.
  5. Где искать описание незнакомого метода?
    Ответ В справочнике MDN: запрос вида «mdn» плюс имя метода.
  6. Что означает ошибка Uncaught ReferenceError: summa is not defined?
    Ответ Использовано имя summa, которого движок не знает: переменная не объявлена или в имени опечатка.
  7. Зачем в теге <script> пишут defer?
    Ответ Чтобы код выполнился после того, как браузер построит страницу. Иначе скрипт не найдёт элементы и получит null.
