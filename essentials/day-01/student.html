День 1. Что такое JavaScript

Короткая выжимка лекции: перечитать перед следующим занятием.

Главное

JavaScript — язык программирования. Программа на нём — это список инструкций, которые выполняются по порядку. В браузере он отвечает за поведение страницы.
Три слоя страницы: HTML — содержимое, CSS — внешний вид, JavaScript — поведение.
Движок — программа внутри браузера, которая выполняет код. V8 в Chrome и Edge, SpiderMonkey в Firefox, JavaScriptCore в Safari. Движок V8 работает и без браузера — это Node.js.
ECMAScript — официальный стандарт языка. Новая редакция выходит каждый год: ES2015, ES2016 и так далее. Старый код при этом продолжает работать.
Ядро и окружение. Ядро языка — числа, строки, функции, Math, JSON — одинаково везде. Окружение добавляет своё: браузер — страницу (document), окна, события; Node.js — файлы и сервер (process). 
typeof document;   // "object" в браузере, "undefined" в Node.js
typeof process;    // "undefined" в браузере, "object" в Node.js

Где работает JavaScript

  • страницы и веб-приложения — в браузере;
  • серверы — Node.js;
  • приложения для телефона — React Native;
  • программы для компьютера — Electron (VS Code, Discord).

Консоль

Консоль сама показывает значение последнего выражения. console.log печатает, но ничего не возвращает — поэтому после вывода консоль пишет undefined. Незаконченная строка (function greet() {) не выполняется по Enter, а ждёт продолжения; перенос вручную — Shift + Enter.

3 + 5;               // 8
console.log(3 + 5);  // печатает 8, а ниже — undefined
