Day 2. Tools

The editor, a project of two files, the console and debugging.

The workplace

A browser + the VS Code editor + a project folder. The Live Server extension opens the page at http://127.0.0.1:5500 and refreshes it by itself after saving.

A project of two files

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Day 2</title>
  <script src="app.js" defer></script>
</head>
<body>
  <h1>Checking the tools</h1>
</body>
</html>
// app.js
console.log("File connected");
File names: Latin letters, lowercase, no spaces. On Windows App.js and app.js are one file, but on many servers on the internet they are different. арр.js typed with Cyrillic letters will not be found anywhere.

Console commands

console.log("text", value);
console.info("information");
console.warn("a warning");
console.error("an error");

console.table(students);     // a table
console.dir(document.body);  // a tree of properties

console.group("section");
console.groupEnd();

console.time("label");
console.timeEnd("label");

console.count("got here");
console.assert(age >= 18, "too young");
console.trace();
console.clear();

Substitutions: console.log("Student %s got %d", "Aman", 5) — each one takes the next value. In the console $_ keeps the result of the previous line. Without a name console.count() counts under the name default; an unknown name in timeEnd gives the warning Timer '…' does not exist.

Step-by-step debugging. Do not guess — stop and look: in the average function, at the first stop Scope showed i: 1 — the loop skipped the first mark.
A breakpoint is a mark on a line of code where the browser stops the program so that you can look at the values of the variables. You set it by clicking a line number in the Sources tab or with the word debugger right in the code.

When nothing works

  1. look at the console and read the error;
  2. check that the file is saved;
  3. reload the page with Ctrl + F5;
  4. put console.log("the file works") as the first line;
  5. read the file name and the path letter by letter.

A script that is not found gives two red lines in the console: 404 (Not Found) and Refused to execute script … MIME type ('text/html'). Which address the page tried to load is shown by document.scripts[0].src.

VS Code shortcuts: Ctrl + S — save, Ctrl + / — comment, Alt + arrows — move a line, Ctrl + D — select the same word.
  1. Create a course folder and inside it a folder day-02 with the files index.html and app.js. Check that the text from console.log appears in the console.
  2. Print a list of five of your subjects with marks using console.table.
  3. Measure with console.time how long a loop of a million steps takes. Write the result in your notebook.
  4. Put debugger in the middle of your code and look at the values of the variables. Remove it after the check.
  5. Write the name apps.js instead of app.js in <script>, find both red lines in the console and check the address with document.scripts[0].src. Then put the correct name back.
