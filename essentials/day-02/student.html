День 2. Инструменты

Редактор, проект из двух файлов, консоль и отладка.

Рабочее место

Браузер + редактор VS Code + папка проекта. Расширение Live Server открывает страницу по адресу http://127.0.0.1:5500 и сама обновляет её после сохранения.

Проект из двух файлов

<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>День 2</title>
  <script src="app.js" defer></script>
</head>
<body>
  <h1>Проверка инструментов</h1>
</body>
</html>
// app.js
console.log("Файл подключён");
Имена файлов — латиницей, маленькими буквами, без пробелов. App.js и app.js — разные файлы.

Инструменты разработчика

Команды консоли

console.log("текст", значение);
console.info("информация");
console.warn("предупреждение");
console.error("ошибка");

console.table(students);     // таблица
console.dir(document.body);  // дерево свойств

console.group("раздел");
console.groupEnd();

console.time("метка");
console.timeEnd("метка");

console.count("сюда зашли");
console.assert(age >= 18, "мало лет");
console.trace();
console.clear();
Точка останова — метка на строке кода, где браузер остановит программу, чтобы вы посмотрели значения переменных. Ставится щелчком по номеру строки во вкладке Sources или словом debugger прямо в коде.

Если ничего не работает

  1. посмотреть в консоль и прочитать ошибку;
  2. проверить, сохранён ли файл;
  3. обновить страницу через Ctrl + F5;
  4. поставить console.log("файл работает") первой строкой;
  5. прочитать имя файла и путь по буквам.
Горячие клавиши VS Code: Ctrl + S — сохранить, Ctrl + / — комментарий, Alt + стрелки — двигать строку, Ctrl + D — выделить такое же слово.
  1. Заведите папку курса и внутри неё папку day-02 с файлами index.html и app.js. Проверьте, что надпись из console.log появляется в консоли.
  2. Выведите список пяти своих предметов с оценками методом console.table.
  3. Замерьте через console.time, сколько выполняется цикл на миллион шагов. Запишите результат в тетрадь.
  4. Поставьте debugger в середину своего кода и посмотрите значения переменных. Уберите его после проверки.
