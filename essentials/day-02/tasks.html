День 2. Задания

Уроки 2 и 3, 90 минут. Сегодня много работы руками: ставим редактор, собираем проект, осваиваем консоль. Все файлы складываем в папку day-02.

Разминка

1. Рабочее место
Легко10 мин

поставить редактор и завести папку курса.

Установите VS Code, поставьте расширение Live Server. Создайте папку курса и внутри неё папку day-02. Откройте её в редакторе: File → Open Folder.

  • в левой панели редактора видно имя папки day-02;
  • расширение Live Server установлено;
  • включено автосохранение (File → Auto Save).
2. Страница и скрипт
Легко10 мин

подключить файл со скриптом к странице.

Создайте index.html и app.js. В странице — заголовок «День 2» и подключение скрипта с defer. В скрипте — вывод «Файл подключён». Откройте страницу через Live Server.

  • в адресной строке http://127.0.0.1:5500, а не file:///;
  • надпись видна в консоли;
  • после изменения текста и сохранения страница обновилась сама.
3. Четыре уровня сообщений
Легко7 мин

увидеть разницу между log, info, warn и error.

Выведите по одному сообщению каждым из четырёх методов. Затем в консоли найдите фильтр уровней и оставьте только ошибки и предупреждения.

  • четыре сообщения выведены;
  • получилось спрятать обычные сообщения фильтром;
  • записано, каким цветом показывается каждый уровень.

Основные задания

4. Таблица оценок
Средне12 мин

показать список данных читаемо.

Соберите список из пяти учеников с оценками и выведите его двумя способами: обычным console.log и методом console.table. Сравните, что удобнее читать.

const students = [
  { name: "Аман", mark: 5 },
  { name: "Мерет", mark: 4 },
];
console.table(students);
  • в таблице пять строк и два столбца;
  • записан вывод: в каком случае таблица удобнее обычного вывода.
5. Группы сообщений
Средне12 мин

навести порядок в длинном выводе.

Выведите расписание на три дня: каждый день — своя группа, внутри группы три предмета. Один из дней сделайте сразу свёрнутым.

Свёрнутая группа открывается методом console.groupCollapsed, закрывается так же — console.groupEnd.
  • три группы, в каждой по три строки;
  • одна группа свёрнута при открытии страницы;
  • группы раскрываются и сворачиваются щелчком.
6. Замер времени
Средне12 мин

измерить, а не гадать.

Замерьте время двух циклов: на сто тысяч шагов и на десять миллионов. Выведите оба результата и сравните. Внутри цикла складывайте числа в переменную.

console.time("маленький");
let sum = 0;
for (let i = 0; i < 100000; i++) { sum = sum + i; }
console.timeEnd("маленький");
  • оба замера выведены с разными именами меток;
  • записано, во сколько раз второй цикл медленнее;
  • объяснено, почему время в разных запусках немного отличается.
7. Счётчик вызовов
Средне10 мин

узнать, сколько раз выполняется кусок кода.

Напишите функцию приветствия, которая внутри вызывает console.count. Вызовите её пять раз с разными именами, потом обнулите счётчик и вызовите ещё дважды.

  • счётчик дошёл до 5, обнулился и начал считать заново;
  • использован console.countReset.

Со звёздочкой

8. Остановиться и осмотреться
Сложно14 мин

поработать с точкой останова.

Напишите код, который считает стоимость покупки: цена, количество, скидка. Поставьте точку останова перед подсчётом итога — щелчком по номеру строки во вкладке Sources. Обновите страницу и посмотрите значения переменных. Затем пройдите программу по шагам до конца.

Кнопки управления находятся над списком переменных: продолжить, шаг через строку, зайти внутрь.
  • программа останавливается в нужной строке;
  • выписаны значения всех переменных на момент остановки;
  • то же самое повторено словом debugger в коде, а затем строка убрана.
9. Сломай и почини
Сложно13 мин

научиться читать ошибки и порядок действий при поломке.

Сломайте свой проект тремя способами по очереди, каждый раз записывая текст ошибки из консоли и то, как вы её нашли:

  1. измените в подключении имя файла на App.js;
  2. напишите consol.log("тест") с одной буквой «e»;
  3. уберите закрывающую кавычку в строке.
  • для каждой поломки записан текст ошибки;
  • указано, в какой строке браузер нашёл проблему;
  • проект после всех трёх правок снова работает.
