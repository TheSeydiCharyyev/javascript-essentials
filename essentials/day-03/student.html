День 3. Обзор языка

Выжимка лекции: восемь типов, переменные, операторы, ход программы, первая программа и чтение ошибок.

Главное

Программа собирается из четырёх вещей: значение, выражение (вычисляется в значение), инструкция (одно действие) и блок (инструкции в фигурных скобках). Выполняется сверху вниз.
Заучивать сегодня нечего. Задача дня — узнавать части языка в чужом коде и знать, на каком дне курса мы к ним вернёмся.

Восемь типов значений

ГруппаТипы
примитивы (7) Number, BigInt, String, Boolean, Symbol, Undefined, Null
объекты (всё остальное) { }, [ ], функция, Date, Error… 
3 / 2;              // 1.5 — целых и дробных отдельно нет
0.1 + 0.2;          // 0.30000000000000004 — дробные хранятся приближённо
NaN === NaN;        // false — единственное значение, не равное себе
typeof [1, 2];      // "object" — массив тоже объект
typeof null;        // "object" — старая ошибка языка
Ложны только шесть значений: false, 0, "", NaN, null, undefined. Всё остальное истинно — включая "0", [] и {}.

undefined — значения никто не клал. null — пустоту поставили намеренно.

const user = { name: "Аман" };
user.name = "Мерет";   // можно: const запрещает переприсваивание, а не изменение

Операторы

"3" + 4 + 5;      // "345" — плюс со строкой склеивает
3 + 4 + "5";      // "75"
123 == "123";     // true  — нестрогое, приводит типы
123 === "123";    // false — строгое, пишем только так
0 && "Салам";     // 0      — короткое замыкание
"" || "Гость";    // "Гость" — запасное значение

Объекты, массивы, функции

const student = { name: "Гүлнар", marks: [5, 4, 5] };
student.name;         // через точку
student["marks"];     // через скобки
student.city = "Мары";     // свойство добавляется в любой момент

function add(x, y) { return x + y; }   // объявление
const add2 = (x, y) => x + y;          // стрелочная
function greet(name = "Гость") { }     // значение по умолчанию
function avg(...numbers) { }           // остаточные параметры
Объекты и массивы передаются по ссылке: const b = a не копия, а второе имя того же объекта. Поэтому { } === { } — всегда false.
Язык и среда. Сам язык — числа, строки, объекты, функции, if, for; ввода и вывода у него нет. console, document, fetch, alert даёт браузер, а в Node.js вместо них файлы и сеть.

Первая программа

const student = { name: "Аман", marks: [5, 4, 5, 3, 5] };

function average(numbers) {
  let sum = 0;
  for (const n of numbers) sum += n;
  return sum / numbers.length;
}

const score = average(student.marks);
const line = `${student.name}: средний балл ${score.toFixed(2)}`;
console.log(line);
document.getElementById("result").textContent = line;

Подключение к странице: <script src="app.js" defer></script> — слово defer обязательно, иначе код выполнится раньше разметки.

Чтение ошибки

// Uncaught   TypeError   : Cannot read...   at app.js:24:45
//    |            |              |                  |
// не поймали   вид ошибки   что не так    файл:строка:столбец — кликается!
ВидКуда смотреть
SyntaxErrorскобки и кавычки; ломает весь файл сразу
ReferenceErrorопечатка в имени или переменная объявлена ниже
TypeErrorтам null/undefined или вызвали не функцию
RangeErrorчисло вне пределов, бесконечная рекурсия
Частые ошибки. Значение на строке после return — движок сам поставит точку с запятой, и функция вернёт undefined. if (x = 5) присваивает, а не сравнивает. average без скобок — это сама функция, а не её результат. Регистр важен: name и Name — разные переменные.
