День 4. Переменные

Выжимка лекции: три слова объявления, область видимости, мёртвая зона, шесть ошибок.

Главное

Переменная — имя, за которым закреплено значение. У неё три свойства: имя (как зовут), изменяемость (можно ли положить другое значение) и срок жизни (с какой строки и до какой она существует).
Правило выбора на весь курс: пишем const; если значение надо заменить — меняем на let. var не пишем никогда, но уметь читать обязаны.

Объявление

let score = 42;   // let score — объявление, = 42 — инициализатор
let empty;        // undefined
const total;      // SyntaxError: Missing initializer in const declaration

let a = 1, b = a + 1;   // список: b видит a, b = 2
let x = y = 5;          // ловушка: y стала случайной глобальной

const держит имя, а не содержимое

const city = "Мары";
city = "Ашхабад";       // TypeError: Assignment to constant variable.

const basket = ["хлеб"];
basket.push("чай");     // работает — меняем содержимое, не имя
const user = { n: 1 };
user.n = 2;             // тоже работает
В переменной лежит не объект, а адрес объекта. const запрещает поменять адрес, но не запрещает прийти по нему и переставить вещи внутри.

Где переменная видна

if (true) { let b = 1; var c = 2; }
console.log(b);   // ReferenceError — let не вышла из блока
console.log(c);   // 2 — var не знает про блок

let s = 1;
{ let s = 2; }    // затенение: другая переменная
console.log(s);   // 1

for (const n of [1, 2, 3]) { }   // for...of — const
for (let i = 0; i < 3; i++) { }  // обычный for — let
Видимость идёт только вглубь: изнутри блока видно внешние переменные, снаружи внутренние — нет. Нужно значение после блока — объявите его let до блока, внутри только присваивайте.

Обращение до объявления

console.log(m);  var m = 1;   // undefined — объявление поднято, значение нет
console.log(n);  let n = 1;   // ReferenceError: Cannot access 'n' before initialization

typeof nothingAtAll;          // "undefined" — имени нет вообще, и это не ошибка
{ typeof i; let i = 10; }     // ReferenceError — мёртвая зона

Мёртвая зона длится от открывающей скобки блока до строки объявления.

SyntaxError — не выполнилась ни одна строка, ищите скобку или кавычку. ReferenceError и TypeError — на ходу, значит всё до них отработало. Последние две строки таблицы срабатывают только в строгом режиме.

Необъявленная переменная

let total = 0;
totl = total + 5;     // опечатка: молча создалась глобальная
console.log(total);   // 0, а ждали 5 — и ни одного сообщения
Имена. Регистр важен: userName и username — разные переменные. Пишем латиницей: обычные — camelCase, настройки — MAX_SCORE, «да / нет» — isReady, списки — во множественном числе.
Ловушки. if (true) let a = 1; — SyntaxError, нужны скобки. Лишняя ; после for (...) закрывает цикл. Вложенные /* */ дают загадочное «Invalid regular expression».
  1. Перепишите вчерашний «Табель» по сегодняшним правилам: пороги — именованные константы, verdict объявлен до if. Поменяйте один порог и проверьте, что вывод изменился.
  2. Сломайте программу четырьмя способами из таблицы ошибок и выпишите точный текст каждого сообщения из своей консоли.
  3. Выполните в консоли slucaynaya = 1;, затем globalThis.slucaynaya. Запишите, что получилось, и объясните почему.
  4. Найдите в интернете любой пример кода с var и перепишите его на const и let. Запишите, где понадобился let и почему.
