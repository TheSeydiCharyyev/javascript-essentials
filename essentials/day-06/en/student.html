Day 6. Arithmetic and assignment

A summary of the lecture: five operators, the remainder, assignment, increment, precision.

The main points

An operator is a sign that does something with values (operands). A binary one takes two values (2 + 3), a unary one takes one (-5, i++), a ternary one takes three (day 7).
+ is the only arithmetic operator with double behavior: if at least one operand is a string, it joins. All the others always calculate with numbers.

Five operators

2 + 3;        // 5        addition
"2" + 3;      // "23"     joining!
"10" - 5;     // 5        minus always gives a number
"10" * 2;     // 20
10 / 3;       // 3.3333333333333335
10 / 0;       // Infinity — not an error
10 % 3;       // 1        the remainder, NOT percent
2 ** 10;      // 1024     exponentiation
The order of joining matters: 1 + 2 + "3" gives "33", while "1" + 2 + 3 gives "123". It is calculated from left to right.

The remainder %: four techniques

const n = 7;
const days = ["Mon", "Tue", "Wed"];
let i = 0;
n % 2 === 0;                     // false — parity
1234 % 10;                       // 4 — the last digit
((i - 1) % days.length + days.length) % days.length;   // 2 — backward, without a minus
i = (i + 1) % days.length;       // 1 — a circular counter forward

// time from seconds
const total = 3725;
Math.floor(total / 3600);        // 1 — hours
Math.floor(total / 60) % 60;     // 2 — minutes
total % 60;                      // 5 — seconds
The sign of the remainder comes from the dividend: -10 % 3 is -1, not 2. Division answers “how many whole ones”, the remainder answers “how many are left”.

Exponentiation and unary operators

2 ** 3 ** 2;   // 512 — right to left, this is 2 ** 9
// -2 ** 2;    → SyntaxError — parentheses are needed
(-2) ** 2;     // 4
-(2 ** 2);     // -4

+"42";         // 42  — unary plus = Number()
+"";           // 0
+"abc";        // NaN
const a = "5", b = "3";
+a + +b;       // 8 — two unary pluses, then addition

Assignment

let x;
console.log(x = 5);   // 5 — assignment is an expression
let p, q, r;
p = q = r = 7;        // a chain, right to left
if (x = 0) { }        // A TRAP: assigned, not compared; x is now 0

x += 5;               // 5 — the same with -=, *=, /=, %=, **=

let x2 = 10;
x2 += "5";            // "105" (string!) — += inherits joining

const user = {};
user.name = "Aman";   // you can assign to a property
const marks = [5, 4];
marks[0]++;           // and to an array element: now [6, 4]

Increment

let i = 5;
const a = i++;   // a = 5, i = 6   postfix: gave the old value, then increased
let j = 5;
const b = ++j;   // b = 6, j = 6   prefix: increased, then gave the value
If the result goes nowhere, there is no difference. In for (let i = 0; i < 5; i++) you can write either form. ++ does not work with const and turns the value into a number.

Order and precision

2 + 3 * 4;          // 14 — multiplication first
const m1 = 5, m2 = 4, m3 = 3;
m1 + m2 + m3 / 3;   // 10 — a wrong average!
(m1 + m2 + m3) / 3; // 4 — the right one

0.1 + 0.2;                                      // 0.30000000000000004
(0.1 + 0.2).toFixed(2);                         // "0.30"  — for display
Math.abs((0.1+0.2) - 0.3) < Number.EPSILON;     // true    — for comparison
// for money: keep it in tenge as whole numbers, divide only for output
Common mistakes. "10" + 5 gives "105" — a value from an input field is always a string. % is not percent. (i - 1) % n for going backward gives a minus. if (x = 5) assigns. [object Object] in the output means an object was printed instead of text.

  3. Check -10 % 3, 10 % -3 and the formula ((n % d) + d) % d for the same numbers in the console. Write down the difference.
