День 6. Арифметика и присваивание

Выжимка лекции: пять операторов, остаток, присваивание, инкремент, точность.

Главное

Оператор — знак, который что-то делает со значениями (операндами). Бинарный берёт два значения (2 + 3), унарный одно (-5, i++), тернарный три (день 7).
+ — единственный арифметический оператор с двойным поведением: если хоть один операнд строка, он склеивает. Все остальные всегда считают числами.

Пять операторов

2 + 3;        // 5        сложение
"2" + 3;      // "23"     склейка!
"10" - 5;     // 5        минус всегда число
"10" * 2;     // 20
10 / 3;       // 3.3333333333333335
10 / 0;       // Infinity — не ошибка
10 % 3;       // 1        остаток, НЕ проценты
2 ** 10;      // 1024     степень
Порядок склейки важен: 1 + 2 + "3" даёт "33", а "1" + 2 + 3 даёт "123". Считается слева направо.

Остаток %: четыре приёма

n % 2 === 0;                 // чётность
1234 % 10;                   // 4 — последняя цифра
i = (i + 1) % arr.length;    // круговой счётчик вперёд
((i - 1) % n + n) % n;       // и назад, без минуса

// время из секунд
Math.floor(total / 3600);       // часы
Math.floor(total / 60) % 60;    // минуты
total % 60;                     // секунды
Знак остатка берётся от делимого: -10 % 3 это -1, а не 2. Деление отвечает «сколько целых», остаток — «сколько осталось».

Особые значения

xx + 2x * 2
null, ""20
undefined, NaNNaNNaN
true32
"5""52"10

null тихо считается нулём и даёт неверное число без сообщения — это опаснее, чем NaN.

Степень и унарные

2 ** 3 ** 2;   // 512 — справа налево, это 2 ** 9
-2 ** 2;       // SyntaxError — нужны скобки
(-2) ** 2;     // 4        -(2 ** 2);   // -4

+"42";         // 42  — унарный плюс = Number()
+"";           // 0        +"abc";      // NaN
+a + +b;       // два унарных плюса, потом сложение

Присваивание

let x;
console.log(x = 5);   // 5 — присваивание это выражение
a = b = c = 7;        // цепочка, справа налево
if (x = 0) { }        // ЛОВУШКА: присвоили, а не сравнили

x += 5;  x -= 5;  x *= 2;  x /= 4;  x %= 3;  x **= 2;

let x2 = 10;
x2 += "5";            // "105" (string!) — += наследует склейку

user.name = "Аман";   // присваивать можно свойству
marks[0]++;           // и элементу массива

Инкремент

let i = 5;
const a = i++;   // a = 5, i = 6   постфикс: отдал старое, потом увеличил
let j = 5;
const b = ++j;   // b = 6, j = 6   префикс: увеличил, потом отдал
Если результат никуда не идёт — разницы нет. В for (let i = 0; i < 5; i++) можно писать любую форму. ++ не работает с const и превращает значение в число.

Порядок и точность

2 + 3 * 4;          // 14 — умножение раньше
a + b + c / 3;      // неверное среднее!
(a + b + c) / 3;    // верное

0.1 + 0.2;                                      // 0.30000000000000004
(0.1 + 0.2).toFixed(2);                         // "0.30"  — для показа
Math.abs((0.1+0.2) - 0.3) < Number.EPSILON;     // true    — для сравнения
// для денег: хранить в тенге целыми, делить только при выводе
Частые ошибки. "10" + 5 даёт "105" — значение из поля ввода всегда строка. % — это не проценты. (i - 1) % n для хода назад даёт минус. if (x = 5) присваивает. [object Object] в выводе значит, что вывели объект вместо текста.
  1. Напишите три строки, дающие "105", 15 и 5 из значений "10" и 5. Объясните каждую.
  2. Сделайте функцию formatTime(sec), которая из секунд даёт строку «ч:мм:сс». Проверьте на 65, 600 и 3725.
  3. Проверьте в консоли -10 % 3, 10 % -3 и формулу ((n % d) + d) % d для тех же чисел. Запишите разницу.
  4. Посчитайте итог заказа: цена 1200, 3 штуки, скидка 10%, потом налог 5%. Разбейте на три именованных шага и выведите каждый.
