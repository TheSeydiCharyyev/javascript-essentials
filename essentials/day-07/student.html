День 7. Сравнение и логика

Выжимка лекции: === против ==, порядок, логические операторы, ??, тернарный оператор.

Главное

Сравнения отвечают «да» или «нет». Логические операторы соединяют несколько ответов в один. Вместе они дают программе способность выбирать.
Правило без исключений: пишем только === и !==. Единственное оправданное место для == — проверка value == null, которая ловит сразу null и undefined.

=== против ==

5 === 5;          // true    тип + значение
5 === "5";        // false   разные типы — сразу false
5 == "5";         // true    приводит типы

"0" == 0;         // true   \
"" == 0;          // true    } == нетранзитивно: A=B, B=C, но A≠C
"0" == "";        // false  /

{ } === { };      // false   два разных объекта
[1,2] === [1,2];  // false   и два разных массива
Объекты сравниваются по ссылке, а не по содержимому. Обходной путь — JSON.stringify(a) === JSON.stringify(b), но он зависит от порядка свойств.

Больше и меньше

"10" > 9;      // true    строка стала числом
"10" > "9";    // false   обе строки — посимвольно!
"Z" < "a";     // true    заглавные раньше строчных
"a" > 1;       // false \  строка не стала числом — NaN,
"a" < 1;       // false /  и оба сравнения ложны

null == 0;     // false
null > 0;      // false
null >= 0;     // true  ← противоречие: у == своё правило для null
Строгой версии у < > <= >= нет — типы приводятся всегда. Диапазон пишется только двумя сравнениями: mark >= 2 && mark <= 5. Запись 2 <= mark <= 5 истинна всегда.

Логические операторы

aba && ba || b!a
truetruetruetruefalse
truefalsefalsetruefalse
falsetruefalsetruetrue
falsefalsefalsefalsetrue
 
1 && "салам";      // "салам"  — возвращают ОПЕРАНД, не true
0 && "салам";      // 0
"" || "Гость";     // "Гость"
1 && 2 && 3;       // 3        все истинные → последний
!0;                // true     ! всегда даёт true/false

&& — первое ложное или последнее. || — первое истинное или последнее.

Отрицание меняет союз: !(a && b) это !a || !b, а !(a || b) это !a && !b. Лучше не переворачивать вовсе: дайте условию имя и пишите !canEnter.

Короткое замыкание

false && f();          // f() НЕ вызовется — ответ уже ясен
true || f();           // тоже не вызовется

const name = input || "Гость";   // запасное значение
const title = user && user.name; // защита от null

?? вместо ||

0 || 10;        // 10   ← || срабатывает на всех шести ложных
0 ?? 10;        // 0    ← ?? только на null и undefined
"" || "Гость";  // "Гость"
"" ?? "Гость";  // ""
false ?? 10;    // false

null || undefined ?? "foo";     // SyntaxError
(null || undefined) ?? "foo";   // "foo" — нужны скобки
Вопрос для выбора: ноль и пустая строка — это нормальные данные? Количество, счёт, температура — да, берите ??. Имя, которое не должно быть пустым, — ||.

Тернарный оператор

условие ? значение_если_да : значение_если_нет

const status = age >= 18 ? "взрослый" : "ребёнок";
console.log(`${count} ${count === 1 ? "штука" : "штук"}`);

const grade = score >= 90 ? "5"
  : score >= 75 ? "4"
  : "3";

if — инструкция, значения не возвращает. Тернарный оператор — выражение, результат можно сразу присвоить в const.

Когда что. Результат идёт справа от = или внутрь ${ } — тернарный оператор. Результат никуда не идёт, это просто действия — if...else. Веток больше трёх — if...else if.
Оператор запятая (1, 2, 3) возвращает последнее; живёт практически только в заголовке for: i++, j--.
  1. Выпишите три строки "0" == 0, "" == 0, "0" == "", проверьте в консоли и объясните каждую одним предложением.
  2. Напишите условие «оценка годная»: число от 2 до 5 включительно. Проверьте его на значениях 1, 2, 5, 9 и на строке "4".
  3. Для значений 0, "", null, false сравните, что дают x || "нет" и x ?? "нет". Заполните таблицу 4 × 2.
  4. Перепишите на тернарный оператор: let t; if (n % 2 === 0) { t = "чёт"; } else { t = "нечет"; } — и объясните, почему теперь можно const.
