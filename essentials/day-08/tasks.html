День 8. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–3 делаем в консоли, дальше — в папке day-08.

Разминка

1. Таблица приведения
Легко7 мин

увидеть все три направления на одних и тех же значениях.

Для каждого значения посчитайте String(), Number() и Boolean(). Заполните таблицу 8 × 3.

"0"      " "      ""      [0]      [null]      [1, 2]      null      undefined
Три значения дадут в колонке Number() ноль, хотя выглядят пустыми или непохожими на ноль. Найдите их.
  • таблица заполнена до проверки в консоли;
  • все 24 значения сверены;
  • отмечены все случаи, где Number() дал 0;
  • объяснено, почему Boolean("0") и Boolean([]) истинны.
2. Одно значение, пять контекстов
Легко6 мин

почувствовать, что результат зависит от места, а не от значения.

Возьмите const x = []; и выполните пять строк. Для каждой запишите результат и в какой тип превратился массив.

x ? "истина" : "ложь"
`${x}`
x + 1
x - 1
x == false
  • пять результатов записаны;
  • для каждого указано направление приведения;
  • объяснено, почему x + 1 и x - 1 дали разное.
3. Кто считается первым
Легко7 мин

проверить таблицу приоритетов на практике.

Сначала предскажите, потом проверьте. Для каждой строки запишите порядок шагов.

2 + 3 * 4
(2 + 3) * 4
10 - 5 - 2
2 ** 3 ** 2
1 + 2 === 3 && 2 > 1
true || false && false
  • предсказания записаны до проверки;
  • для каждой строки выписан порядок действий по шагам;
  • найдены две строки, где порядок оказался не слева направо;
  • объяснено, почему последняя строка даёт true.

Основные задания

4. Маршрут сравнения
Средне12 мин

разобрать механизм == до конца.

Для каждой пары распишите маршрут в три строки: какие типы, что во что превратилось, какой итог.

"0" == 0
"" == 0
"0" == ""
true == 1
"1" == true
null == 0
[] == false
для каждой пары: типы → после приведения → результат.
Пара "1" == true проходит два превращения: сначала true становится числом, потом строка. Проследите оба шага.
  • маршрут расписан для всех семи пар;
  • найдена пара, где приведения не было вовсе, и объяснено почему;
  • найдена пара, где превращений было два;
  • записано, что даст === для каждой пары.
5. Проверка на границе
Средне14 мин

написать функцию, после которой в программе ходят только годные данные.

Напишите toMark(input): принимает строку из поля ввода, возвращает число от 2 до 5 или null, если ввод негодный. Проверьте на списке:

"4"      "  5  "      ""      "  "      "пять"      "9"      "3.5"      "4px"
Порядок проверок важен. Пустоту ловите до Number() — иначе пустая строка станет нулём и попадёт в проверку диапазона с неверным сообщением.
  • все восемь значений проверены, ответы записаны;
  • "" и " " дают null;
  • "4px" даёт null — записано, что дал бы parseInt и почему тут он не подходит;
  • записан порядок проверок и объяснено, что сломается при перестановке.

function total(a, b) {
  const sum = a + b;
  console.log("сумма: " + sum);

const price = 3px;
const name = "Аман;
console.log(name);
Первая ошибка, которую покажет браузер, — не первая по счёту в файле. Чините сверху вниз только после того, как поймёте, куда указывает сообщение.
  • найдены все три ошибки, записан порядок, в котором браузер их показывал;
  • для каждой записаны обе строки: указанная и настоящая;
  • отмечено, что у двух ошибок строки совпали, а у одной — нет;

7. «Табель»: чистим ввод
Средне12 мин

применить приведение к настоящим данным из формы.

Скопируйте папку day-07 в day-08. Замените массив оценок на «сырой», как из полей ввода, и разберите его:

const raw = ["5", "4", "", "  3  ", "пять", "9", "5"];

Программа должна собрать два списка: принятые оценки (числами) и отброшенные — с указанием причины для каждой.

  • приняты ровно четыре оценки, все числа, а не строки;
  • у каждой отброшенной записана своя причина: пусто, не число, вне диапазона;
  • " 3 " принимается — объяснено почему;
  • проверено через typeof, что в списке принятых лежат числа;
  • средний балл считается только по принятым.

Заполните таблицу: для каждой строки посчитайте Number(), parseInt() и parseFloat().

"42"      "42px"      "px42"      ""      "  7  "      "3.9"      "1e3"

Затем решите две задачи и объясните выбор функции:

  • таблица 7 × 3 заполнена;
  • найдены все строки, где функции разошлись;
  • для обеих задач выбрана функция и объяснён выбор;

9. Шесть ловушек
Сложно12 мин

собрать вместе всё, что сегодня ведёт себя неожиданно.

Для каждого фрагмента сначала запишите предсказание, потом проверьте и объясните расхождение одним предложением.

// 1
const input = "";
console.log(Number(input), Number.isNaN(Number(input)));

// 2
console.log([5] + 1, [5] - 1);

// 3
const student = { name: "Аман" };
console.log("Студент: " + student);

// 4
console.log(typeof 1 + 1);

// 5
console.log(true || false && false);

// 6
console.log("" == 0, "0" == 0, "0" == "");
Ни один фрагмент не выдаёт ошибку — все шесть тихо возвращают не то, что кажется. Именно поэтому приведение типов и опасно.
  • предсказания записаны до запуска;
  • для каждого названа причина: пустая строка как ноль, ToPrimitive у массива, объект в строковом контексте, приоритет typeof, приоритет &&, маршруты ==;
  • фрагменты 3 и 4 переписаны так, чтобы выводили ожидаемое;
  • для фрагмента 1 написана правильная проверка пустого ввода.
