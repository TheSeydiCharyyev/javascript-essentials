День 9. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–3 делаем в консоли, дальше — в папке day-09.

Разминка

1. Первая развилка
Легко6 мин

написать if и else своими руками.

Для каждой задачи напишите условие из двух веток и проверьте на двух значениях:

  • число чётное или нечётное;
  • строка пустая или нет;
  • возраст 18 и больше или меньше.
Чётность — через остаток из дня 6: n % 2 === 0.
  • три условия написаны, у каждого обе ветки;
  • каждое проверено на двух значениях;
  • везде стоят фигурные скобки;
  • нигде нет точки с запятой после закрывающей скобки.
2. Сначала предскажи: что выполнится
Легко7 мин

поймать ловушку с фигурными скобками и порядком веток.

Предскажите вывод каждого фрагмента, потом проверьте.

// А
const mark = 3;
if (mark === 5)
  console.log("отлично");
  console.log("молодец!");

// Б
const score = 95;
if (score >= 50) {
  console.log("тройка");
} else if (score >= 90) {
  console.log("пятёрка");
}

// В
const list = [];
if (list) {
  console.log("список есть");
}
if (list.length) {
  console.log("в списке что-то есть");
}
  • предсказания записаны до проверки;
  • объяснено, почему во фрагменте А печатается «молодец!»;
  • объяснено, почему во фрагменте Б отличник получил тройку;
  • объяснено, почему во фрагменте В сработала одна строка из двух.
3. Провал в switch
Легко7 мин

увидеть своими глазами, что делает забытый break.

Наберите и запустите. Запишите вывод. Затем добавьте break в каждую ветку и запустите снова.

const action = "draw";

switch (action) {
  case "draw":
    console.log("рисуем");
  case "eat":
    console.log("едим");
  default:
    console.log("ничего");
}
  • записан вывод до и после добавления break;
  • объяснено, почему выполнился default, хотя значение совпало с первым case;
  • записано, что выведет та же программа при action = "eat" без break;
  • своими словами сформулировано, что такое case.

Основные задания

4. Оценка по баллам
Средне12 мин

построить лестницу и проверить её на границах.

Напишите grade(score): 90 и выше — «5», 75 и выше — «4», 50 и выше — «3», иначе «2». Проверьте на девяти значениях — по три вокруг каждой границы:

49  50  51    74  75  76    89  90  91

Затем специально сломайте функцию: поменяйте одно >= на > и найдите, какое из девяти значений изменило ответ.

  • все девять значений дают правильную оценку;
  • лестница закрыта последней веткой — нет undefined;
  • после порчи найдено ровно одно изменившееся значение;
  • записано, почему остальные восемь не изменились.
5. Меню команд
Средне13 мин

применить switch там, где он действительно уместен.

Напишите runCommand(cmd, list), где list — массив задач:

  • "добавить" — добавить задачу, вернуть «добавлено, всего N»;
  • "сколько" — вернуть «задач: N»;
  • "очистить" — опустошить список, вернуть «список очищен»;
  • "помощь" и "?" — одинаковый ответ со списком команд;
  • что угодно другое — «не знаю команду "…"».
Две команды с одинаковым ответом — это группировка case, а не копия кода. Очистить массив можно так: list.length = 0;.
  • все пять вариантов работают;
  • «помощь» и «?» сделаны группировкой, код не продублирован;
  • есть default, и он показывает саму неизвестную команду;
  • проверена последовательность: сколько → добавить → сколько → очистить → сколько.
6. Распутать вложенность
Средне13 мин

превратить лестницу вложенных условий в плоский список правил.

Перепишите эту функцию двумя способами: через объединение условий и через ранний выход. Поведение менять нельзя.

function canEnter(user) {
  if (user !== null) {
    if (user.age >= 18) {
      if (user.ticket !== null) {
        if (!user.banned) {
          return "проходите";
        }
      }
    }
  }
  return "отказ";
}

Проверьте оба варианта на пяти случаях: всё в порядке, ребёнок, без билета, забанен, null.

  • оба варианта написаны и дают одинаковый ответ на всех пяти случаях;
  • в варианте с ранним выходом нет ни одной вложенности;
  • записано, какой вариант вы бы оставили и почему;
  • объяснено, почему user !== null должна проверяться первой.
7. «Табель»: словесные оценки
Средне12 мин

использовать оба инструмента в одной программе по назначению.

Скопируйте папку day-08 в day-09 и доработайте «Табель»:

  • markToWord(mark) через switch: 5 — «отлично», 4 — «хорошо», 3 — «удовлетворительно», 2 — «неудовлетворительно», иначе — «неизвестно»;
  • вердикт по среднему баллу — лестницей else if, четыре ветки;
  • подсчёт пятёрок и двоек через if...else if;
  • вывод каждой оценки словом.
  • все четыре пункта работают;
  • switch использован для конкретных значений, лестница — для диапазонов; записано, почему именно так;
  • вердикт проверен на границах: наборы оценок, дающие ровно 4.5 и ровно 3.5;
  • у markToWord есть default.

Со звёздочкой

8. Дырка между ветками
Сложно10 мин

найти значение, которое не попадает никуда.

В каждой функции есть значение, при котором она возвращает undefined. Найдите его, объясните и почините.

function a(score) {
  if (score > 90) return "5";
  if (score < 90) return "4";
}

function b(mark) {
  if (mark >= 4) return "хорошо";
  else if (mark <= 2) return "плохо";
}

function c(age) {
  if (age > 0 && age < 18) return "ребёнок";
  if (age > 18) return "взрослый";
}
Проверяйте на границах. Для первой функции интересны 89, 90, 91 — но не только они одни во второй и третьей.
  • для каждой функции найдены все проблемные значения;
  • для функции c найдено более одного такого значения;
  • все три починены, проверены на границах;
  • сформулировано правило, как не допускать такие дырки.
9. Пять ловушек
Сложно12 мин

собрать вместе всё, что сегодня ведёт себя неожиданно.

Для каждого фрагмента сначала запишите предсказание, потом проверьте и объясните расхождение одним предложением.

// 1
switch ("5") {
  case 5: console.log("число"); break;
  case "5": console.log("строка"); break;
  default: console.log("ничего");
}

// 2
switch (1) {
  case 1: let a = 1; break;
  case 2: let a = 2; break;
}

// 3
const b = new Boolean(false);
if (b) { console.log("вошли в if"); }
if (b == true) { console.log("вошли в сравнение"); }

// 4
let x = 5;
if (x = 0) { console.log("вошли"); }
console.log(x);

// 5
if ([]) { console.log("пустой массив истинен"); }
if ([] == false) { console.log("и равен false"); }
Один фрагмент вообще не запустится — и сломает весь файл, а не только себя. Найдите его первым и вынесите в отдельный файл, иначе не проверите остальные.
  • предсказания записаны до запуска;
  • найден фрагмент с SyntaxError, записан текст ошибки и причина;
  • для остальных четырёх названа причина: строгое сравнение в switch, объект-обёртка, присваивание вместо сравнения, истинность объектов;
  • фрагменты 2 и 4 переписаны так, чтобы делали то, что от них ожидают;
  • объяснено, почему фрагмент 5 печатает обе строки.
