Day 10. Loops

A summary of the lecture: for, while, do...while, break, continue, labels.

The main points

A loop is a way to write an action once and run it many times. Together with branching, this is enough to express any algorithm.
In for the step runs after the body, and the condition before it. That is why on the first pass the counter equals its start value, and with a false condition the body will not run even once.

Three loops

for (let i = 0; i < 3; i++) { }     // start; condition; step — all in the header

let i = 0;
while (i < 3) { i++; }              // the step is inside the body

let j = 0;
do { j++; } while (j < 3);          // the condition AFTER the body; the semicolon is needed

Forms of the counter

const arr = [5, 4, 3];

for (let i = 0; i < arr.length; i++) { }        // forward
for (let i = arr.length - 1; i >= 0; i--) { }   // backward: -1 and >= 0
for (let i = 0; i < 10; i += 2) { }             // every other one
for (let i = 0, j = 5; i < j; i++, j--) { }     // two counters
i <= arr.length means an extra pass with undefined. Indexes end at length - 1. A backward loop with i > 0 skips the element at index zero.

Five techniques

const marks = [5, 4, 3, 5, 2, 4];
let sum = 0;
let fives = 0;
let max = marks[0];
for (let i = 0; i < marks.length; i++) {
  sum += marks[i];                             // accumulator
  if (marks[i] === 5) { fives++; }             // counter
  if (marks[i] > max) { max = marks[i]; }      // maximum
}
let has = false;
for (let i = 0; i < marks.length; i++) {
  if (marks[i] === 2) { has = true; break; }   // flag: found it — exit
}
[sum, fives, max, has];                        // [23, 2, 5, true]
// building a string is the same accumulator, only with text

On days 19 and 20 all of this will be written shorter — with reduce, filter, includes, join. But inside them are the same loops.

The infinite loop

// do not run these — both loops are infinite:
// while (i < 3) { console.log(i); }       → forgot i++
// for (let i = 0; i !== 10; i += 3) { }   → 0, 3, 6, 9, 12 — past 10
Three checks: does the variable from the condition change, does it change in the right direction, is the stop condition reachable. In conditions write < and >, not !==.
While debugging, add a safety net: guard++; if (guard > 1000) break;

break and continue

for (let i = 0; i < 10; i++) {
  if (i === 3) { break; }         // exit the loop completely
  if (i % 2 === 0) { continue; }  // skip the pass, go to the step
  console.log(i);
}
continue in while before the step = an infinite loop, because the step is in the body and will be skipped. continue gets along with for.

Nested loops and labels

for (let i = 0; i < 3; i++) {
  for (let j = i + 1; j < 3; j++) { }   // j = i + 1 — pairs without repeats
}

outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    break outer;      // exit the OUTER loop
  }
}

The inner loop runs through completely on each step of the outer one. Nested loops multiply the work: 1000 × 1000 is a million passes. The counters must be different.

Three errors of the day. break outside a loop — Illegal break statement. continue outside a loop — Illegal continue statement. A label that does not exist — Undefined label 'x'. All three are syntax errors, which means they switch off the whole file.
Labels are almost never written in real code: more often nested loops are moved into a function and exited with return.
