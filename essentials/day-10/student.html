День 10. Циклы

Выжимка лекции: for, while, do...while, break, continue, метки.

Главное

Цикл — способ написать действие один раз, а выполнить много. Вместе с ветвлением этого достаточно, чтобы выразить любой алгоритм.
В for шаг выполняется после тела, а условие — перед. Поэтому на первом проходе счётчик равен начальному значению, а при ложном условии тело не выполнится ни разу.

Три цикла

for (let i = 0; i < 3; i++) { }     // начало; условие; шаг — всё в заголовке

let i = 0;
while (i < 3) { i++; }              // шаг внутри тела

let j = 0;
do { j++; } while (j < 3);          // условие ПОСЛЕ тела; точка с запятой нужна
СитуацияЦикл
знаем, сколько раз; идём по массивуfor
повторяем, пока условие верноwhile
тело должно выполниться хотя бы разdo...while
нужны только значения, индекс не нуженfor...of — день 11

Формы счётчика

for (let i = 0; i < arr.length; i++) { }        // вперёд
for (let i = arr.length - 1; i >= 0; i--) { }   // назад: -1 и >= 0
for (let i = 0; i < 10; i += 2) { }             // через один
for (let i = 0, j = 5; i < j; i++, j--) { }     // два счётчика
i <= arr.length — лишний проход с undefined. Индексы кончаются на length - 1. Цикл назад с i > 0 пропустит нулевой элемент.

Пять приёмов

let sum = 0;        sum += arr[i];               // накопитель
let n = 0;          if (...) n++;                // счётчик
let max = arr[0];   if (arr[i] > max) max = ...; // максимум (с i = 1)
let has = false;    has = true; break;           // флаг
let line = "";      line += arr[i] + ", ";       // сборка строки

На дне 20 всё это запишется короче — через reduce, filter, includes, join. Но внутри них те же циклы.

Вечный цикл

while (i < 3) { console.log(i); }       // i++ забыли — зависание

for (let i = 0; i !== 10; i += 3) { }   // 0,3,6,9,12 — мимо 10, не остановится
Три проверки: меняется ли переменная из условия, меняется ли в нужную сторону, достижимо ли условие остановки. В условиях пишите < и >, а не !==.
На время отладки ставьте страховку: guard++; if (guard > 1000) break;

break и continue

for (let i = 0; i < 10; i++) {
  if (i === 3) break;      // выйти из цикла совсем
  if (i % 2 === 0) continue;  // пропустить проход, идти к шагу
  console.log(i);
}
continue в while до шага = вечный цикл, потому что шаг лежит в теле и будет пропущен. continue дружит с for.

Вложенные циклы и метки

for (let i = 0; i < 3; i++) {
  for (let j = i + 1; j < 3; j++) { }   // j = i + 1 — пары без повторов
}

outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    break outer;      // выход из ВНЕШНЕГО цикла
  }
}

Внутренний цикл прокручивается целиком на каждый шаг внешнего. Вложенные циклы перемножают работу: 1000 × 1000 — миллион проходов. Счётчики должны быть разными.

Три ошибки дня. break вне цикла — Illegal break statement. continue вне цикла — Illegal continue statement. Несуществующая метка — Undefined label 'x'. Все три синтаксические, а значит отключают весь файл.
Метки в настоящем коде почти не пишут: чаще вложенные циклы выносят в функцию и выходят через return.
  1. Выведите числа от 1 до 20 тремя циклами — for, while и do...while. Результат должен совпасть.
  2. Напишите пять приёмов для массива [5, 4, 3, 5, 2, 4]: сумма, сколько пятёрок, максимум, есть ли двойка, строка через запятую.
  3. Сделайте таблицу умножения от 2 до 5 вложенными циклами, по строке на число.
  4. Напишите цикл while с ошибкой, которая даёт зависание, — но добавьте страховку на 1000 проходов. Запишите, что вывела страховка.
