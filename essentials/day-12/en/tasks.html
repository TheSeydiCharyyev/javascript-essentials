Day 12. Tasks

Lessons 2 and 3, 90 minutes. Warm-up — 20 minutes, main tasks — 50 minutes, starred tasks — 20 minutes. Tasks 1–3 are done in the console, the rest in the folder day-12.

Warm-up

1. Three functions
Easy7 min

write your first functions with your own hands.

Write each one and check it on three different arguments:

  • isEven(n) — whether a number is even;
  • maxOf(a, b) — the bigger of two;
  • greet(name) — returns “Salam, name!”.
  • all three functions work, with three checks each;
  • each one returns a value instead of printing it;
  • the names follow the rules: is for “yes / no”;
  • it is written down what isEven returns without an argument.
2. How many arguments
Easy6 min

see that the language does not check the number of arguments.

For the function add(x, y), make these calls and write down the results:

add(2, 3)
add(2, 3, 4)
add(2)
add()
add("2", "3")
add.length
add.name
  • all seven results are written down;
  • it is explained why add(2) gives NaN, not an error;
  • it is explained where the result of add("2", "3") came from — with a reference to day 6;
  • it is written down what length and name of a function mean.
3. Parentheses and return
Easy7 min

catch the two most common traps.

Predict the output of each fragment, then check.

// A
function double(n) { return n * 2; }
console.log(double);
console.log(double(5));

// B
function getCity() {
  return
    "Mary";
}
console.log(getCity());

// C
function check() {
  console.log("checking");
  return true;
  console.log("and this?");
}
console.log(check());
  • three predictions are written down before the check;
  • it is explained how the two lines in fragment A differ;
  • it is explained why B gives undefined, and the fragment is fixed;
  • it is written down whether it is an error that a line is not printed in fragment C.

Main tasks

4. An early exit
Medium12 min

remove nesting with return.

Rewrite it with an early exit. The behavior must not change.

function describe(score) {
  if (typeof score === "number") {
    if (score >= 0) {
      if (score >= 90) {
        return "excellent";
      } else {
        if (score >= 75) {
          return "good";
        } else {
          return "okay";
        }
      }
    } else {
      return "a score cannot be negative";
    }
  } else {
    return "a number is needed";
  }
}

Check both versions on 95, 80, 50, -1, "a hundred", 0.

  • the rewritten version gives the same answers on all six values;
  • it has no nesting at all;
  • it has no else at all;
  • it is written down how many lines it became instead of how many.
5. Split into functions
Medium14 min

the main skill of the day — dividing a task.

This function does too much. Split it into at least four, so that each one has one job.

function processMarks(marks) {
  const valid = [];
  for (const m of marks) {
    if (m >= 2 && m <= 5) {
      valid.push(m);
    }
  }
  let sum = 0;
  for (const m of valid) {
    sum += m;
  }
  const avg = valid.length === 0 ? 0 : sum / valid.length;
  let v;
  if (avg >= 4.5) { v = "top student"; }
  else if (avg >= 3.5) { v = "good student"; }
  else { v = "needs work"; }
  return `${avg.toFixed(2)} — ${v}`;
}
The names already suggest themselves from the code: pick, add up, evaluate, build a string. Check each new function separately before putting everything together.
  • there are at least four functions;
  • each one has a name without the word “and”;
  • each one is checked with a separate call, and the results are written down;
  • the final function gives the same answer as the original on three sets of marks;
  • an empty array is checked — it should be 0.00, not NaN.
6. A function as a value
Medium12 min

pass a function into a function.

Write applyToAll(numbers, fn): it goes through an array, applies the passed function to each element and returns a new array.

Check it with three different functions: double, square, turn into a string.

applyToAll([1, 2, 3], double);   // [2, 4, 6]
applyToAll([1, 2, 3], square);   // [1, 4, 9]
Inside is an ordinary loop and push. The passed function is called the same way as any other: fn(element).
  • the function works with all three passed functions;
  • the original array did not change — checked by printing it;
  • it is written down what happens if you pass applyToAll([1,2], double()) with parentheses, and why;
  • what a callback is is explained in your own words.
7. The “Report card” from functions
Medium12 min

rebuild the course program on functions.

Copy the folder day-11 to day-12 and rewrite the “Report card” with functions: isValidMark, selectValid, average, verdict, countFives, makeReport.

Then call makeReport for four students:

"Aman",   [5, 4, 9, 3, 5, 0, 4, 5]
"Meret",  [3, 3, 4]
"Gülnar", [9, 0, "five"]
"Sapar",  [5, 5, 4, 5]
  • all six functions are written, each with one job;
  • the four reports are printed correctly;
  • Gülnar’s average is 0.00, not NaN — it is explained which line makes sure of that;
  • it is checked that each branch of verdict worked at least once;
  • each function is also checked with a separate call.

Starred tasks

8. Recursion
Hard10 min

write a function that calls itself.

Write factorial(n) recursively and check it on 0, 1, 5, 10.

Then two experiments:

  • remove the exit condition and run it — write down the text of the error;
  • write the same function with a loop and compare which one is clearer.
The factorial of 0 is 1 — this is a convention of mathematics, and the exit condition must take it into account. Check that your version does not go into infinity on zero.
  • all four values give the right answer, including 0;
  • the exact text of the error without the exit condition is written down;
  • a version with a loop is written, and the results matched;
  • it is written down which version is clearer and why.
9. Six traps
Hard10 min

bring together everything that behaves unexpectedly today.

For each fragment first write down a prediction, then check it and explain the difference in one sentence.

// 1
function f(x, y) { return x - y; }
console.log(f(2, 10));

// 2
function g() { return; 42; }
console.log(g());

// 3
const five = 5;
console.log(five());

// 4
greet("Aman");
function greet(n) { console.log("Salam, " + n); }

// 5
hi("Aman");
const hi = function (n) { console.log("Salam, " + n); };

// 6
function outer() { const x = 1; }
outer();
console.log(x);
Three fragments crash, three do not. Move the crashing ones into separate files, otherwise you will not be able to check the others.
  • the predictions are written down before running;
  • all three crashing fragments are found, and the text of each error is written down;
  • it is explained why 4 works and 5 does not;
  • for fragment 1 it is explained why there is no error although the result is wrong;
  • fragments 1, 2, 5 and 6 are rewritten correctly.
