День 12. Функции

Выжимка лекции: объявление, параметры, return, область видимости, разбиение задачи.

Главное

Функция — кусок программы с именем. Решает три задачи: не повторяться, дать действию имя, разделить задачу на части.
Объявить и вызвать — разные вещи. Работа начинается при вызове, когда после имени стоят круглые скобки. Забытые скобки не падают: вы просто получаете саму функцию вместо результата.

Объявление

function add(x, y) {   // x, y — ПАРАМЕТРЫ (в объявлении)
  return x + y;
}
add(2, 3);             // 2, 3 — АРГУМЕНТЫ (при вызове)

Связь идёт по порядку, а не по именам. Совпадение имён ничего не значит.

Сколько аргументов

add(2, 3);      // 5
add(2, 3, 4);   // 5   лишние молча выброшены
add(2);         // NaN недостающий = undefined
add();          // NaN

add.length;     // 2   сколько параметров объявлено
add.name;       // "add"
Вызов с неверным числом аргументов — не ошибка. Ни предупреждения, ни сообщения, только странный результат позже. Важные функции проверяют аргументы сами и бросают TypeError.
До трёх параметров — список, дальше — один объект: createStudent({ name, age }).

return

function f() { }             // undefined
function f() { return; }     // тоже undefined
function f() { return       // ЛОВУШКА: точка с запятой вставится сама
  42; }                      // вернёт undefined!

// return завершает функцию НЕМЕДЛЕННО — код ниже мёртв
// это не ошибка: Firefox предупредит, Chrome промолчит

Ранний выход

function grade(s) {
  if (s >= 90) return "5";
  if (s >= 75) return "4";
  return "3";
}

else не нужен: если первый return сработал, до второго дело не дойдёт. Читается как список правил.

Область видимости

function f() { const secret = 42; }
f();
console.log(secret);   // ReferenceError

const TAX = 0.05;
function withTax(p) { return p + p * TAX; }   // наружу смотреть можно
Внутрь видно, наружу нет. Всё нужное функция получает через параметры, а не берёт из внешних переменных. Исключение — константы-настройки.

Поднятие

greet();  function greet() { }    // работает — поднимается целиком
hi();     const hi = function(){}; // ReferenceError

Функция — значение

const sum = add;           // в переменную
const ops = [add];         // в массив
marks.map(double);         // аргументом — это КОЛБЭК
button.addEventListener("click", handleClick);    // передали функцию
button.addEventListener("click", handleClick());  // ОШИБКА: вызвали сразу

Рекурсия

function factorial(n) {
  if (n <= 1) return 1;        // условие выхода ОБЯЗАТЕЛЬНО
  return n * factorial(n - 1);
}
// без выхода: RangeError: Maximum call stack size exceeded
Семь ошибок дня. TypeError: x is not a function — самая частая, причин три: опечатка, обращение к несуществующему, имя занято. Смотрите влево от скобок.
Синтаксические (до запуска): параметр не имя, параметры без запятой, функция без имени, нет ) после аргументов. При работе: не функция, слишком глубокая рекурсия.
Код после return — не ошибка, а предупреждение, и только в Firefox.
  1. Напишите isEven(n), maxOf(a, b) и greet(name). Вызовите каждую по три раза с разными аргументами.
  2. Вызовите maxOf(5) и maxOf(5, 3, 1). Запишите, что вернулось и почему ошибки не было.
  3. Перепишите на ранний выход: функция с тремя вложенными if...else, которая по баллам выдаёт оценку.
  4. Разбейте на четыре функции программу, которая по массиву оценок считает средний балл и выдаёт вердикт. Проверьте каждую функцию отдельно.
