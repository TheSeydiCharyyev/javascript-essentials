День 12. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–3 делаем в консоли, дальше — в папке day-12.

Разминка

1. Три функции
Легко7 мин

написать первые функции своими руками.

Напишите и проверьте каждую на трёх разных аргументах:

  • isEven(n) — чётное ли число;
  • maxOf(a, b) — большее из двух;
  • greet(name) — возвращает «Салам, имя!».
  • все три функции работают, по три проверки на каждую;
  • каждая возвращает значение, а не выводит его;
  • имена соответствуют правилам: is для «да / нет»;
  • записано, что вернёт isEven без аргумента.
2. Сколько аргументов
Легко6 мин

увидеть, что язык не проверяет число аргументов.

Для функции add(x, y) вызовите и запишите результат:

add(2, 3)
add(2, 3, 4)
add(2)
add()
add("2", "3")
add.length
add.name
  • все семь результатов записаны;
  • объяснено, почему add(2) даёт NaN, а не ошибку;
  • объяснено, откуда взялся результат add("2", "3") — со ссылкой на день 6;
  • записано, что означают length и name у функции.
3. Скобки и return
Легко7 мин

поймать две самые частые ловушки.

Предскажите вывод каждого фрагмента, потом проверьте.

// А
function double(n) { return n * 2; }
console.log(double);
console.log(double(5));

// Б
function getCity() {
  return
    "Мары";
}
console.log(getCity());

// В
function check() {
  console.log("проверяю");
  return true;
  console.log("а это?");
}
console.log(check());
  • три предсказания записаны до проверки;
  • объяснено, чем отличаются две строки во фрагменте А;
  • объяснено, почему Б даёт undefined, и фрагмент исправлен;
  • записано, является ли ошибкой то, что во фрагменте В строка не печатается.

Основные задания

4. Ранний выход
Средне12 мин

убрать вложенность через return.

Перепишите на ранний выход. Поведение менять нельзя.

function describe(score) {
  if (typeof score === "number") {
    if (score >= 0) {
      if (score >= 90) {
        return "отлично";
      } else {
        if (score >= 75) {
          return "хорошо";
        } else {
          return "нормально";
        }
      }
    } else {
      return "балл не может быть отрицательным";
    }
  } else {
    return "нужно число";
  }
}

Проверьте оба варианта на 95, 80, 50, -1, "сто", 0.

  • переписанная версия даёт те же ответы на всех шести значениях;
  • в ней нет ни одной вложенности;
  • нет ни одного else;
  • записано, сколько строк стало вместо скольких.
5. Разбить на функции
Средне14 мин

главный навык дня — разделить задачу.

Эта функция делает слишком много. Разбейте её минимум на четыре, чтобы у каждой была одна работа.

function processMarks(marks) {
  const valid = [];
  for (const m of marks) {
    if (m >= 2 && m <= 5) {
      valid.push(m);
    }
  }
  let sum = 0;
  for (const m of valid) {
    sum += m;
  }
  const avg = valid.length === 0 ? 0 : sum / valid.length;
  let v;
  if (avg >= 4.5) { v = "отличник"; }
  else if (avg >= 3.5) { v = "хорошист"; }
  else { v = "надо подтянуть"; }
  return `${avg.toFixed(2)} — ${v}`;
}
Названия уже напрашиваются из кода: отобрать, сложить, оценить, собрать строку. Каждую новую функцию проверьте отдельно, прежде чем собирать всё вместе.
  • получилось не меньше четырёх функций;
  • у каждой имя без союза «и»;
  • каждая проверена отдельным вызовом, результаты записаны;
  • итоговая функция даёт тот же ответ, что исходная, на трёх наборах оценок;
  • проверен пустой массив — должно быть 0.00, а не NaN.
6. Функция как значение
Средне12 мин

передавать функцию в функцию.

Напишите applyToAll(numbers, fn): проходит по массиву, применяет к каждому элементу переданную функцию и возвращает новый массив.

Проверьте её тремя разными функциями: удвоить, возвести в квадрат, превратить в строку.

applyToAll([1, 2, 3], double);   // [2, 4, 6]
applyToAll([1, 2, 3], square);   // [1, 4, 9]
Внутри — обычный цикл и push. Переданную функцию вызывают так же, как любую другую: fn(элемент).
  • функция работает со всеми тремя переданными;
  • исходный массив не изменился — проверено выводом;
  • записано, что будет, если передать applyToAll([1,2], double()) со скобками, и почему;
  • объяснено, что такое колбэк, своими словами.
7. «Табель» из функций
Средне12 мин

перестроить программу курса на функции.

Скопируйте папку day-11 в day-12 и перепишите «Табель» на функции: isValidMark, selectValid, average, verdict, countFives, makeReport.

Затем вызовите makeReport для четырёх студентов:

"Аман",   [5, 4, 9, 3, 5, 0, 4, 5]
"Мерет",  [3, 3, 4]
"Гүлнар", [9, 0, "пять"]
"Сапар",  [5, 5, 4, 5]
  • все шесть функций написаны, у каждой одна работа;
  • четыре отчёта выводятся правильно;
  • у Гүлнар средний балл 0.00, а не NaN — объяснено, какая строка это обеспечивает;
  • проверено, что каждая ветка verdict сработала хотя бы раз;
  • каждая функция дополнительно проверена отдельным вызовом.

Со звёздочкой

8. Рекурсия
Сложно10 мин

написать функцию, которая вызывает саму себя.

Напишите factorial(n) рекурсивно и проверьте на 0, 1, 5, 10.

Затем два опыта:

  • уберите условие выхода и запустите — запишите текст ошибки;
  • напишите ту же функцию циклом и сравните, какая понятнее.
Факториал 0 равен 1 — это соглашение математики, и условие выхода должно его учитывать. Проверьте, что ваша версия не уходит в бесконечность на нуле.
  • все четыре значения дают правильный ответ, включая 0;
  • записан точный текст ошибки без условия выхода;
  • написана версия циклом, результаты совпали;
  • записано, какая версия понятнее и почему.
9. Шесть ловушек
Сложно12 мин

собрать вместе всё, что сегодня ведёт себя неожиданно.

Для каждого фрагмента сначала запишите предсказание, потом проверьте и объясните расхождение одним предложением.

// 1
function f(x, y) { return x - y; }
console.log(f(2, 10));

// 2
function g() { return; 42; }
console.log(g());

// 3
const five = 5;
console.log(five());

// 4
greet("Аман");
function greet(n) { console.log("Салам, " + n); }

// 5
hi("Аман");
const hi = function (n) { console.log("Салам, " + n); };

// 6
function outer() { const x = 1; }
outer();
console.log(x);
Три фрагмента падают, три — нет. Падающие вынесите в отдельные файлы, иначе не проверите остальные.
  • предсказания записаны до запуска;
  • найдены все три падающих фрагмента, записан текст каждой ошибки;
  • объяснено, почему 4 работает, а 5 нет;
  • для фрагмента 1 объяснено, почему ошибки нет, хотя результат неверный;
  • фрагменты 1, 2, 5 и 6 переписаны правильно.
