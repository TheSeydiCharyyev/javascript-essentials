День 13. Формы записи функций

Выжимка лекции: объявление, функция-выражение, стрелочная функция.

Главное

Три формы делают одно и то же и вызываются одинаково. Разница — в поднятии, в имени и в трёх мелочах, которых у стрелочных нет.
Вторая и третья формы — не объявление функции, а обычное присваивание. Справа от = стоит значение. Отсюда всё их поведение.

Три формы

function add(a, b) { return a + b; }            // объявление
const add = function (a, b) { return a + b; };  // выражение
const add = (a, b) => a + b;                    // стрелочная

Сокращения стрелочной

n => n * 2          // один простой параметр — скобки можно убрать
(a, b) => a + b     // несколько — скобки обязательны
() => 42            // ноль параметров — скобки обязательны
(n = 1) => n        // значение по умолчанию — скобки обязательны
Есть { после стрелки — должен быть return. Фигурные скобки выключают неявный возврат.
(n) => n * 2 — вернёт 10. (n) => { n * 2; } — вернёт undefined.

Возврат объекта

() => { a: 1 }      // undefined — это БЛОК, a: читается как метка
() => ({ a: 1 })    // правильно — круглые скобки

Поднятие

add(2, 3);  function add(a,b){return a+b}      // работает

add(2, 3);  const add = (a,b) => a + b;
// ReferenceError: Cannot access 'add' before initialization

add(2, 3);  var add = function(a,b){return a+b};
// TypeError: add is not a function ← имя есть, значение undefined

Имена

const myVar = function () { };   // myVar.name === "myVar"
const arrowFn = () => { };       // arrowFn.name === "arrowFn"
const outer = function inner(){}; // outer.name === "inner", снаружи inner нет

Имя видно в стеке вызовов. Анонимная функция прямо на месте покажется как строка без имени — найти её труднее.

Чего у стрелочных нет

const o = { name: "Аман", say: () => this.name };   // не сработает — нет this
const f = () => arguments.length;   // ReferenceError: arguments is not defined
new (() => {})();                   // TypeError: не конструктор
Методом объекта стрелочную не делают. Перенос строки перед => — SyntaxError; после стрелки переносить можно.

IIFE

(function () { /* ... */ })();
(() => { /* ... */ })();

// спрятать данные, оставив доступ:
const counter = (function () {
  let count = 0;
  return { inc: () => ++count, get: () => count };
})();
Выбор. Договорённость курса: function для функций программы, стрелки для колбэков. Главное — не смешивать в одном файле без причины.
Как читать: слева от стрелки — параметры; есть { — ищите return; куда передают — тот и вызовет.
Ловушка передачи: filter(isFive) — передали функцию, filter(isFive()) — вызвали и передали результат.
  1. Запишите функцию «удвоить число» всеми тремя способами и вызовите каждую.
  2. Сократите до предела: const f = function (n) { return n + 1; }; Запишите все промежуточные формы.
  3. Напишите стрелочную функцию, которая коротким телом возвращает объект { name, age }. Сначала без круглых скобок — запишите результат, потом с ними.
  4. Возьмите marks.filter(m => m >= 4).map(m => m * 10) и разверните в девять строк с именованными функциями. Проверьте, что результат тот же.
