День 13. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–3 делаем в консоли, дальше — в папке day-13.

Разминка

1. Одна функция, три формы
Легко6 мин

записать одно и то же тремя способами.

Функция «возвращает квадрат числа». Запишите её:

  • объявлением через function;
  • функцией-выражением;
  • стрелочной, максимально коротко.

Вызовите каждую и выведите .name каждой.

  • все три работают и дают одинаковый результат;
  • в стрелочной нет лишних скобок и return;
  • у второй и третьей в конце стоит точка с запятой — объяснено почему;
  • записаны три значения .name.
2. Сократить до предела
Легко7 мин

пройти все шаги сокращения.

Сократите каждую функцию настолько, насколько позволяет язык. Запишите все промежуточные формы.

const a = function (n) { return n + 1; };
const b = function (x, y) { return x * y; };
const c = function () { return "привет"; };
const d = function (n) { const m = n * 2; return m + 1; };
  • для каждой записаны все промежуточные формы;
  • у b и c скобки остались — объяснено почему;
  • у d блок остался — объяснено почему;
  • все четыре проверены вызовом после сокращения.
3. Сначала предскажи: что вернётся
Легко7 мин

поймать ловушки фигурных скобок.

Предскажите результат каждого вызова, потом проверьте.

const f1 = (n) => n * 2;
const f2 = (n) => { n * 2; };
const f3 = (n) => { return n * 2; };
const f4 = () => { a: 1 };
const f5 = () => ({ a: 1 });

console.log(f1(5), f2(5), f3(5), f4(), f5());
  • пять предсказаний записаны до проверки;
  • объяснено, почему f2 и f4 дают undefined;
  • записано, чем { в f4 отличается от { в f5;
  • сформулировано правило про фигурные скобки одним предложением.

Основные задания

4. Поднятие на практике
Средне12 мин

увидеть три разных исхода при одном и том же коде.

Наберите три файла, в каждом вызов стоит до определения. Запишите, что получилось.

// А
add(2, 3);
function add(a, b) { return a + b; }

// Б
add(2, 3);
const add = (a, b) => a + b;

// В
add(2, 3);
var add = function (a, b) { return a + b; };
  • для всех трёх записан результат или точный текст ошибки;
  • объяснено, почему у Б и В разные виды ошибки;
  • объяснено, почему А работает — со ссылкой на день 4;
  • записано, какой из трёх вариантов вы бы выбрали и почему.
5. Развернуть и свернуть
Средне13 мин

научиться читать плотный код со стрелками.

Разверните эту строку в отдельные именованные функции — так, чтобы результат не изменился:

const result = marks.filter(m => m >= 4).map(m => m * 10);

Затем наоборот: сверните этот код в одну строку со стрелками.

function isLow(m) {
  return m < 3;
}
function toText(m) {
  return "оценка " + m;
}
const low = marks.filter(isLow);
const texts = low.map(toText);
  • обе задачи выполнены, результаты совпали с исходными;
  • проверено на массиве [5, 4, 3, 5, 2], результаты записаны;
  • записано, какая версия каждой задачи читается лучше и почему;
  • объяснено, почему в filter(isLow) нет скобок после имени.
6. Выбрать форму
Средне12 мин

применить правило выбора к настоящим случаям.

Для каждой задачи выберите форму записи и объясните выбор одним предложением. Затем напишите её.

  1. функция calculateTotal, 15 строк, вызывается из четырёх мест;
  2. проверка «оценка больше 3» для передачи в filter;
  3. метод getName объекта student;
  4. обработчик нажатия кнопки, три строки;
  5. функция, которую надо вызвать в начале файла, а написать в конце.
  • для всех пяти выбрана форма и дано объяснение;
  • в пункте 3 выбрана не стрелочная — причина названа;
  • в пункте 5 выбрано объявление — причина названа;
  • все пять написаны и работают.

Со звёздочкой

8. Спрятать счётчик
Сложно10 мин

собрать немедленно вызываемую функцию и понять, зачем она.

Напишите counter через IIFE: переменная счётчика спрятана внутри, а снаружи доступны только inc, dec и get.

counter.inc();
counter.inc();
counter.dec();
counter.get();        // 1
typeof count;         // "undefined" — до переменной не добраться
IIFE возвращает объект с тремя стрелочными функциями. Переменная объявляется внутри функции, до return.
  • все три метода работают;
  • typeof count снаружи даёт "undefined";
  • проверено, что напрямую испортить счётчик нельзя;
  • объяснено, чем это лучше обычной переменной рядом с функциями.
9. Шесть ловушек
Сложно12 мин

собрать вместе всё, что сегодня ведёт себя неожиданно.

Для каждого фрагмента сначала запишите предсказание, потом проверьте и объясните расхождение одним предложением.

// 1
const f = (n) => { n * 2; };
console.log(f(5));

// 2
const g = () => { a: 1 };
console.log(g());

// 3
const h = (a)
  => a + 1;
console.log(h(1));

// 4
const add = n, m => n + m;

// 5
const obj = { name: "Аман", say: () => this.name };
console.log(obj.say());

// 6
const count = () => arguments.length;
console.log(count(1, 2, 3));
Ошибок три, но они разные. Два фрагмента — SyntaxError: они ломают весь файл, вынесите их отдельно. Ещё один падает только при вызове. Оставшиеся три тихо дают не то, что кажется.
  • предсказания записаны до запуска;
  • найдены все три ошибки, записан текст каждой;
  • объяснено, чем два SyntaxError отличаются от третьей ошибки по последствиям;
  • для фрагмента 4 объяснено, почему сообщение говорит не о стрелке;
  • для фрагмента 5 записано, что вывелось у вас в браузере — и отмечено, что результат зависит от среды;
  • для остальных названа причина: скобки выключают возврат, блок вместо объекта, перенос перед стрелкой, нет this, нет arguments;
  • фрагменты 1, 2, 3 и 4 переписаны правильно.
