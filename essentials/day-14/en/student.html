Day 14. Default and rest parameters

A summary of the lecture: how to set a default value and how to take any number of arguments.

The main points

A default is put in when there is no argument. A rest parameter collects all the extra arguments into an array. The first is about “fewer than needed”, the second about “more”.
A default is used only on undefined. Neither null, nor 0, nor "" switches it on.

A default value

function makeGreeting(name, greeting = "Salam") {
  return greeting + ", " + name + "!";
}

makeGreeting("Aman");                 // "Salam, Aman!"
makeGreeting("Aman", "Hoş geldiň");   // "Hoş geldiň, Aman!"
What was passedWhat the parameter gets
nothing or undefinedthe value from the header
nullnull
0, "", false, NaNwhat was passed
The old trick num = num || 1 breaks on zero and an empty string. The ?? operator works correctly, but a default in the header is better: it shows right away that the parameter is optional.

A default is an expression

function calc(n, m = double(n)) { }   // you can call a function
function greet(name, g, msg = g + " " + name) { }   // what is to the LEFT is visible
function bad(a = b, b = 2) { }        // ReferenceError when bad() is called

It is evaluated anew at every call — and only if it is needed:

function addMark(mark, marks = []) { marks.push(mark); return marks; }
addMark(5);   // [5]
addMark(4);   // [4], not [5, 4] — a new array every time
Parameters with defaults are put at the end of the list. Otherwise the next ones cannot be reached — you will have to write f(undefined, 7).

The rest parameter

function showArgs(first, second, ...others) {
  console.log(first, second, others);
}

showArgs("bir", "iki", "üç", "dört");  // bir iki ["üç", "dört"]
showArgs("bir", "iki");                // bir iki []
showArgs("bir");                       // bir undefined []

A rest parameter is always an array, even an empty one. Three rules: it is the last one, there is only one, it never has a default. A comma after it is an error too.

// function f(...rest = []) { }       → SyntaxError: Rest parameter may not have a default initializer

function sum(x, y = 1) { }      // different names
function f(arg) { arg = 1; }    // assigning is allowed, declaring again is not
function g(last, ...rest) { }   // the rest parameter goes last
function h(...rest) { }         // no default: it is [] anyway
