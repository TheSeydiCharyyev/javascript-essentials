День 14. Параметры по умолчанию и остаточные

Выжимка лекции: как задать значение по умолчанию и как принять сколько угодно аргументов.

Главное

Умолчание подставляется, когда аргумента нет. Остаточный параметр собирает все лишние аргументы в массив. Первое — про «меньше, чем нужно», второе — про «больше».
Умолчание срабатывает только на undefined. Ни null, ни 0, ни "" его не включают.

Значение по умолчанию

function makeGreeting(name, greeting = "Salam") {
  return greeting + ", " + name + "!";
}

makeGreeting("Аман");                 // "Salam, Аман!"
makeGreeting("Аман", "Hoş geldiň");   // "Hoş geldiň, Аман!"

Старый приём num = num || 1 ломается на нуле и пустой строке. Оператор ?? работает правильно, но умолчание в заголовке лучше: по нему сразу видно, что параметр необязательный.

Умолчание — это выражение

function calc(n, m = double(n)) { }   // можно вызвать функцию
function greet(name, g, msg = g + " " + name) { }   // видно то, что ЛЕВЕЕ
function bad(a = b, b = 2) { }        // ReferenceError при вызове bad()

Вычисляется при каждом вызове заново — и только если понадобилось:

function addMark(mark, marks = []) { marks.push(mark); return marks; }
addMark(5);   // [5]
addMark(4);   // [4], а не [5, 4] — каждый раз новый массив
Параметры с умолчаниями ставят в конец списка. Иначе до следующих не добраться — придётся писать f(undefined, 7).

Остаточный параметр

function showArgs(first, second, ...others) { }

showArgs("бир", "ики", "уч", "дёрт");  // others = ["уч", "дёрт"]
showArgs("бир", "ики");                // others = []
showArgs("бир");                       // second = undefined, others = []

Остаточный параметр — всегда массив, даже пустой. Три правила: он последний, он один, умолчания у него не бывает. Запятая после него — тоже ошибка.

Четыре ошибки

function add(x, x) { }            // в обычном режиме МОЖНО (старый код)
function add(x, x = 1) { }
// SyntaxError: Duplicate parameter name not allowed in this context

function f(arg) { let arg = 1; }
// SyntaxError: Identifier 'arg' has already been declared

function f(...rest, last) { }
// SyntaxError: Rest parameter must be last formal parameter

function f(...rest = []) { }
// SyntaxError: Rest parameter may not have a default initializer
Тексты MDN другие — они по формулировкам Firefox. Искать в интернете надо по тексту своего браузера.
Скобки у стрелочной: (n = 1) => n — с умолчанием скобки обязательны.
f.length — число параметров до первого умолчания; остаточный не считается.
  1. Напишите makeGreeting(name, greeting = "Salam") и вызовите её пять раз: без второго аргумента, с undefined, с null, с 0 и с обычной строкой. Запишите все пять результатов.
  2. Напишите sumAll(...numbers), которая складывает любое число аргументов. Проверьте на трёх, на одном и на нуле аргументов.
  3. Возьмите function addMark(mark, marks = []) { marks.push(mark); return marks; } и объясните письменно, почему два вызова addMark(5) и addMark(4) не накапливают оценки.
  4. Наберите все четыре ошибки из конспекта по одной в отдельном файле и запишите точный текст каждой из своей консоли.
