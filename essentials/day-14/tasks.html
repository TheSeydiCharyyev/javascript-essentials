День 14. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Задания 1–3 делаем в консоли, дальше — в папке day-14.

Разминка

1. Пять аргументов, одно умолчание
Легко6 мин

увидеть своими глазами, что умолчание реагирует только на undefined.

Напишите функцию и вызовите её пять раз, записав каждый результат:

function makeGreeting(name, greeting = "Salam") {
  return greeting + ", " + name + "!";
}

makeGreeting("Аман");
makeGreeting("Аман", undefined);
makeGreeting("Аман", null);
makeGreeting("Аман", 0);
makeGreeting("Аман", "Hoş geldiň");
Два вызова дадут одинаковый результат — найдите какие. Остальные три покажут то, что передали, без всякой подстановки.
  • записаны все пять результатов;
  • названы два вызова, которые дали одно и то же, и объяснено почему;
  • объяснено, почему null и 0 умолчание не включили;
  • сформулировано правило одним предложением.
2. Сначала предскажи: сработает или нет
Легко7 мин

отличить умолчание от старого приёма с ||.

Предскажите результат каждого вызова, потом проверьте.

function a(num = 10) { return num; }
function b(num) { num = num || 10; return num; }
function c(num) { num = num ?? 10; return num; }

console.log(a(), a(0), a(null));
console.log(b(), b(0), b(null));
console.log(c(), c(0), c(null));
Девять значений. Различия появятся только в столбцах 0 и null — первый столбец у всех трёх одинаковый.
  • девять предсказаний записаны до проверки;
  • найдено, где b расходится с a, и названа причина;
  • найдено, где c расходится с a, и названа причина;
  • записано, какую из трёх функций вы бы написали в своём коде и почему.
3. Сложить что угодно
Легко7 мин

написать первую функцию с остаточным параметром.

Напишите sumAll, которая складывает любое число аргументов. Проверьте на трёх, на одном и на нуле аргументов. Потом выведите typeof остаточного параметра и Array.isArray от него.

Внутри функции это обычный массив — перебирайте его for...of из дня 11. Начальное значение суммы — ноль, тогда вызов без аргументов тоже отработает.
  • sumAll(5, 4, 5), sumAll(5) и sumAll() дают 14, 5 и 0;
  • записано, что показали typeof и Array.isArray;
  • объяснено, почему вызов без аргументов не даёт ошибку;
  • то же самое написано ещё раз стрелочной функцией.

Основные задания

4. Неудобный порядок
Средне12 мин

понять на своей ошибке, почему необязательные параметры ставят в конец.

Наберите функцию, у которой умолчание стоит первым, и попробуйте ею воспользоваться:

function report(greeting = "Salam", name) {
  return greeting + ", " + name;
}

report("Аман");   // хотели «Salam, Аман»

Получилось не то. Добейтесь нужного результата, не меняя объявление. Потом перепишите функцию правильно и покажите, что она удобнее.

Аргументы раскладываются по местам, а не по именам: «Аман» попал в первое место. Чтобы сказать «для первого возьми своё», есть ровно одно значение — оно из раздела 3 лекции.
  • записано, что вернул report("Аман") и почему;
  • найден вызов, который даёт «Salam, Аман» без правки объявления;
  • функция переписана с умолчанием в конце, показаны два вызова;
  • объяснено в одном предложении, чем второй вариант лучше.
5. Переписать старый код
Средне12 мин

заменить arguments остаточным параметром.

Вот функция, написанная до 2015 года. Она склеивает все аргументы через пробел:

function oldJoin() {
  const parts = Array.prototype.slice.call(arguments);   // курс 2
  let out = "";
  for (const p of parts) {
    out += p + " ";
  }
  return out;
}

Перепишите её на остаточный параметр так, чтобы результат совпал до символа. Затем ответьте на вопрос: что изменится, если у функции появится первый обязательный параметр title?

Строка со slice.call нужна была только ради превращения arguments в массив — с остаточным параметром она не нужна совсем. Для второго вопроса сравните arguments.length и длину остаточного.
  • новая версия короче и даёт тот же результат на ("бир", "ики");
  • результаты обеих версий сравнены, совпадение проверено;
  • объяснено, почему со старой версией title попал бы в вывод, а с новой — нет;
  • записано, почему в стрелочной функции старую версию повторить нельзя.
6. Умолчание, которое работает
Средне13 мин

убедиться, что умолчание — это код, а не значение.

Три опыта подряд, для каждого запишите вывод и объяснение.

  1. Счётчик вызовов: 
    let calls = 0;
function next() { calls = calls + 1; return calls; }
function withCall(n = next()) { return n; }
    Вызовите withCall() дважды, потом withCall(100). После каждого вызова печатайте calls.
  2. Новый массив каждый раз: function addMark(mark, marks = []) { marks.push(mark); return marks; }. Вызовите дважды без второго аргумента, потом дважды с одним и тем же массивом.
  3. Обязательный аргумент: напишите required(name), которая бросает TypeError, и функцию с параметром name = required("name").
В первом опыте важно печатать calls после каждого вызова, иначе разницы не увидеть. В третьем вспомните throw из дня 11.
  • для опыта 1 записано значение calls после каждого из трёх вызовов и объяснено, почему третий его не изменил;
  • для опыта 2 показано, что два вызова подряд не накапливают оценки, а с общим массивом — накапливают;
  • для опыта 3 функция падает без аргумента и работает с аргументом;
  • проверено, что вызов с undefined тоже вызывает ошибку, и объяснено почему.
7. «Табель»: оценки россыпью
Средне13 мин

перевести программу курса на новый способ передачи данных.

Скопируйте папку day-13 в day-14 и перепишите:

  • makeReport принимает оценки остаточным параметром, а имя получает умолчание "без имени";
  • verdict получает три необязательных порога: excellent = 4.5, good = 3.5, pass = 2.5;
  • вызовы makeReport переписаны без квадратных скобок.

Добавьте пятый вызов — makeReport() вообще без аргументов.

Тела isValidMark, sum, average и makeReport менять не нужно — только списки параметров и вызовы. Если первые четыре отчёта изменились, значит, что-то поехало.
  • первые четыре отчёта совпадают со вчерашними — сверено построчно;
  • пятый вызов даёт «без имени: 0 из 0…» и не падает;
  • показано, что verdict(4.6) и verdict(4.6, 4.8) дают разные слова;
  • объяснено, почему внутри makeReport вызов verdict(avg) менять не пришлось.

Со звёздочкой

8. Четыре ошибки и одно исключение
Сложно10 мин

получить все четыре ошибки дня своими руками и найти ту, что ведёт себя по-разному.

Каждый фрагмент — в отдельный файл: это SyntaxError, они ломают весь файл целиком. Запишите точный текст каждой ошибки из своей консоли.

// 1
function add(x, x) { return x; }
console.log(add(1, 2));

// 2
function add(x, x = 1) { return x; }

// 3
function f(arg) { let arg = "foo"; }

// 4
function replacer(match, ...groups, offset) { }

// 5
function doSomething(...args = []) { }

Фрагментов пять, а ошибок четыре. Разберитесь, что происходит с первым.

Первый фрагмент — единственный, который зависит от режима. Попробуйте добавить в начало файла строку "use strict"; и запустить снова. Сравните с фрагментом 2 и сделайте вывод.
  • записан точный текст четырёх ошибок из своей консоли;
  • для фрагмента 1 записано, что он вывел без строгого режима и что — с ним;
  • объяснено, чем фрагмент 2 отличается от фрагмента 1, из-за чего появляется ошибка;
  • тексты сверены с заголовками страниц MDN из справочника дня и отмечено, что они не совпадают;
  • все пять фрагментов переписаны правильно.
9. Универсальный список
Сложно12 мин

собрать функцию, где работают обе сегодняшние темы сразу.

Напишите makeList, которая печатает нумерованный список:

makeList("Оценки", 5, 4, 5);   // "Оценки: 1) 5 2) 4 3) 5"
makeList("Оценки");            // "Оценки: пусто"
makeList();                    // "Список: пусто"
makeList(undefined, "бир");    // "Список: 1) бир"

Заголовок необязателен и по умолчанию равен "Список", элементов может быть сколько угодно.

Порядок параметров задан примерами: сначала заголовок с умолчанием, потом остаточный. Номер ведите отдельной переменной — она увеличивается на каждом шаге for...of. Случай «элементов нет» проверьте до цикла.
  • все четыре вызова из примера дают ровно то, что написано;
  • при нуле элементов цикл не выполняется ни разу;
  • объяснено, почему makeList(undefined, "бир") печатает «Список», а не «undefined»;
  • проверено, что makeList("Оценки", [5, 4]) даёт один элемент, и объяснено почему;
  • добавлен необязательный параметр-разделитель между заголовком и остаточным — и показано, как его пропустить.
