Day 16. Strings and their methods

A summary of the lecture: find, cut, adjust, build.

The main points

A string cannot be changed. Any method returns a new string, and the old one stays the same. 
let text = "  Aman  ";
text.trim();          // the result is lost: text is still "  Aman  "
text = text.trim();   // this is the right way
In normal mode name[0] = "A" silently does not work; in strict mode it gives TypeError: Cannot assign to read only property.

Since every method returns a string, you can call the next one on the result right away — you get a chain. The order of the steps in it matters:

"  AmAn  ".trim().toLowerCase();   // "aman"
"  Aman  ".slice(0, 4);            // "  Am" — cut together with the spaces
"  Aman  ".trim().slice(0, 4);     // "Aman"

Length and characters

const name = "Gülnar";
name.length;                             // 6, the last index is 5
name[0];  name.charAt(0);  name.at(0);   // "G"
name.at(-1);                             // "r" — only at understands negative ones

Search

const group = "Aman Meret Aman";
group.indexOf("Aman");       // 0 — a position or -1
group.lastIndexOf("Aman");   // 11 — from the end
group.includes("Meret");     // true / false
group.startsWith("Aman");  group.endsWith("Aman");   // true
if (text.indexOf("Aman")) is a mistake: zero means “found at the start”, but in a condition it is falsy. Write !== -1 or includes.
All four methods are case-sensitive.

Cutting

"Turkmenistan".slice(0, 4);   // "Turk" — the second boundary is NOT included
"Turkmenistan".slice(4);      // "menistan"
"Turkmenistan".slice(-6);     // "nistan"
"Turkmenistan".slice(4, 2);   // "" — boundaries the other way around

Adjusting and building

"Aman".toUpperCase();   // "AMAN"
"AMAN".toLowerCase();   // "aman"

const a = "  AmAn ";
const b = "aman";
a.trim().toLowerCase() === b.trim().toLowerCase();   // true — a human-like comparison

"   Aman   ".trim();        // "Aman" — only the edges
"   Aman   ".trimStart();   // "Aman   "
"   Aman   ".trimEnd();     // "   Aman"

"5".padStart(3, "0");         // "005" — 3 is the LENGTH OF THE RESULT, not an addition
"Aman".padEnd(10, ".");       // "Aman......"
String(5).padStart(2, "0");   // "05" — a number has no string methods
"-".repeat(40);               // a line

const student = "Aman";
const avg = 4.333;
`${student}: average ${avg.toFixed(2)}`;   // "Aman: average 4.33"
`a line break
right inside the text`;
padEnd is for text (a column on the left), padStart is for numbers (aligned to the right). The width is taken from the longest value, otherwise the table falls apart.

Codes and conversions

"Aman".charCodeAt(0);        // 65
"🙂".charCodeAt(0);          // 55357 — half of the icon
"🙂".codePointAt(0);         // 128578 — the whole icon
String.fromCharCode(65);     // "A"

String(5);                   // "5"
String(null);                // "null" — works with anything
(5).toString(2);             // "101" — the numeral system
Three errors of the day, all RangeError: "abc".repeat(-1) → Invalid count value: -1; "abc".repeat(1e10) → Invalid string length; String.fromCodePoint(-1) → Invalid code point -1. On MDN they are titled with the Firefox wordings.
Not today: split, replace, match — they come with regular expressions in course 2.
