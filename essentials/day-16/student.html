День 16. Строки и их методы

Выжимка лекции: найти, отрезать, поправить, собрать.

Главное

Строку изменить нельзя. Любой метод возвращает новую строку, а старая остаётся прежней. 
text.trim();          // результат пропал
text = text.trim();   // вот так правильно
В обычном режиме name[0] = "А" молча не срабатывает, в строгом — TypeError: Cannot assign to read only property.

Раз каждый метод возвращает строку, у результата сразу можно вызвать следующий — получается цепочка. Порядок шагов в ней важен:

"  АмАн  ".trim().toLowerCase();   // "аман"
"  Аман  ".slice(0, 4);            // "  Ам" — резали вместе с пробелами
"  Аман  ".trim().slice(0, 4);     // "Аман"

Поиск

text.indexOf("Аман")        // позиция или -1
text.lastIndexOf("Аман")    // с конца
text.includes("Мерет")      // true / false
text.startsWith("Аман")   text.endsWith("Аман")
if (text.indexOf("Аман")) — ошибка: ноль означает «нашёл в начале», но в условии это ложь. Писать !== -1 или includes.
Все четыре метода различают регистр.

Отрезаем

"Туркменистан".slice(-6)     // "нистан"
"Туркменистан".slice(4, 2)   // "" — границы наоборот

Правим и собираем

"Аман".toUpperCase()   "АМАН".toLowerCase()
a.trim().toLowerCase() === b.trim().toLowerCase()   // сравнение по-человечески

"   Аман   ".trim()   .trimStart()   .trimEnd()     // только края

"5".padStart(3, "0")      // "005" — 3 это ДЛИНА РЕЗУЛЬТАТА, не добавка
"Аман".padEnd(10, ".")    // "Аман......"
String(5).padStart(2, "0")  // у числа методов строки нет
"-".repeat(40)            // линия

padEnd — для текста (колонка слева), padStart — для чисел (выравнивание вправо). Ширину берут по самому длинному значению, иначе таблица разъедется.

Коды и превращения

"Аман".charCodeAt(0)      // 1040
"🙂".charCodeAt(0)        // 55357 — половина значка
"🙂".codePointAt(0)       // 128578 — значок целиком
String.fromCharCode(1040) // "А"

String(5)  String(null)   // работает с чем угодно
(5).toString(2)           // "101" — система счисления
Три ошибки дня, все RangeError: "abc".repeat(-1) → Invalid count value: -1; "abc".repeat(1e10) → Invalid string length; String.fromCodePoint(-1) → Invalid code point -1. На MDN они озаглавлены по формулировкам Firefox.
