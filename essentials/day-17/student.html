День 17. Числа и первые даты

Выжимка лекции: превратить в число, проверить, округлить, поставить дату.

Из строки в число

Number() строгий — либо вся строка число, либо NaN. parseInt и parseFloat читают слева, сколько получится.
СтрокаNumberparseIntparseFloat
"4.5"4.544.5
"42px"NaN4242
"px42"NaNNaNNaN
""0NaNNaN
Для данных из формы берём Number(): он честно сообщает о мусоре вместо того, чтобы молча прочитать половину. 
parseInt("1010", 2)   // 10  — основание указывать явно
parseInt(day, 10)     // так пишут в надёжном коде

Проверки

Number.isNaN("abc")    // false — честная проверка
isNaN("abc")           // true  — старая, сначала превращает в число
Number.isFinite("42")  // false;  isFinite("42") → true
Number.isInteger(4)    // лучшая проверка «пришло целое число»
x === NaN              // ВСЕГДА false — так не проверяют
В новом коде — только те проверки, что с приставкой Number. Старые isNaN и isFinite втихую преобразуют аргумент.

Округление

(4.333).toFixed(2)   // "4.33" — это СТРОКА, не число
(7).toFixed(2)       // "7.00"
(1.005).toFixed(2)   // "1.00" — а не "1.01"

0.1 + 0.2            // 0.30000000000000004
0.1 + 0.2 === 0.3    // false
Math.abs(0.1 + 0.2 - 0.3) < Number.EPSILON   // true

Дроби хранятся приблизительно — это свойство двоичной записи, а не языка. Поэтому деньги и оценки держат в целых, а дробь показывают только при выводе.

Константы и системы счисления

Number.MAX_SAFE_INTEGER   // 9007199254740991 — граница точных целых
Number.EPSILON            // порог для сравнения дробей

(255).toString(16)   // "ff"
(255).toString(1)    // RangeError: toString() radix argument must be between 2 and 36
parseInt("ff", 16)   // 255

Даты

Дата внутри — одно число: миллисекунды с 1 января 1970 года. Поэтому даты можно вычитать. 
Date.now()                     // сейчас, число
const d = new Date(2026, 8, 22, 14, 5);   // 22 сентября 2026, 14:05

d.getFullYear()   // 2026
d.getMonth()      // 8  — СЕНТЯБРЬ, месяцы с нуля!
d.getDate()       // 22
d.getHours()      // 14
d.getMinutes()    // 5

(end.getTime() - start.getTime()) / (1000 * 60 * 60 * 24)   // разница в днях
Месяцы нумеруются с нуля, а дни — с единицы. Январь — 0, сентябрь — 8, декабрь — 11. Месяц 12 переедет в следующий год. 
d.toLocaleDateString("ru-RU")   // "22.09.2026"
d.toLocaleTimeString("ru-RU")   // "14:05:00"

const bad = new Date("не дата");
String(bad)                     // "Invalid Date"
bad.getTime()                   // NaN
!Number.isNaN(bad.getTime())    // так проверяют дату
Три ошибки дня, все RangeError: основание вне 2…36, слишком много знаков в toFixed, toISOString от неверной даты (Invalid time value).
