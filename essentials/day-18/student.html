День 18. Math и случайные числа

Выжимка лекции: округлить, найти крайнее, бросить кубик.

Главное

Math — не тип значения, а коробка с функциями и константами. Его не создают через new, всё вызывается от слова Math.
Math.round(x) даёт число для вычислений, x.toFixed(2) — строку для показа. Путать их — частая ошибка в отчётах.

Четыре округления

Math.round(4.5)   // 5   к ближайшему, половина ВВЕРХ
Math.floor(4.9)   // 4   всегда вниз
Math.ceil(4.1)    // 5   всегда вверх
Math.trunc(4.9)   // 4   отбросить дробную часть
Числоroundfloorceiltrunc
4.55454
−4.1−4−5−4−4
−4.5−4−5−4−4
На минусах floor и trunc расходятся: «вниз» — это дальше от нуля, «отбросить» — к нулю. И Math.round(-4.5) даёт −4: половина идёт вверх по прямой, а не дальше от нуля.

Любой шаг округления

Math.round(price / 10) * 10     // до десятков
Math.round(price / 100) * 100   // до сотен
Math.floor(price / 5) * 5       // вниз до кратного пяти
Math.round(x * 100) / 100       // до сотых — ЧИСЛОМ, не строкой

Крайние и степени

Math.abs(-5)     // 5        Math.sign(-5)    // -1
Math.sqrt(144)   // 12       Math.pow(2, 10) === 2 ** 10
Math.hypot(3, 4) // 5        Math.cbrt(27)    // 3

Math.max(3, 7, 5)    // 7
Math.max()           // -Infinity !
Math.max(3, NaN, 5)  // NaN !
Math.max(marks)      // NaN — массив это ОДИН аргумент
const maxOf = (numbers) => {
  let best = numbers[0];
  for (const n of numbers) { best = Math.max(best, n); }
  return best;
};

Случайные числа

Math.random() даёт дробное число от нуля включительно до единицы не включая. Единица не выпадает никогда — на этом и построена формула. 
function randomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}

randomInt(1, 6);   // бросок кубика
Math.round(Math.random() * 6) — ошибка. Исходов семь, и края выпадают вдвое реже: примерно по 5000 против 10000 на 60 000 бросков. Программа при этом работает, ошибку видно только счётчиком.
Забыть + 1 в (max - min + 1) — значит никогда не получить максимум.

Константы и углы

Math.PI   Math.E   Math.SQRT2   Math.LN2   // без скобок

const area = Math.PI * radius ** 2;

Math.sin(90 * Math.PI / 180);   // 1 — аргумент в РАДИАНАХ
Math.sin(90);                   // 0.894 — это синус 90 радиан
Тригонометрия и логарифмы — 33 страницы справочника, даны одной таблицей: разбирают их тогда, когда задача до них доходит. Из логарифмов чаще других нужен Math.log2 — «сколько раз поделить пополам».
Math.sumPrecise решает вчерашнюю задачу точной суммы, но он настолько новый, что в Node 22 его нет вовсе. Перед использованием — typeof Math.sumPrecise.
