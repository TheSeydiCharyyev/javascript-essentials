Day 19. Arrays

A summary of the lecture: creation, access, adding and removing, search.

The main points

An array is a list of values with an order. The number of an element is called an index and starts from zero. The length is length, the index of the last one is length - 1.
Methods fall into two groups: some change the source array, others return a new value. This is the main thing to remember from this day.

Creation

const marks = [5, 4, 5];        // a literal — the usual way
const empty = [];               // empty, we will fill it later
Array.of(7);                    // [7]
Array.from("Mary");             // ["M", "a", "r", "y"]
new Array(7);                   // an empty array of length 7 — we do not write this

Access

const a = ["x", "y", "z"];
a[0];           // "x"
a.at(-1);       // "z" — the last
a.length;       // 3
a[1] = "Y";     // replacing by index

slice and splice

const l = ["a", "b", "c", "d"];
l.slice(1, 3);        // ["b", "c"] — a copy, the original is intact
l.splice(1, 2, "X");  // the original became ["a", "X", "d"]
slice — cut a copy for yourself. splice — cut out of the original.

Stack and queue

A stack is “last in, first out”: push + pop, like the “Undo” button. A queue is “first in, first out”: push + shift, like a line at a checkout. Working with the start (unshift, shift) on long arrays is hundreds of times slower than with the end.

Search and joining

const m = [5, 4, 5];
m.indexOf(5);       // 0
m.lastIndexOf(5);   // 2
m.indexOf(9);       // -1 — not found
m.includes(4);      // true

["Aman", "Meret"].join(", ");   // "Aman, Meret"
[1, 2].concat([3]);             // [1, 2, 3] — a new array
Array.isArray([1]);             // true (typeof is useless here)

[5, 4, 3].with(1, 5);           // [5, 5, 3] — a copy with a replacement
[5, 4, 3].toSpliced(1, 1);      // [5, 3] — a copy without an element

Holes and an empty array

const h = [1, , 3];         // a hole — there is no element at all
h[1];                       // undefined
h.includes(undefined);      // true
h.indexOf(undefined);       // -1 — indexOf skips holes

[].pop();                   // undefined — no error
[].indexOf(1);              // -1

Methods on an empty array throw no errors, so the error shows up further on: [].pop().toUpperCase() gives a TypeError. If an array may be empty, check length beforehand.

Two groups of methods

Change the arrayReturn something new
push, pop, shift, unshift, splice, reverse, fill, copyWithin slice, concat, join, at, includes, indexOf, with, toReversed, toSpliced
Common mistakes. if (arr.indexOf(x)) is wrong if the element is the first one: index 0 means “no”. new Array(7) is not [7] but seven empty slots. arr.push(...) returns the length, not the array.
