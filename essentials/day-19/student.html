День 19. Массивы

Выжимка лекции: создание, доступ, добавление и удаление, поиск.

Главное

Массив — список значений с порядком. Номер элемента называется индексом и начинается с нуля. Длина — length, индекс последнего — length - 1.
Методы делятся на две группы: одни меняют исходный массив, другие возвращают новое значение. Это главное, что нужно запомнить с этого дня.

Создание

const marks = [5, 4, 5];        // литерал — обычный способ
const empty = [];               // пустой, заполним позже
Array.of(7);                    // [7]
Array.from("Мары");             // ["М", "а", "р", "ы"]
new Array(7);                   // пустой массив длиной 7 — так не пишем

Доступ

const a = ["x", "y", "z"];
a[0];           // "x"
a.at(-1);       // "z" — последний
a.length;       // 3
a[1] = "Y";     // замена по индексу

slice и splice

const l = ["a", "b", "c", "d"];
l.slice(1, 3);        // ["b", "c"] — копия, оригинал цел
l.splice(1, 2, "X");  // оригинал стал ["a", "X", "d"]
slice — отрезать себе копию. splice — вырезать из оригинала.

Поиск и склейка

const m = [5, 4, 5];
m.indexOf(5);       // 0
m.lastIndexOf(5);   // 2
m.indexOf(9);       // -1 — не найдено
m.includes(4);      // true

["Аман", "Мерет"].join(", ");   // "Аман, Мерет"
[1, 2].concat([3]);             // [1, 2, 3] — новый массив
Array.isArray([1]);             // true (typeof тут бесполезен)

Две группы методов

Меняют массивВозвращают новое
push, pop, shift, unshift, splice, reverse, fill, copyWithin slice, concat, join, at, includes, indexOf, with, toReversed, toSpliced
Частые ошибки. if (arr.indexOf(x)) — неверно, если элемент первый: индекс 0 означает «нет». new Array(7) — не [7], а семь пустых мест. arr.push(...) возвращает длину, а не массив.
