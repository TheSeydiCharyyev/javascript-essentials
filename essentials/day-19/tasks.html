День 19. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Код пишем в файле arrays.js и запускаем на странице или в консоли.

Разминка

1. Список покупок
Легко6 мин

создать массив и прочитать его элементы.

Создайте массив из пяти покупок. Выведите первый элемент, последний через at, длину списка и элемент с индексом 2.

  • последний элемент получен через at(-1), а не по числу 4;
  • все четыре значения выведены в консоль.
2. Очередь в столовой
Легко7 мин

потренировать четыре метода концов.

Массив ["Аман", "Мерет"]. Выполните по порядку: пришёл Сапар (в конец), обслужили первого (убрать с начала), вне очереди зашла Гүлнар (в начало), последний ушёл (убрать с конца). После каждого шага выводите массив.

  • использованы все четыре метода: push, shift, unshift, pop;
  • записано, что вернули shift и pop.
3. Есть ли в списке
Легко7 мин

различать indexOf и includes.

Массив предметов ["математика", "физика", "информатика"]. Проверьте двумя способами, есть ли в нём «физика» и есть ли «химия». Выведите результаты.

indexOf отвечает числом, includes — true или false.
  • для каждого предмета показаны оба ответа;
  • объяснено, почему indexOf вернул −1.

Основные задания

4. Копия против оригинала
Средне12 мин

увидеть разницу между slice и splice своими глазами.

Возьмите массив ["a", "b", "c", "d", "e"]. Сделайте две вещи в таком порядке:

  1. получите копию из элементов с индексами 1–3 и выведите исходный массив;
  2. удалите из исходного массива два элемента начиная с индекса 1 и выведите его снова.
результат каждой строки и вывод: какой метод испортил исходный массив.
  • после первого шага массив не изменился;
  • после второго — изменился;
  • в тетради записан вывод одним предложением.
5. Редактор расписания
Средне15 мин

применить splice для вставки и замены.

Дано расписание: ["алгебра", "физика", "физкультура", "история"]. Выполните:

  • вставьте «информатику» между физикой и физкультурой, ничего не удаляя;
  • замените «историю» на «геометрию»;
  • уберите первый урок;
  • выведите итог строкой через « → ».
Вставка без удаления: arr.splice(индекс, 0, значение). Строка получается методом join(" → ").
  • все три изменения сделаны через splice;
  • итог выведен одной строкой;
  • порядок предметов правильный.
6. Две группы методов
Средне12 мин

проверить на практике, какие методы меняют массив.

Для каждого метода из списка выполните его на массиве [3, 1, 2] и запишите в таблицу: что вернул метод и изменился ли исходный массив. Методы: push, slice, reverse, concat, splice, join, toReversed.

let a = [3, 1, 2];
const r = a.push(4);
console.log(r);   // что вернул метод
console.log(a);   // изменился ли массив
  • таблица из семи строк заполнена;
  • каждый метод проверен на свежем массиве;
  • методы правильно разделены на две группы.
7. Оценки класса
Средне11 мин

собрать небольшую программу из знакомых методов.

Массив оценок [5, 3, 4, 5, 2, 5]. Выведите: сколько всего оценок, индекс первой пятёрки, индекс последней пятёрки, есть ли двойка, список оценок строкой через запятую и тот же список в обратном порядке — так, чтобы исходный массив остался нетронутым.

  • шесть ответов выведены;
  • после всех действий исходный массив по-прежнему [5, 3, 4, 5, 2, 5].

Со звёздочкой

8. Ловушка new Array
Сложно10 мин

разобраться, почему конструктор ведёт себя необычно.

Выполните и объясните каждую строку:

console.log(Array.of(3));
console.log(new Array(3));
console.log(new Array(3).length);
console.log(Array.from("777"));
// console.log(new Array(2.5)); — раскомментируйте и прочитайте ошибку
  • для каждой строки записан результат;
  • найдено и записано название ошибки из последней строки;
  • сделан вывод, каким способом создавать массив в обычной работе.
9. Три последних покупки
Сложно12 мин

собрать решение из нескольких методов и не испортить данные.

Есть история покупок: ["хлеб", "чай", "рис", "масло", "сахар", "соль"]. Напишите код, который выводит три последние покупки в обратном порядке (самая свежая первой), одной строкой через запятую. Исходный массив менять нельзя.

Три с конца даёт slice(-3). Перевернуть копию можно методом toReversed либо slice().reverse().
  • результат: «соль, сахар, масло»;
  • после выполнения исходный массив не изменился — проверено выводом;
  • решение занимает не больше трёх строк.
