День 20. Перебор массивов

Выжимка лекции: сделать с каждым, собрать новый список, свернуть в одно.

Главное

Каждому методу передают функцию, и он зовёт её для каждого элемента. Выбор метода решается одним вопросом: что должно получиться.
НужноМетодВернёт
просто действиеforEachundefined
список той же длиныmapмассив
список корочеfilterмассив
первый подходящийfind / findIndexэлемент / позиция или −1
да или нетsome / everytrue / false
одно значениеreduceчто угодно
 
arr.forEach((value, index, array) => { });   // колбэк получает ТРИ аргумента

marks.map((m) => m * 10);       // [50, 40, 30]  — длина та же
marks.filter((m) => m >= 4);    // [5, 4]        — короче
marks.filter((m) => m >= 4).map((m) => m * 10);   // цепочка
forEach ничего не возвращает, и выйти из него нельзя: break — ошибка, return работает как continue. Нужен досрочный выход — берите find, some или обычный цикл.

Ловушка map(parseInt)

["1", "2", "3"].map(Number);     // [1, 2, 3]
["1", "2", "3"].map(parseInt);   // [1, NaN, NaN]
["10", "10", "10"].map(parseInt); // [10, NaN, 2]
Индекс попадает во второй параметр parseInt — систему счисления. По имени передавайте только функции с одним аргументом; в остальных случаях пишите стрелку: map((s) => parseInt(s, 10)).

Поиск и проверки

marks.find((m) => m < 4);        // 3          или undefined
marks.findIndex((m) => m < 4);   // 2          или -1
marks.findLast(...)  marks.findLastIndex(...)

marks.some((m) => m === 5);      // есть хотя бы один
marks.every((m) => m >= 2);      // все подходят

[].some(() => true);    // false
[].every(() => false);  // true — «истинно от пустоты»

reduce

marks.reduce((sum, mark) => sum + mark, 0);   // 12
//            накопленное  элемент          начальное значение

names.reduce((line, name) => line + name + "; ", "");   // строка
marks.reduce((best, m) => Math.max(best, m));           // максимум

[].reduce((a, b) => a + b);
// TypeError: Reduce of empty array with no initial value
Начальное значение пишите всегда. Оно защищает от пустого списка и задаёт тип результата. Исключение — когда пустой список заведомо не дойдёт, как в maxOf из «Табеля».

Сортировка

const nums = [10, 9, 100, 2];

nums.sort();                    // [10, 100, 2, 9] — КАК СТРОКИ
nums;                           // и массив ПЕРЕСТАВЛЕН

nums.sort((a, b) => a - b);     // по возрастанию
nums.sort((a, b) => b - a);     // по убыванию
nums.toSorted((a, b) => a - b); // копия, оригинал цел
[[1, 2], [3, [4]]].flat();               // [1, 2, 3, [4]]
[1, 2, 3].flatMap((n) => [n, n * 10]);   // [1, 10, 2, 20, 3, 30]
[1, 2, 3, 4].flatMap((n) => n % 2 === 0 ? [n * 10] : []);   // [20, 40]
Две ошибки дня: Reduce of empty array with no initial value (текст одинаков во всех браузерах) и The comparison function must be either a function or undefined — когда в sort передали не функцию.
Цепочка — это несколько проходов. На сотне элементов неважно; читаемость почти всегда важнее скорости.
  1. Перепишите три своих цикла из прошлых дней на map, filter и reduce. Проверьте, что результат совпал.
  2. Посчитайте сумму, максимум и количество пятёрок в массиве оценок — каждым способом по два раза: циклом и методом.
  3. Отсортируйте [10, 9, 100, 2] четырьмя способами: без функции, по возрастанию, по убыванию и не испортив оригинал. Запишите все четыре результата и состояние исходного массива после каждого.
  4. Получите обе ошибки дня своими руками и запишите точный текст каждой.
