День 21. Объекты

Выжимка лекции: свойства, проверки, перебор, копии.

Главное

Массив — «много однотипного по порядку». Объект — «одно целое из разных частей, у каждой своё имя». Список товаров — массив объектов. 
const student = { name: "Аман", age: 17, city: "Мары" };

student.name       // точка: имя читается буквально
student["name"]    // скобки: внутри любое выражение
student[key]       // ключ в переменной — ТОЛЬКО скобки
student.phone      // undefined, а не ошибка
Скобки обязательны в трёх случаях: ключ в переменной, ключ с пробелом или дефисом, ключ числовой. Числовые ключи при переборе всегда идут первыми и по возрастанию.

Менять можно всё

student.age = 18;        // изменили
student.group = "1-А";   // добавили
delete student.name;     // удалили

const объекту не мешает: он запрещает менять саму переменную, а не содержимое. delete возвращает true почти всегда — по его результату ничего не проверяют.

Есть ли свойство

const s = { name: "Аман", phone: undefined };

s.phone !== undefined;        // false — но свойство-то есть
"phone" in s;                 // true
Object.hasOwn(s, "phone");    // true

"toString" in s;              // true  — досталось от языка
Object.hasOwn(s, "toString"); // false — своего нет
Для своих данных берите Object.hasOwn: он отвечает ровно на заданный вопрос и не находит унаследованное.

Перебор

Object.keys(student);      // ["name", "age", "city"]
Object.values(student);    // ["Аман", 17, "Мары"]
Object.entries(student);   // [["name", "Аман"], ["age", 17], …]

Object.keys(student).length;   // у объекта НЕТ length

Object.keys(student).forEach((key) => {
  console.log(key + ": " + student[key]);
});

for...in короче, но заглядывает в унаследованное и не отдаёт массив, поэтому в новом коде чаще пишут Object.keys.

Копии и ссылки

const b = a;                          // НЕ копия: та же ссылка
const copy = Object.assign({}, a);    // копия верхнего уровня

Object.assign({}, defaults, given);   // объединение: {} первым!
Object.assign(defaults, given);       // ОШИБКА: испортит defaults
Копия поверхностная. Вложенные объекты остаются общими: после copy.address.city = "Ашхабад" изменится и оригинал. Плоские объекты копируются нормально, вложенные — нет.

Методы и новое

const o = {
  items: [],
  add(item) { this.items.push(item); },   // курс 2
  count() { return this.items.length; },  // курс 2
};

Object.fromEntries([["a", 1]]);                  // { a: 1 }
Object.groupBy(marks, (m) => m >= 4 ? "ок" : "нет");   // совсем новый
Девять страниц ошибок — больше, чем в любом другом дне. Почти все синтаксические: { x = 5 } вместо { x: 5 }, забытая скобка, точка без имени. Chrome в таких случаях говорит «Unexpected token» и показывает место — ищите ошибку строкой выше; формулировки MDN взяты из Firefox, они понятнее.
Две ошибки только в строгом режиме: присваивание свойства числу и удаление защищённого свойства. Без строгого режима — тишина. Это четвёртый и пятый такие случаи в курсе после дней 4, 14 и 16.
  1. Опишите себя объектом из пяти свойств, включая массив и вложенный объект. Выведите каждое свойство двумя способами — через точку и через скобки.
  2. Переберите свой объект тремя способами: Object.keys, Object.entries и for...in. Сравните код.
  3. Сделайте копию через Object.assign, измените в копии вложенный объект и проверьте оригинал. Объясните результат письменно.
  4. Превратите два вчерашних массива (товары и цены) в массив объектов и повторите все пять вычислений из дня 20 — уже без индексов.
