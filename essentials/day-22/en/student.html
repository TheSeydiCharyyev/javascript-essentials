Day 22. Destructuring, spread, ?.

A summary of the lecture: take apart, spread out, read safely.

The main points

There are no new capabilities today — there are three short forms for yesterday’s things: take an object apart, copy and merge, read a field that may be missing.

Destructuring

const marks = [5, 4, 3];
const [first, second] = marks;   // first = 5, second = 4 — an array BY POSITION
const [, , third] = marks;       // third = 3 — a skip
const [p, q, r, s = 0] = marks;  // s = 0 — a default (only on undefined)
const [head, ...tail] = marks;   // head = 5, tail = [4, 3] — the rest
let x = 1;
let y = 2;
[x, y] = [y, x];                 // x = 2, y = 1 — a swap; a semicolon on the line ABOVE

const student = { name: "Aman", age: 17, address: { city: "Mary" } };
const { name, age } = student;            // name = "Aman", age = 17 — an object BY NAME
const { name: studentName } = student;    // studentName = "Aman" — renaming
const { group = "1-A" } = student;        // group = "1-A" — a default
const { address: { city } } = student;    // city = "Mary" — nested
const { name: n, ...others } = student;   // others = { age: 17, address: {…} } — the rest
For an array the matching is by position, and you make up the names. For an object it is by the property name, and the order in the pattern does not matter.

Taking an array apart by position is worth it only where the position means something — for example, a “key — value” pair from Object.entries.

In parameters and callbacks

function makeRow({ name, marks = [] } = {}) { }   // = {} saves you from a call without arguments

const cart = [{ name: "bread", price: 3.5 }, { name: "tea", price: 12 }];
cart.map(({ name, price }) => name + " — " + price);   // ["bread — 3.5", "tea — 12"]

const prices = { bread: 3.5, tea: 12 };
for (const [key, value] of Object.entries(prices)) { }

A bonus besides brevity: for a function with an object parameter the order of the arguments stops mattering, and the call explains itself.

Three traps. Without const you need parentheses: ({ a } = obj). You cannot take apart undefined — TypeError: Cannot destructure property…. A default will not fire on null.

Spread — three dots spread out

const copy = [...marks];                    // [5, 4, 3] — a copy of the array
const both = [...marks, ...[2, 1]];         // [5, 4, 3, 2, 1] — merging
const defaults = { city: "Mary", group: "1-A" };
const given = { name: "Aman", city: "Ashgabat" };
const merged = { ...defaults, ...given };   // { city: "Ashgabat", group: "1-A", name: "Aman" }
const plus = { ...given, year: 2026 };      // a copy plus a property

Math.max(...marks);   // 5 — array → arguments
[..."Aman"];          // ["A", "m", "a", "n"]
The copy is shallow — nested objects stay shared, as with Object.assign.
A line cannot start with an object literal: in a file { ...obj }; is read as a block — SyntaxError: Unexpected token '...'. Put the result into a variable.

Optional chaining

const pupil = { name: "Meret" };   // no address
// pupil.address.city   → TypeError: Cannot read properties of undefined (reading 'city')
pupil.address?.city;             // undefined, without an error

const key = "name";
pupil?.[key];                    // "Meret" — a property by a variable
pupil.greet?.();                 // undefined — there is no method, there was no call

pupil.address?.city ?? "not given";   // "not given"
pupil.address?.city.length;           // undefined — the whole chain breaks off
What ?. does not do: it does not save you from a typo in a property name (a silent undefined) or from an undeclared variable (ReferenceError).
Do not put it everywhere: the program will stop crashing, but it will start lying. It is needed where a missing field is a normal situation.
  1. Take the student object from day 21 and get the name, the age, the city and the first mark out of it — one line for each, with destructuring.
  2. Rewrite three of your callbacks from day 20 so that the parameter is taken apart with a pattern: ({ name, price }) => …
  3. Copy an object that has a nested object with { ...obj }, change the nested part and check the original. Write down what happened.
  4. Find three places in your code from past days where ?. fits, and three where it would be unnecessary. Explain the difference.
