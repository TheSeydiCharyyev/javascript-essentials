День 24. DOM: находим элементы

Выжимка лекции: дерево страницы, поиск по id и селектору, переходы по соседям.

Главное

DOM — дерево объектов, которое браузер строит из HTML. JavaScript меняет не файл, а это дерево. Вход в него — переменная document. Это возможность браузера, а не языка: в Node document нет.
Скрипт подключаем с defer. Без него код выполнится раньше, чем браузер дочитает разметку, и document.body окажется null. 
document.title;           // надпись на вкладке — можно и поменять
document.body.nodeName;   // "BODY" — имя тега большими буквами
document.body.nodeType;   // 1 — элемент (3 — текст, 9 — документ)

Найти один элемент

document.getElementById("title");     // id без решётки
document.querySelector("#title");     // тот же элемент через селектор
document.querySelector(".student");   // класс — с точкой
document.querySelector("nope");       // null — не нашлось, без ошибки
СелекторЧто ищет
li, .student, #listтег, класс, id
li.absentтег и класс вместе
main pp на любой глубине внутри main
nav > aa прямо внутри nav
li:not(.absent)все, кроме
header a, footer pто или другое
Не нашлось — null, и ошибка вылезет строкой ниже: Cannot read properties of null (reading '…'). Искать причину нужно в строке с поиском: опечатка, нет defer, чужая страница. А селектор с ошибкой в записи ("li..student") сразу бросает SyntaxError.

Найти все

const items = document.querySelectorAll(".student");   // NodeList
items.length;   items[0];   items.item(0);

for (const li of items) { console.log(li); }   // перебор — for...of
items.forEach((li) => console.log(li));        // или forEach

[...items].map((li) => li.nodeName);           // map — только у массива

Ничего не нашлось — пустой список с длиной 0, а не null. for...in по списку не годится: он выдаёт ещё и length, item, forEach.

Старые методы getElementsByClassName и getElementsByTagName возвращают живую HTMLCollection: она следит за страницей, но forEach у неё нет. querySelectorAll делает снимок. У любого элемента есть свой querySelector: так ищут внутри контейнера, например main.querySelectorAll("p").

Переносы строк и отступы между тегами — тоже узлы, текстовые. Поэтому у списка из пяти пунктов childNodes.length равен 11, а firstChild — не первый пункт. Ищете теги — берите переходы со словом Element. На краю дерева переход возвращает null.

Проверить и подняться

const meret = document.querySelector(".absent");   // Мерет

meret.matches(".absent");    // true — подходит ли под селектор
meret.closest("main");       // сам элемент или ближайший подходящий предок
meret.closest("footer");     // null — такого предка нет
document.body.contains(meret);   // true — лежит ли внутри

closest надёжнее цепочек parentElement.parentElement: лишняя обёртка в разметке его не сломает.
