День 24. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Почти все задания делаем на учебной странице «Группа JS-1» из лекции: соберите её в папке day-24 и держите открытой консоль. Задание 4 — на своей странице, задание 7 — в папке day-24/tabel.

Разминка

1. Три способа
Легко6 мин

убедиться, что разные способы поиска приводят к одному и тому же объекту.

Найдите заголовок h1 тремя способами и положите в три переменные: через getElementById, через querySelector по id и через querySelector по селектору "header h1". Сравните их попарно и выведите nodeName.

=== для объектов спрашивает «та же ли это коробка». Если все три сравнения дадут true, значит, в дереве один заголовок, а способов добраться до него много.
  • три переменные, три разных способа поиска;
  • оба сравнения дали true;
  • записано, что вернул nodeName и почему большими буквами;
  • объяснено, почему в getElementById решётка не нужна, а в селекторе обязательна.
2. Сколько чего
Легко7 мин

научиться предсказывать, что найдёт селектор.

Сначала на бумаге запишите, сколько элементов найдёт каждый селектор. Потом проверьте:

const selectors = ["li", ".absent", "li:not(.absent)", "p", ".note", "nav a", "body *"];

selectors.forEach((sel) => {
  console.log(sel, document.querySelectorAll(sel).length);
});
* — любой элемент, а body * — любой элемент внутри body. Посчитайте по схеме дерева из лекции, сам body в ответ не входит.
  • предсказания записаны до запуска;
  • для всех семи селекторов записан настоящий ответ;
  • для каждого промаха объяснено, где ошиблись;
  • добавлен восьмой селектор, который не находит ничего, — записано, что вернул length.
3. Узлы и элементы
Легко7 мин

увидеть текстовые узлы из пробелов и найти закономерность.

["#list", "nav", "body", "header"].forEach((sel) => {
  const el = document.querySelector(sel);
  console.log(sel, el.childNodes.length, el.children.length);
});

Предскажите оба числа для каждого элемента, запустите и сравните. Потом выведите nodeName у firstChild и у firstElementChild каждого из четырёх.

Посмотрите в разметку: каждый ребёнок стоит на своей строке. Сколько кусков «перенос строки плюс отступ» получается вокруг пяти пунктов списка?
  • предсказания записаны до запуска;
  • найдена формула, связывающая два числа, и проверена на всех четырёх;
  • записано, что у всех четырёх firstChild — текстовый узел;
  • объяснено, что изменится, если записать список в одну строку без пробелов.

Основные задания

4. Селекторы
Средне12 мин

подобрать селектор под задачу и проверить, что найдено ровно нужное.

Создайте страницу с расписанием:

<section id="week">

Для каждого пункта напишите один селектор и проверьте его через querySelectorAll(...).length: все дни (5), выходные (2), рабочие дни (3), все предметы (4), дополнительный предмет (1), предметы среды (2), первый и последний день (по 1).

Для рабочих дней пригодится :not, для среды — :nth-child(3) и пробел перед классом предмета. Проверяйте не только число, но и сами элементы: выведите список в консоль.

  • каждый список выведен в консоль и просмотрен;
  • нарочно сломан один селектор (две точки подряд) — записан текст ошибки;
  • объяснено, чем .day .subject отличается от .day > .subject и почему здесь они находят одно и то же.

6. Где лежит элемент
Средне12 мин

отвечать на вопросы об элементе через closest и matches.

Напишите where(el): она возвращает "шапка", "список", "подвал" или "другое" — смотря где лежит элемент. Проверьте на заголовке, на Мерет, на абзаце из подвала и на абзаце с расписанием.

where(document.querySelector("h1"));          // "шапка"
where(document.querySelector(".absent"));     // "список"
where(document.querySelector("footer p"));    // "подвал"
where(document.getElementById("info"));       // "другое"

Потом посчитайте пропустивших двумя способами: через querySelectorAll(".absent") и через массив всех li, filter и matches.

closest возвращает элемент или null, а в условии if элемент истинен, null — ложен. Для filter список сначала превратите в массив.
  • все четыре проверки дали ожидаемый ответ;
  • объяснено, почему абзац с расписанием — «другое», хотя он в main;
  • оба способа подсчёта дали 2;
  • проверено на ссылке из nav — записано, что вернула функция.

Со звёздочкой

8. Путь к элементу
Сложно10 мин

пройти от элемента к корню и записать дорогу.

Напишите path(el): она поднимается от элемента до body и возвращает дорогу строкой.

path(document.querySelector(".absent"));   // "BODY > MAIN > UL > LI"
path(document.querySelector("nav a"));     // "BODY > HEADER > NAV > A"
path(document.body);                       // "BODY"
Цикл while с parentElement: на каждом шаге имя добавляется в начало массива (unshift из дня 19), в конце — join(" > "). Подумайте, когда цикл должен остановиться.
  • все три примера дают указанный ответ;
  • функция проверена на каждом пункте списка — дорога у всех одинаковая;
  • добавлена depth(el) — число шагов до body;
  • объяснено, что будет, если передать элемент из head, и как это исправить.
