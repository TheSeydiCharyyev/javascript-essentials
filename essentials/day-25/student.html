День 25. Меняем страницу

Выжимка лекции: текст, разметка, атрибуты, классы, стили и свои данные в разметке.

Главное

Свойства элемента приходят по уровням: Node даёт textContent, Element — innerHTML, атрибуты и классы, HTMLElement — innerText, style, dataset, hidden. У текстового узла нет ни классов, ни стиля: он не элемент.

Текст и разметка

el.textContent = "текст";          // теги останутся буквами; стирает всех детей
el.innerText;                      // текст как на экране, без спрятанного
el.innerHTML = "<b>жирный</b>";     // строка разбирается как HTML
el.insertAdjacentHTML("beforeend", "<i>в конец</i>");   // рядом, старое не трогает
Данные — только через textContent. Через innerHTML строка из данных станет разметкой, а обработчик вроде onerror в ней — кодом (XSS). Нужны и разметка, и данные — разметку пишем своей строкой, данные кладём в готовый элемент текстом.

innerHTML += … пересобирает всё содержимое: медленно, а сохранённые ссылки на старые элементы ведут в никуда. Дописывать — через insertAdjacentHTML.

Атрибуты

link.getAttribute("href");         // "#list" — как в разметке, или null
link.href;                         // полный адрес — свойство-отражение
link.setAttribute("title", "…");   link.removeAttribute("title");
el.hasAttribute("hidden");         // true / false
АтрибутСвойство
idel.id — "", если атрибута нет
classel.className, el.classList
data-group-nameel.dataset.groupName
hiddenel.hidden — true / false
Всё, что читается со страницы, — строки: setAttribute("title", null) запишет "null", а dataset.id + 1 даст "21". Число — через Number. У атрибутов-флажков важно наличие: hidden="false" элемент прячет.

Классы и стиль

el.classList.add("star", "late");   el.classList.remove("late");
el.classList.toggle("star");         // true — добавил, false — убрал
el.classList.toggle("star", cond);   // по условию
el.classList.contains("absent");     el.classList.replace("absent", "late");

el.className = "star";               // осторожно: стирает все остальные классы

el.style.backgroundColor = "#f5f3ff";   // имена «верблюдом»
el.style.width = percent + "%";         // единицы обязательны
el.style.color = "";                    // убрать
style видит только встроенный стиль: цвет от класса он не покажет. Ошибки в нём молчат — число без единиц, опечатка в значении или в имени просто ничего не делают. Поэтому оформление — классами с именами по смыслу (absent, а не gray), а style — только для того, что вычисляет программа.

Свои данные

li.dataset.id;                   // "2" из data-id="2" — строка
Number(li.dataset.id) + 1;       // 3
li.dataset.groupName = "JS-1";   // появится data-group-name="JS-1"
delete li.dataset.groupName;     // и исчезнет

Имя из разметки в код: убираем data-, каждый дефис с буквой после него превращается в большую букву. Элемент с данными легко найти селектором по атрибуту: [data-name="Сапар"]. А на дне 27 dataset подскажет, по какому студенту щёлкнули.

Спрятать и прокрутить

secret.hidden = true;                          // спрятать
secret.hidden = false;                         // показать
footer.scrollIntoView({ behavior: "smooth" }); // плавно прокрутить к элементу
  1. На учебной странице выведите в консоль textContent, innerText и innerHTML у main и объясните каждое различие.
  2. Запишите в абзац строку "<i>Мары</i>" обоими способами и опишите, что стало с разметкой.
  3. Отметьте классом star всех, кто был на занятии, одним forEach с toggle.
  4. Раскрасьте строки «Табеля» по вердикту и найдите строку Сапара селектором по data-name.
