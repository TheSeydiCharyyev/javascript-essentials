Day 26. Tasks

Lessons 2 and 3, 90 minutes. Warm-up — 20 minutes, main tasks — 50 minutes, starred tasks — 20 minutes. The page for experiments is yesterday’s, from the folder day-25: copy it to day-26. Tasks 7 and 8 are done in the folder day-26/tabel. Before each task reload the page (F5).

Warm-up

1. Create and insert
Easy6 min

go through the three steps “create — fill — insert” and see each of them.

Create the list item “Nazik” with the class student and the attribute data-id="6". Print isConnected and the number of items on the page before inserting and after. Then create “Ilýas” and put him first.

The number of items on the page is document.querySelectorAll("li").length. Before inserting it does not change, however you fill the new element.
  • before inserting isConnected is false, there are 5 items;
  • after — true, 6 items, Nazik is the last;
  • Ilýas is inserted with prepend and stands first;
  • it is written down what append returned, and it is explained why.
2. Four places
Easy7 min

tell inserting inside from inserting next to it.

Create four paragraphs with the texts “before”, “at the start”, “at the end”, “after” and put them around the list #list, one for each method: before, prepend, append, after. Print the innerHTML of main and find all four.

Two paragraphs will end up inside <ul> — next to the items, two outside — next to the list itself. A paragraph inside a list formally breaks the markup, but for the experiment it does not matter.
  • all four paragraphs stand where expected;
  • it is written down which two are inside ul and which two are outside;
  • after is called on a new paragraph that is not inserted — it is written down what happened;
  • the same experiment is repeated with strings instead of paragraphs.
3. Move or copy
Easy7 min

make sure that inserting moves, and a copy is made explicitly.

Move the first list item to the end with append and count the items. Then insert its deep copy at the end and count again. Compare a deep and a shallow copy. Finally, copy the heading #title and insert the copy into the footer.

After copying the heading, check querySelectorAll("#title").length. What needs to be done with the copy before inserting?
  • after moving there are still 5 items, after the copy — 6;
  • it is written down how a shallow copy differs from a deep one;
  • two elements with id="title" are found, and this is fixed by changing the copy’s id;
  • it is explained why a node cannot stand in two places.

Main tasks

4. Remove and put back
Medium12 min

remove elements correctly and not lose them.

Take all the absent ones (.absent) off the page, keeping them in an array. Check how many items are left. Then put the removed ones back at the end of the list with one line.

The array of removed ones is a querySelectorAll snapshot turned into an array. append with three dots will help put them all back at once.
  • after removing there are three in the list, after putting back — five: Aman, Gülnar, Oguljan, Meret, Sapar;
  • putting back is done with one append call;
  • a for...of loop over list.children with remove is tried — it is written down who was left, and it is explained why;
  • the list is cleared completely with one line without a loop.
5. A list from an array
Medium13 min

write a function that redraws a list from data.

Write toItem(name) and renderList(list, names) from the lecture. Call renderList three times: with three names, with the same ones again and with an empty array. Then teach the items to number themselves.

renderList(list, ["Aman", "Meret", "Gülnar"]);
// <li>1. Aman</li><li>2. Meret</li><li>3. Gülnar</li>
map from day 20 passes the function the element’s number as the second argument. If toItem has a second parameter, it gets that number — starting from zero.
  • a repeated call does not double the items, an empty array clears the list;
  • the items are numbered from one;
  • clearing is temporarily removed from renderList — it is written down what happened after the second call;
  • the name "<b>Aman</b>" is checked: the tags are seen as letters.
6. Student cards
Medium12 min

build an element with children in the right order.

Write makeCard(student): it returns a <div class="card"> with a heading with the name, a paragraph “Marks: …” and a paragraph “Average: …” with two digits after the point. Insert the cards of all students into main with one line.

const group = [
  { name: "Aman", marks: [5, 4, 5] },
  { name: "Meret", marks: [3, 4] },
  { name: "Sapar", marks: [5, 5, 4, 5] },
];
First create all four elements, then fill them, then card.append(name, marks, avg). The average mark — with reduce and toFixed(2).
  • there are three cards on the page, the averages are 4.67, 3.50, 4.75;
  • all the data is written through textContent;
  • the cards are inserted with one append call;
  • it is explained why a card is built before inserting, not on the page.
7. The “Report card” without prepared rows
Medium13 min

create table rows with code, as many as there are students.

Copy day-25/tabel to day-26/tabel and rebuild it:

  • in the markup the table body is empty: <tbody></tbody>;
  • makeRow(report) creates a <tr> row with six cells, a class by verdict and data-name;
  • all the rows are inserted with one append call.
  • the table looks the same as yesterday, the numbers matched;
  • a sixth student “Ilýas” with the marks [5, 5, "4"] is added from the console — a green row 4.67 appeared;
  • inserting all the rows is called twice — it is written down how many rows there became, and it is fixed with one line;
  • it is written down which functions from past days did not change in a single line.

Starred tasks

8. Sorting the table
Hard10 min

rearrange rows without creating or removing them.

Sort the rows of the “Report card” by average mark, from the largest to the smallest. The row without marks must end up last.

// after sorting:
// Sapar 4.75, Oguljan 4.50, Aman 4.33, Meret 3.33, Gülnar —
The average mark is the text of the row’s second cell: row.children[1].textContent. A helper function can give a number, and for “—”, for example, -1. Then — as with sorting the list in the lecture.
  • the order matched the example;
  • there are still five rows — none was created or removed;
  • the classes and data-name stayed on their rows;
  • the reverse sorting is done too — from the smallest to the largest.
9. Six catches
Hard10 min

gather everything that behaves unexpectedly today.

// 1
const li = document.createElement("li");
li.textContent = "Nazik";
console.log(document.querySelectorAll("li").length);

// 2
const list = document.querySelector("#list");
console.log(list.append(li));

// 3
list.append(list.firstElementChild);
console.log(list.children.length);

// 4
for (const item of list.children) {
  item.remove();
}
console.log(list.children.length);

// 5
const p = document.createElement("p");
p.after("text");
console.log(p.nextSibling);

// 6
list.appendChild("Ilýas");
The fragments go in a row, and each depends on the previous ones. Only the last one crashes. In the fourth, work out on paper which numbers are removed at each step.
  • the predictions are written down before running;
  • for the sixth the exact error text is written down;
  • for each of the first five it is explained where the answer came from;
  • the fourth is rewritten so that all the items are removed.
