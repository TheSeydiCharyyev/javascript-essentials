День 26. Задания

Уроки 2 и 3, 90 минут. Разминка — 20 минут, основные — 50 минут, со звёздочкой — 20 минут. Страница для опытов — вчерашняя, из папки day-25: скопируйте её в day-26. Задания 7 и 8 — в папке day-26/tabel. Перед каждым заданием обновляйте страницу (F5).

Разминка

1. Создать и вставить
Легко6 мин

пройти три шага «создать — наполнить — вставить» и увидеть каждый.

Создайте пункт списка «Назик» с классом student и атрибутом data-id="6". Выведите isConnected и число пунктов на странице до вставки и после. Потом создайте «Ильяс» и поставьте его первым.

Число пунктов на странице — document.querySelectorAll("li").length. До вставки оно не изменится, как бы вы ни наполняли новый элемент.
  • до вставки isConnected — false, пунктов 5;
  • после — true, пунктов 6, Назик последняя;
  • Ильяс вставлен через prepend и стоит первым;
  • записано, что вернул append, и объяснено, почему.
2. Четыре места
Легко7 мин

различать вставку внутрь и вставку рядом.

Создайте четыре абзаца с текстами «до», «в начале», «в конце», «после» и поставьте их вокруг списка #list, по одному на каждый метод: before, prepend, append, after. Выведите innerHTML у main и найдите все четыре.

Два абзаца окажутся внутри <ul> — рядом с пунктами, два снаружи — рядом с самим списком. Абзац внутри списка разметку формально нарушает, но для опыта это неважно.
  • все четыре абзаца стоят там, где ожидалось;
  • записано, какие два внутри ul, а какие два снаружи;
  • вызван after у нового, невставленного абзаца — записано, что произошло;
  • тот же опыт повторён со строками вместо абзацев.
3. Перенос или копия
Легко7 мин

убедиться, что вставка переносит, а копию делают явно.

Перенесите первый пункт списка в конец через append и посчитайте пункты. Потом вставьте в конец его глубокую копию и посчитайте снова. Сравните глубокую и мелкую копию. Наконец, скопируйте заголовок #title и вставьте копию в подвал.

После копии заголовка проверьте querySelectorAll("#title").length. Что нужно сделать с копией до вставки?
  • после переноса пунктов по-прежнему 5, после копии — 6;
  • записано, чем мелкая копия отличается от глубокой;
  • найдено два элемента с id="title", и это исправлено сменой id у копии;
  • объяснено, почему узел не может стоять в двух местах.

Основные задания

4. Удалить и вернуть
Средне12 мин

удалять элементы правильно и не терять их.

Уберите со страницы всех отсутствующих (.absent), сохранив их в массиве. Проверьте, сколько пунктов осталось. Затем верните удалённых в конец списка одной строкой.

Массив удалённых — это снимок querySelectorAll, превращённый в массив. Вернуть всех разом поможет append с тремя точками.
  • после удаления в списке трое, после возврата — пятеро: Аман, Гүлнар, Огулджан, Мерет, Сапар;
  • возврат сделан одним вызовом append;
  • попробован цикл for...of по list.children с remove — записано, кто остался, и объяснено почему;
  • список очищен целиком одной строкой без цикла.
5. Список из массива
Средне13 мин

написать функцию, которая перерисовывает список по данным.

Напишите toItem(name) и renderList(list, names) из лекции. Вызовите renderList три раза: с тремя именами, с теми же ещё раз и с пустым массивом. Потом научите пункты нумероваться.

renderList(list, ["Аман", "Мерет", "Гүлнар"]);
// <li>1. Аман</li><li>2. Мерет</li><li>3. Гүлнар</li>
map из дня 20 передаёт функции вторым аргументом номер элемента. Если у toItem будет второй параметр, он его и получит — начиная с нуля.
  • повторный вызов не удваивает пункты, пустой массив очищает список;
  • пункты нумеруются с единицы;
  • из renderList временно убрана очистка — записано, что стало после второго вызова;
  • проверено имя "<b>Аман</b>": теги видны буквами.
6. Карточки студентов
Средне12 мин

собрать элемент с детьми в правильном порядке.

Напишите makeCard(student): она возвращает <div class="card"> с заголовком-именем, абзацем «Оценки: …» и абзацем «Средний: …» с двумя знаками после точки. Вставьте в main карточки всех студентов одной строкой.

const group = [
  { name: "Аман", marks: [5, 4, 5] },
  { name: "Мерет", marks: [3, 4] },
  { name: "Сапар", marks: [5, 5, 4, 5] },
];
Сначала создайте все четыре элемента, потом наполните, потом card.append(name, marks, avg). Средний балл — через reduce и toFixed(2).
  • на странице три карточки, средние — 4.67, 3.50, 4.75;
  • все данные записаны через textContent;
  • карточки вставлены одним вызовом append;
  • объяснено, почему карточка собирается до вставки, а не на странице.
7. «Табель» без заготовок
Средне13 мин

создавать строки таблицы кодом по числу студентов.

Скопируйте day-25/tabel в day-26/tabel и перестройте:

  • в разметке тело таблицы пустое: <tbody></tbody>;
  • makeRow(report) создаёт строку <tr> с шестью ячейками, классом по вердикту и data-name;
  • все строки вставлены одним вызовом append.
  • таблица выглядит так же, как вчера, числа совпали;
  • из консоли добавлен шестой студент «Ильяс» с оценками [5, 5, "4"] — появилась зелёная строка 4.67;
  • вставка всех строк вызвана дважды — записано, сколько стало строк, и исправлено одной строкой;
  • записано, какие функции прошлых дней не изменились ни в одной строке.

Со звёздочкой

8. Сортировка таблицы
Сложно10 мин

переставлять строки, не создавая и не удаляя их.

Отсортируйте строки «Табеля» по среднему баллу, от большего к меньшему. Строка без оценок должна оказаться последней.

// после сортировки:
// Сапар 4.75, Огулджан 4.50, Аман 4.33, Мерет 3.33, Гүлнар —
Средний балл — текст второй ячейки строки: row.children[1].textContent. Вспомогательная функция может отдавать число, а для «—» — например, -1. Дальше — как с сортировкой списка в лекции.
  • порядок совпал с примером;
  • строк по-прежнему пять — ни одна не создана и не удалена;
  • классы и data-name остались на своих строках;
  • сделана и обратная сортировка — от меньшего к большему.
9. Шесть подвохов
Сложно10 мин

собрать вместе всё, что сегодня ведёт себя неожиданно.

// 1
const li = document.createElement("li");
li.textContent = "Назик";
console.log(document.querySelectorAll("li").length);

// 2
const list = document.querySelector("#list");
console.log(list.append(li));

// 3
list.append(list.firstElementChild);
console.log(list.children.length);

// 4
for (const item of list.children) {
  item.remove();
}
console.log(list.children.length);

// 5
const p = document.createElement("p");
p.after("текст");
console.log(p.nextSibling);

// 6
list.appendChild("Ильяс");
Фрагменты идут подряд, и каждый зависит от предыдущих. Падает только последний. В четвёртом посчитайте на бумаге, какие номера удаляются на каждом шаге.
  • предсказания записаны до запуска;
  • для шестого записан точный текст ошибки;
  • для каждого из первых пяти объяснено, откуда взялся ответ;
  • четвёртый переписан так, чтобы удалялись все пункты.
