День 29. Мини-проект: список дел

Выжимка лекции: как устроена программа и как проверить, что проект готов.

Пять частей программы

// 1. Данные — всё, от чего зависит вид страницы
let tasks = [
  { id: 1, text: "Повторить день 26", done: true },
  // … у каждого дела id, text и done
];
let nextId = 4;
let filter = "all";

// 2. Элементы страницы — находим один раз
const list = document.querySelector("#tasks");

// 3. Показ: страница строится из данных
function render() {
  list.textContent = "";
  list.append(...tasks.filter(isVisible).map(makeItem));
  // счётчик и кнопки — тоже из данных, по всем делам
}

// 4. Действия: понять, что случилось → изменить данные → render()
// 5. Первый показ
render();
Страница — картинка данных. Слушатель не правит список сам: он меняет tasks или filter и зовёт render(). Одно действие меняет сразу список, счётчик и кнопки — когда всё строит одна функция, страница не разойдётся с данными.

makeItem(task) делает из одного объекта один пункт и только возвращает его. Данные — через textContent, класс — через classList.toggle("done", task.done), а в data-id пункт запоминает номер своего дела.

От элемента к данным

function taskOf(element) {
  const id = Number(element.closest("li").dataset.id);   // "2" → 2
  return tasks.find((t) => t.id === id);
}

// в слушателе click на списке — удалить нажатое дело:
const task = taskOf(event.target);
tasks = tasks.filter((t) => t !== task);   // все, кроме него; поэтому let
Всё, что лежит в dataset, — строки: без Number сравнение "2" === 2 ложно и find вернёт undefined. Связь «пункт — дело» строят только через id: позиция в списке меняется от фильтра и удаления, а id — никогда.

При любой странности первый вопрос — что в данных? Спросите консоль: tasks. Данные верны, а страница нет — ищите render.

Как расширять

Любая доработка ложится в ту же схему: новое поле или переменная в данных (important, query), строчка в makeItem или isVisible, новый слушатель, который меняет данные и зовёт render. Сохранения пока нет: обновили страницу — вернулись исходные дела. Его добавим на дне 31.
