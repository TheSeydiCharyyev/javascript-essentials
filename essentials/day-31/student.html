День 31. fetch, async/await и localStorage

Выжимка лекции: запрос к серверу, асинхронные функции, хранилище браузера, кодирование адреса.

Запрос и ответ

async function loadGroup() {
  const response = await fetch("group.json");   // ответ пришёл: статус и заголовки
  if (!response.ok) {                            // 404, 500 — для fetch не ошибка!
    throw new Error(`Сервер ответил ${response.status}`);
  }
  return response.json();                        // тело: json() или text(), один раз
}
Страницу открывают через Live Server: с file:/// запросы запрещены. fetch отклоняется только без ответа — TypeError: Failed to fetch. Ответ 404 приходит «успешно», с ok === false, поэтому ok проверяют до чтения тела: иначе страница ошибки уйдёт в json() и даст Unexpected token '<'.

Все три удобно свести в один catch: плохой статус превращают в ошибку сами, через throw. Что ушло и что пришло, видно на вкладке Network.

async и await

loadButton.addEventListener("click", async () => {
  try {
    const group = await loadGroup();   // значение — только после await
    // … показать
  } catch (err) {
    message.textContent = `Не удалось загрузить: ${err.message}`;
  } finally {
    loadButton.hidden = false;         // уборка в любом исходе
  }
});
Асинхронная функция всегда возвращает промис. await останавливает только свою функцию, страница живёт дальше. await работает лишь внутри async; в консоли Chrome — и вне функции, но это удобство консоли. Забытый await даёт промис вместо данных: r.json is not a function, undefined вместо длины.

Хранилище браузера

const saved = localStorage.getItem("todo:tasks");             // null, если ключа нет
const tasks = saved === null ? [] : JSON.parse(saved);
localStorage.setItem("todo:tasks", JSON.stringify(tasks));   // только строки!
localStorage.removeItem("todo:tasks");                        // своё — своим ключом

Без JSON.stringify объект сохранится как "[object Object]", а getItem вернёт число строкой: "5" + 1 даст "51". Все проекты Live Server живут на одном адресе и делят одно хранилище, поэтому у ключей приставка проекта, а clear() — только для опытов.

Текст в адресе

Любой текст от человека, который идёт в адрес, пропускают через encodeURIComponent: иначе &, ? и # в нём сломают адрес. decodeURIComponent — обратно; неверный код даёт URIError: URI malformed. encodeURI — для адреса целиком, знаки & и ? он оставляет как есть.

Список дел и «Табель» помнят

Список дел сохраняет задачи последней строкой render, а при запуске читает их и восстанавливает счётчик: Math.max(0, ...tasks.map((t) => t.id)) + 1 — иначе номера повторятся. «Табель» при первом запуске берёт данные из students.json, дальше — из хранилища, а сохраняет в updateSummary. Испорченные данные в хранилище лечатся removeItem своего ключа.
