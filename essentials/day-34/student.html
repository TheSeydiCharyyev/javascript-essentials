День 34. Итоговый проект: реализация

Выжимка лекции: работа по плану, текущий элемент по кругу, пустое состояние, план и факт.

Одна задача за раз

Взяли задачу плана → заменили заглушку кодом → проверили руками и в консоли → отметили в плане с настоящими минутами → следующая. Тогда ошибка всегда в последнем куске. Перед большой правкой — копия папки проекта. Застряли — прочитать красную строку до конца, спросить данные, запустить функции-проверки; не помогло за 10 минут — вернуться к копии и идти меньшими шагами.

Текущий элемент по кругу

function current() {
  const cards = deck();
  return cards.length === 0 ? null : cards[position % cards.length];   // null — пусто
}

againButton.addEventListener("click", () => {
  position++;          // просто растёт — % держит в границах колоды
  flipped = false;     // новая карточка — словом
  render();
});
Текущую карточку не хранят, а вычисляют из колоды и позиции: копия устарела бы после первого «Знаю». Остаток от деления ходит по кругу — после последней снова первая, и колода может стать короче без ошибок. Без % — undefined и Cannot read properties of undefined (reading 'word').

Данные, которые зависят от других данных, сбрасываются вместе с ними: сменилась карточка — flipped = false; сменилась тема — ещё и position = 0. Иначе следующая карточка откроется сразу переводом.

Пустое состояние и сброс

knowButton.hidden = current() === null;   // в render: невозможное не предлагаем
if (current() === null) return;           // в слушателе: всё равно защищаемся
if (!confirm("Забыть все выученные слова?")) return;
learned = [];                             // сбрасывают данные, а не хранилище
undefined — «такого места нет», чаще всего ошибка. null — «мы сами сказали: ничего нет», его ждут и проверяют. Хранилище — копия данных: удалить ключ бесполезно, render тут же запишет старый learned обратно.

Новая идея посреди работы не делается, а записывается в «потом» с минутами. Перерасход времени — не повод ускоряться, а повод пересчитать следующий день и выбросить задачу с отметкой later.
