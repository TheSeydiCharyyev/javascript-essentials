Телефон

С телефона в той же сети Wi-Fi открывают адрес компьютера из ipconfig (строка IPv4) вместо 127.0.0.1: http://192.168.1.23:5500/index.html. Не открывается — режим телефона в DevTools, Ctrl + Shift + M.

<meta name="viewport" content="width=device-width, initial-scale=1.0">
<style>
  button { font-size: 18px; padding: 10px 16px; margin: 0 8px 8px 0; }
  .card { … overflow-wrap: anywhere; }
</style>
Без строки viewport телефон строит страницу шириной 980 и уменьшает её: innerWidth — 980 вместо 360. Проверяют худшее: узкий экран, палец (кнопка в 21 пиксель — промах), самое длинное слово.

Перемешивание

for (let i = result.length - 1; i > 0; i--) {
  const j = Math.floor(Math.random() * (i + 1));   // от 0 до i, не до конца массива
  const temp = result[i];
  result[i] = result[j];
  result[j] = temp;
}

sort(() => Math.random() - 0.5) перемешивает неровно: в Chrome два порядка трёх чисел из шести выпадают вдвое чаще. После перемешивания проверка должна сторожить правило («первая карточка — первая в колоде»), а не порядок.
