1. JavaScript'in tarihi

JavaScript создан Бренданом Айком в 1995 году за 10 дней в компании Netscape. Сначала назывался Mocha, потом LiveScript, затем JavaScript (маркетинг на волне Java).

JavaScript was created by Brendan Eich in 1995 in 10 days at Netscape. First called Mocha, then LiveScript, then JavaScript (marketing on Java's wave).

JavaScript Netscape kompaniýasynda Brendan Aýk tarapyndan 1995-nji ýylda 10 günde döredildi. Ilki Mocha, soň LiveScript, soňra JavaScript diýlip atlandyryldy (Java-nyň meşhurlygyndan peýdalanmak üçin marketing).

JavaScript, Netscape şirketinde Brendan Eich tarafından 1995'te 10 günde yaratıldı. Önce Mocha, sonra LiveScript, ardından JavaScript adını aldı (Java'nın popülerliğinden yararlanmak için pazarlama).

JavaScript — высокоуровневый, мультипарадигменный, динамически-типизированный, интерпретируемый язык. Реализует спецификацию ECMAScript.

JavaScript is a high-level, multi-paradigm, dynamically-typed, interpreted language. It implements the ECMAScript specification.

JavaScript — ýokary derejeli, köp paradigmaly, dinamiki tipli, interpretirlenýän dil. ECMAScript spesifikasiýasyny amala aşyrýar.

JavaScript — üst düzey, çok paradigmalı, dinamik türlü, yorumlanan bir dildir. ECMAScript belirtimini uygular.

ECMAScript vs JavaScript: ECMAScript — это спецификация (правила), JavaScript — это реализация (язык, которым мы пользуемся). Как правила футбола vs реальный матч.

ECMAScript vs JavaScript: ECMAScript is the specification (rules), JavaScript is the implementation (language we use). Like football rules vs an actual match.

ECMAScript vs JavaScript: ECMAScript — spesifikasiýa (düzgünler), JavaScript — amala aşyrylyşy (biziň ulanýan dilimiz). Futbolyň düzgünleri we hakyky duşuşyk ýaly.

ECMAScript vs JavaScript: ECMAScript — belirtim (kurallar), JavaScript — uygulama (kullandığımız dil). Futbol kuralları ile gerçek maç gibi.

defer vs async

defer vs async

defer vs async

defer vs async

  • defer — скачать параллельно, выполнить после HTML, в порядке. Рекомендуется.
  • async — скачать параллельно, выполнить как только готов (любой порядок). Для независимых скриптов (аналитика).
  • Ничего — блокирует парсинг HTML. Использовать только в конце <body>.
  • defer — download in parallel, run after HTML, in order. Recommended.
  • async — download in parallel, run as soon as ready (any order). For independent scripts (analytics).
  • Nothing — blocks HTML parsing. Use only at the end of <body>.
  • defer — parallel ýüklemek, HTML-den soň, tertibinde ýerine ýetirmek. Maslahat berilýär.
  • async — parallel ýüklemek, taýýar bolan badyna ýerine ýetirmek (islendik tertipde). Garaşsyz skriptler üçin (analitika).
  • Hiç zat — HTML parsingini petikleýär. Diňe <body>-iň ahyrynda ulanmaly.
  • defer — paralel indir, HTML'den sonra, sırayla çalıştır. Önerilir.
  • async — paralel indir, hazır olur olmaz çalıştır (sıra garantisiz). Bağımsız betikler için (analitik).
  • Hiçbiri — HTML ayrıştırmasını durdurur. Yalnızca <body> sonunda kullanın.
