  5. Запустите через Open with Live Server и откройте консоль (F12).
  1. Create a folder task-2/.

  3. In HTML, make a simple page with the heading "My first JS page" and link app.js via <script src="app.js" defer></script> in <head>.

Задание 4. Исследуем JS-движок браузера
Task 4. Explore the browser's JS engine
Средне Medium 15 мин
Выяснить, какой JS-движок работает в вашем основном браузере и в нём же увидеть его настройки. Find out which JS engine runs in your main browser and see its settings.

Шаги:

Steps:

  1. Откройте ваш основной браузер. Запишите: Chrome / Edge / Firefox / Safari.
  2. В консоли (F12) напишите navigator.userAgent и изучите строку.
  3. Определите, какой JS-движок работает в вашем браузере (V8, SpiderMonkey, JavaScriptCore). Проверьте по таблице в лекции.
  4. В консоли напишите console.log(window) — увидите всё, что доступно в глобальном контексте JS.
  5. Попробуйте вызвать методы: window.innerWidth, window.innerHeight, window.location.href.
  1. Open your main browser. Write down: Chrome / Edge / Firefox / Safari.
  2. In the console (F12), type navigator.userAgent and inspect the string.
  3. Identify which JS engine runs in your browser (V8, SpiderMonkey, JavaScriptCore). Check the table in the lecture.
  4. In the console, type console.log(window) — you'll see everything available in the global JS scope.
  5. Try calling: window.innerWidth, window.innerHeight, window.location.href.
  • В тетради записано: название браузера, название движка, размеры окна в пикселях, ваш userAgent
  • Вы понимаете, что window — глобальный объект браузера, где живут все встроенные функции JS
  • Written in the notebook: browser name, engine name, window dimensions in pixels, your userAgent
  • You understand that window is the browser's global object where all built-in JS functions live
Задание 5. Кнопка-счётчик
Task 5. Counter button
Сложно Hard 25 мин
Написать маленькое интерактивное приложение: кнопка, которая считает, сколько раз её нажали, и показывает это на странице. Write a small interactive app: a button that counts how many times it was clicked and shows it on the page.

Что должно получиться: на странице заголовок «Счётчик: 0» и кнопка «Нажми меня». При каждом клике число в заголовке увеличивается на 1.

What to build: a heading "Counter: 0" and a "Click me" button. Each click increments the number in the heading by 1.

Заготовка HTML:

HTML skeleton:

<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>Счётчик</title>
    <script src="counter.js" defer></script>
</head>
<body>
    <h1 id="title">Счётчик: 0</h1>
    <button id="btn">Нажми меня</button>
</body>
</html>

В counter.js нужна переменная count = 0, обработчик addEventListener("click", ...) на кнопке, и обновление текста через title.textContent = "Счётчик: " + count.

In counter.js you need a variable count = 0, a handler addEventListener("click", ...) on the button, and updating the text via title.textContent = "Counter: " + count.

  • При каждом клике число увеличивается на 1
  • JS подключён через внешний файл с defer
  • В консоли нет ошибок (F12 → Console)
  • (Бонус) После 10 кликов показывается alert «Поздравляю, 10 кликов!»
  • Each click increments the number by 1
  • JS is linked as an external file with defer
  • No errors in the console (F12 → Console)
  • (Bonus) After 10 clicks, show an alert "Congratulations, 10 clicks!"

Что нужно сделать:

What to do:

  1. Выберите одно из направлений: фронтенд, бэкенд (Node.js), мобильные приложения (React Native), десктоп (Electron), игры.
  2. Найдите в интернете 3 реальных продукта, которые используют JS в выбранной области. Например, для Electron: VS Code, Slack, Discord.
  3. Для каждого продукта запишите: название, ссылку на сайт, что делает, какие технологии (React, Vue, Node.js и т. п.) использует.
  4. Напишите короткий вывод (3-5 предложений): почему JS — хороший выбор для этой области.
  1. Choose one area: frontend, backend (Node.js), mobile (React Native), desktop (Electron), games.
  2. Find 3 real products that use JS in that area. For example, for Electron: VS Code, Slack, Discord.
  3. For each product, record: name, website link, what it does, what technologies it uses (React, Vue, Node.js, etc.).
  4. Write a short conclusion (3-5 sentences): why JS is a good choice for this area.

  • Описаны 3 реальных продукта
