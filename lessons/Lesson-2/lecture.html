Проблема без Live Server

The problem without Live Server

Live Server bolmasa ýüze çykýan mesele

Обычно, чтобы увидеть HTML-страницу, вы делаете двойной клик по файлу — браузер открывает её через file:///. Это работает, но:

Normally, to see an HTML page, you double-click the file — the browser opens it via file:///. This works, but:

Adatça HTML sahypany görmek üçin faýla iki gezek basýarsyňyz — brauzer ony file:/// arkaly açýar. Bu işleýär, ýöne:

  • После каждой правки надо вручную обновлять браузер (F5)
  • Некоторые вещи (например, загрузка JSON через fetch) работают только по HTTP, а не из файла
  • ES6-модули (import/export) требуют HTTP и падают при открытии напрямую
  • After each edit you must manually refresh the browser (F5)
  • Some things (like loading JSON via fetch) work only over HTTP, not from a file
  • ES6 modules (import/export) require HTTP and fail when opened directly
  • Her üýtgetmeden soň brauzeri el bilen täzelemeli (F5)
  • Käbir zatlar (mysal üçin, fetch arkaly JSON ýüklemek) faýldan däl-de, diňe HTTP arkaly işleýär
  • ES6 modullary (import/export) HTTP talap edýär we göni açylanda işlemeýär

Решение: Live Server

Solution: Live Server

Çözgüt: Live Server

Расширение Live Server поднимает у вас на компьютере маленький HTTP-сервер и открывает страницу по адресу вроде http://127.0.0.1:5500. При каждом сохранении файла страница автоматически перезагружается — без нажатия F5.

Live Server starts a tiny HTTP server on your machine and opens the page at an address like http://127.0.0.1:5500. When you save a file, the page auto-reloads — no F5 needed.

Live Server giňeltmesi kompýuteriňizde kiçijik HTTP serwer işledýär we sahypany http://127.0.0.1:5500 ýaly salgyda açýar. Faýly her gezek ýatda saklanyňyzda sahypa F5 basmazdan awtomatik täzeden ýüklenýär.

// Компьютер загадывает число от 1 до 100
const secret = Math.floor(Math.random() * 100) + 1;
let attempts = 0;
let guess = null;

console.log("Я загадал число от 1 до 100. Попробуй угадать!");

// Играем пока пользователь не угадает
while (guess !== secret) {
    const input = prompt("Твоё число (1-100):");

    // Если пользователь нажал «Отмена»
    if (input === null) {
        console.log("Игра отменена.");
        break;
    }

    guess = Number(input);
    attempts++;

    if (guess < secret) {
        console.log(guess + " — мало! Пробуй больше.");
    } else if (guess > secret) {
        console.log(guess + " — много! Пробуй меньше.");
    } else {
        console.log("🎉 Угадал! Число было " + secret);
        console.log("Попыток: " + attempts);
    }
}
