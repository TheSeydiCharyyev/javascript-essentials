4. Live Server — авто-обновление страницы

4. Live Server — auto-reload

В прошлом занятии вы узнали, что такое Live Server. Сегодня разберём, зачем он нужен и как работает.

In the last lesson you learned what Live Server is. Today we'll understand why it's needed and how it works.

Проблема без Live Server

The problem without Live Server

Обычно, чтобы увидеть HTML-страницу, вы делаете двойной клик по файлу — браузер открывает её через file:///. Это работает, но:

Normally, to see an HTML page, you double-click the file — the browser opens it via file:///. This works, but:

  • После каждой правки надо вручную обновлять браузер (F5)
  • Некоторые вещи (например, загрузка JSON через fetch) работают только по HTTP, а не из файла
  • ES6-модули (import/export) требуют HTTP и падают при открытии напрямую
  • After each edit you must manually refresh the browser (F5)
  • Some things (like loading JSON via fetch) work only over HTTP, not from a file
  • ES6 modules (import/export) require HTTP and fail when opened directly

Решение: Live Server

Solution: Live Server

Расширение Live Server поднимает у вас на компьютере маленький HTTP-сервер и открывает страницу по адресу вроде http://127.0.0.1:5500. При каждом сохранении файла страница автоматически перезагружается — без нажатия F5.

Live Server starts a tiny HTTP server on your machine and opens the page at an address like http://127.0.0.1:5500. When you save a file, the page auto-reloads — no F5 needed.

5. Node.js и npm — что это и зачем

5. Node.js and npm — what and why

До 2009 года JavaScript жил только в браузере. Потом Райан Даль взял движок V8 из Chrome и упаковал его в отдельную программу, которая работает в операционной системе. Так появился Node.js.

Before 2009, JavaScript lived only in the browser. Then Ryan Dahl took the V8 engine from Chrome and wrapped it in a standalone program that runs in the operating system. That's how Node.js was born.

Node.js — это среда исполнения JavaScript, которая работает вне браузера. Использует тот же движок V8, что и Chrome. Позволяет запускать JS-файлы командой node filename.js в терминале.

Node.js is a JavaScript runtime that runs outside the browser. It uses the same V8 engine as Chrome. It lets you run JS files with node filename.js in the terminal.

Зачем нам Node.js на этом этапе

Why we need Node.js at this stage

Сейчас — чтобы быстро проверять маленькие куски кода без лишней возни с HTML-страницей. Написал test.js, выполнил node test.js в терминале — сразу увидел результат. В будущем Node понадобится для установки библиотек через npm, сборки проектов, создания серверов.

Right now — to quickly test small chunks of code without the hassle of an HTML page. You write test.js, run node test.js in the terminal — and instantly see the result. Later Node will be needed for installing libraries via npm, building projects, and creating servers.

Что такое npm

What is npm

npm (Node Package Manager) — это менеджер пакетов, который устанавливается вместе с Node.js. Через него вы скачиваете и подключаете готовые библиотеки: React, Express, Lodash и ещё более миллиона. В мире JavaScript npm — это «магазин приложений» для разработчиков.

npm (Node Package Manager) is a package manager that installs together with Node.js. Through it you download and use ready-made libraries: React, Express, Lodash, and over a million others. In the JS world, npm is the "app store" for developers.

Теперь — пишем первое настоящее приложение. Это классическая игра: компьютер загадывает число от 1 до 100, вы его отгадываете, он подсказывает «больше» или «меньше», считает количество попыток.

Now — we write our first real application. A classic game: the computer picks a number from 1 to 100, you guess it, it hints "higher" or "lower", and counts your attempts.

game.js — основной код:

game.js — the main logic:

// Компьютер загадывает число от 1 до 100
const secret = Math.floor(Math.random() * 100) + 1;
let attempts = 0;
let guess = null;

console.log("Я загадал число от 1 до 100. Попробуй угадать!");

// Играем пока пользователь не угадает
while (guess !== secret) {
    const input = prompt("Твоё число (1-100):");

    // Если пользователь нажал «Отмена»
    if (input === null) {
        console.log("Игра отменена.");
        break;
    }

    guess = Number(input);
    attempts++;

    if (guess < secret) {
        console.log(guess + " — мало! Пробуй больше.");
    } else if (guess > secret) {
        console.log(guess + " — много! Пробуй меньше.");
    } else {
        console.log("🎉 Угадал! Число было " + secret);
        console.log("Попыток: " + attempts);
    }
}

Разбор кода

Code walkthrough

  • Math.random() — возвращает случайное число от 0 до 1 (например, 0.7342).
  • * 100 — превращаем в число от 0 до 100.
  • Math.floor(...) — округляем вниз до целого (0 до 99).
  • + 1 — получаем диапазон 1 до 100.
  • prompt(...) — показывает окно ввода в браузере, возвращает строку или null (если нажали Отмена).
  • Number(input) — превращаем строку в число.
  • while (guess !== secret) — цикл работает, пока не угадали.
  • attempts++ — увеличиваем счётчик попыток на 1.
  • Math.random() — returns a random number from 0 to 1 (e.g., 0.7342).
  • * 100 — turns it into 0 to 100.
  • Math.floor(...) — rounds down to an integer (0 to 99).
  • + 1 — gives us the range 1 to 100.
  • prompt(...) — shows an input dialog in the browser, returns a string or null (if Cancel was clicked).
  • Number(input) — converts string to number.
  • while (guess !== secret) — loop runs until guessed.
  • attempts++ — increments the attempt counter by 1.

Не волнуйтесь, если пока не понимаете каждую строку — while, Math.floor, prompt. Мы подробно разберём их в следующих занятиях: переменные, условия, циклы, функции. Сегодня важно увидеть, что настоящая программа — это просто последовательность понятных команд.
