4. Live Server

4. Live Server

Live Server — расширение VS Code, которое поднимает локальный HTTP-сервер (адрес http://127.0.0.1:5500) и автоматически обновляет страницу при сохранении файла.

Live Server is a VS Code extension that starts a local HTTP server (address http://127.0.0.1:5500) and auto-reloads the page when you save a file.

Запустить: правый клик по index.html → Open with Live Server. Или кнопка Go Live в правом нижнем углу.

Launch: right-click index.html → Open with Live Server. Or the Go Live button at the bottom right.

5. Node.js и npm

5. Node.js and npm

Node.js — среда исполнения JavaScript вне браузера (использует тот же движок V8). Позволяет запускать JS в терминале: node file.js.

Node.js is a JavaScript runtime outside the browser (uses the same V8 engine). Lets you run JS in the terminal: node file.js.

npm (Node Package Manager) — менеджер пакетов, устанавливается вместе с Node.js. Через него качают библиотеки (React, Express, Lodash и др.).

npm (Node Package Manager) — package manager, installs with Node.js. Used to download libraries (React, Express, Lodash, etc.).

Установка: nodejs.org → LTS → установить → в терминале проверить: node --version, npm --version.

Install: nodejs.org → LTS → install → verify in terminal: node --version, npm --version.

8. Игра «Угадай число»

8. "Guess the number" game

const secret = Math.floor(Math.random() * 100) + 1;
let attempts = 0;
let guess = null;

while (guess !== secret) {
    const input = prompt("Твоё число (1-100):");
    if (input === null) { console.log("Отмена."); break; }
    guess = Number(input);
    attempts++;
    if (guess < secret) console.log(guess + " — мало!");
    else if (guess > secret) console.log(guess + " — много!");
    else console.log("🎉 Угадал! Попыток: " + attempts);
}

Ключевые функции

Key functions

  • Math.random() — случайное число от 0 до 1
  • Math.floor(x) — округление вниз
  • prompt("...") — окно ввода в браузере
  • Number(str) — строка → число
  • while (условие) { ... } — цикл, пока условие истинно
