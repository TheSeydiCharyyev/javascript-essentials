1. Инструкции и выражения

1. Statements and expressions

Выражение (expression) — производит значение: 2 + 2, "hello", Math.random().

Expression — produces a value: 2 + 2, "hello", Math.random().

Инструкция (statement) — действие, обычно заканчивается ;: let x = 5;, console.log("hi");.

Statement — action, usually ends with ;: let x = 5;, console.log("hi");.

ASI — Automatic Semicolon Insertion. JS сам ставит ;, если забыли, но не всегда корректно. Всегда ставьте сами (или через Prettier).

ASI — Automatic Semicolon Insertion. JS inserts ; if you forgot, but not always correctly. Always add them (or rely on Prettier).

3. Правила синтаксиса

3. Syntax rules

  • Регистр важен: name ≠ Name ≠ NAME
  • Пробелы и отступы — для людей, движку всё равно. Стандарт: 2 пробела
  • Строки: "двойные", 'одинарные', `шаблонные`
  • Prettier сам унифицирует стиль при сохранении
  • Case matters: name ≠ Name ≠ NAME
  • Whitespace — for humans, engine doesn't care. Standard: 2 spaces
  • Strings: "double", 'single', `template`
  • Prettier unifies style on save

8. Приветствующий (мини-проект)

8. Greeter (mini-project)

alert("Привет! Познакомимся 👋");
const name = prompt("Как тебя зовут?");

if (name === null || name.trim() === "") {
    alert("Без имени никак. Пока!");
} else {
    const age = Number(prompt("Сколько тебе лет?"));

    console.group("👤 Профиль");
    console.log("Имя:", name);
    console.log("Возраст:", age);
    console.log("Лет до 100:", 100 - age);
    console.groupEnd();

    const likesJS = confirm("Тебе нравится JS?");
    if (likesJS) alert("Отлично, " + name + "! 🎉");
    else alert("Ничего, полюбишь 😉");
}
  • JS чувствителен к регистру: age ≠ Age.
  • Всегда ставьте ; в конце инструкции (Prettier сделает сам).
  • Комментарии — «зачем», не «что».
  • Переменные — camelCase, классы — PascalCase.
  • Три типа ошибок: Syntax, Reference, Type.
  • prompt возвращает строку — для числа используйте Number(...).
  • Диалоги работают только в браузере, в Node их нет.
  • JS is case-sensitive: age ≠ Age.
  • Always end statements with ; (Prettier helps).
  • Comments explain "why", not "what".
  • Variables — camelCase, classes — PascalCase.
  • Three error types: Syntax, Reference, Type.
  • prompt returns a string — use Number(...) for numbers.
  • Dialogs work only in the browser, not Node.
