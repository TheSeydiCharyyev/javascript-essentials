Задание 4. Комментируй разумно
Task 4. Comment wisely
Средне Medium 15 мин
Понять разницу между «комментарий-мусор» и «комментарий-польза». Understand the difference between "noise comments" and "useful comments".

Перепишите код ниже так, чтобы:

Rewrite the code below so that:

  • Плохие комментарии («что») — убраны, а имена переменных сделаны осмысленными.
  • Где действительно нужно — оставлен или добавлен полезный комментарий («зачем», бизнес-правило, неочевидное решение).
