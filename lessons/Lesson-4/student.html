1. Что такое переменная

1. What is a variable

Переменная — это именованное хранилище данных. Аналогия: подписанная коробка в памяти. У неё есть имя и содержимое.

A variable is a named storage for data. Analogy: a labeled box in memory. It has a name and contents.

let age = 20;     // объявили + положили значение
age = 21;         // заменили значение

Знак = — это не «равно», а «присвоить». Для сравнения используют == и ===.

The = sign is not "equals", it's "assign". For comparison use == and ===.

Правило: начинай с const. Переключайся на let только если действительно нужно переприсвоить.

Rule: start with const. Switch to let only when you actually need to reassign.

const PI = 3.14;          // не изменится
let score = 0;            // будет меняться
score = 10;               // OK
PI = 3.15;                // ❌ TypeError

3. Правила именования

3. Naming rules

Обязательные

Required

  • Буквы, цифры, _, $ — можно
  • С цифры начинать нельзя: 2name ❌
  • Регистр важен: age ≠ Age
  • Зарезервированные слова нельзя: let, if, function...
  • Letters, digits, _, $ — allowed
  • Can't start with a digit: 2name ❌
  • Case matters: age ≠ Age
  • No reserved words: let, if, function...

Стили

Styles

  • camelCase — переменные и функции: userName, maxScore
  • PascalCase — классы: User, HttpClient
  • UPPER_SNAKE_CASE — константы: MAX_USERS
  • camelCase — variables and functions: userName, maxScore
  • PascalCase — classes: User, HttpClient
  • UPPER_SNAKE_CASE — constants: MAX_USERS

4. 8 типов данных

4. 8 data types

Типы данных ┌────────────────────┴────────────────────┐ │ │ ПРИМИТИВЫ (7) ССЫЛОЧНЫЙ (1) ├── number └── object ├── string ├── { } объекты ├── boolean ├── [ ] массивы ├── null └── функции ├── undefined ├── symbol └── bigint

Примитив = копия значения. Объект = ссылка на память.

Primitive = value is copied. Object = a reference is shared.

let a = 5; let b = a; b = 10;
console.log(a);    // 5 — независимы

let u1 = { name: "Анна" };
let u2 = u1; u2.name = "Боб";
console.log(u1.name);  // "Боб" — один объект на двоих!

5. Number, String, Boolean

// boolean — true / false

Falsy-значения (6 штук)

Falsy values (6 of them)

false, 0, "", null, undefined, NaN — всё остальное truthy.

false, 0, "", null, undefined, NaN — everything else is truthy.

Внимание: "0", "false", [], {} — truthy! Любая непустая строка — true.

Watch out: "0", "false", [], {} are truthy! Any non-empty string is true.

7. typeof

7. typeof

typeof 42;             // "number"
typeof "hi";           // "string"
typeof true;           // "boolean"
typeof undefined;      // "undefined"
typeof null;           // "object" ← баг 1995, не исправляют
typeof { };            // "object"
typeof [ ];            // "object" ← массив тоже object
typeof function(){};   // "function"

Запомни: typeof null === "object" — историческая «причуда». Все остальные типы работают предсказуемо.

Remember: typeof null === "object" is a historical quirk. All other types behave predictably.

8. Преобразование типов

8. Type conversion

Явное (мы просим)

Explicit (we ask)

String(123);         // "123"
Number("42");        // 42
Number("abc");       // NaN
Boolean(0);          // false
Boolean("text");     // true
parseInt("42px");    // 42
parseFloat("3.14");  // 3.14

Неявное (JS делает сам)

Implicit (JS does it)

"5" + 3      // "53"  ← + со строкой = склейка
"5" - 3      // 2     ← - всегда число
"5" * "2"    // 10
true + 1     // 2     ← true → 1
null + 1     // 1     ← null → 0
undefined+1  // NaN

Главное правило: + со строкой = конкатенация. Все остальные (-, *, /, %) — приводят к числу.

Key rule: + with a string = concatenation. All others (-, *, /, %) force a number.
