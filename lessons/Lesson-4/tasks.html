Задание 1. Карточка о себе
Task 1. Card about yourself
Легко Easy 15 мин
Объявить 5 переменных разных типов и вывести красивую карточку через шаблонный литерал. Declare 5 variables of different types and print a neat card with a template literal.

Шаги:

Steps:

  1. Создайте папку task-1/ с файлами index.html и app.js.
  2. В app.js объявите 5 переменных:
    • firstName — ваше имя (string)
    • age — возраст (number)
    • isStudent — учитесь ли вы (boolean)
    • city — город (string)
    • hobbies — массив из 3 любимых занятий (array)
  3. Выведите в консоль одну многострочную карточку через шаблонный литерал `...${...}...`.
  4. Используйте const для всех переменных.
  1. Create a folder task-1/ with files index.html and app.js.
  2. In app.js declare 5 variables:
    • firstName — your name (string)
    • age — your age (number)
    • isStudent — whether you study (boolean)
    • city — your city (string)
    • hobbies — an array of 3 favorite hobbies (array)
  3. Print one multiline card in the console using a template literal `...${...}...`.
  4. Use const for all variables.

Ожидаемый вид вывода:

Expected output:

=== Обо мне ===
Имя:     Сейди
Возраст: 24
Студент: да
Город:   Ашхабад
Хобби:   код, чтение, кофе
  • 5 переменных объявлены через const
  • Карточка выведена одним console.log()
  • Использован шаблонный литерал (backticks)
  • Массив выведен через hobbies.join(", ")
  • 5 variables declared with const
  • The card is printed in one console.log()
  • Template literal (backticks) is used
  • The array is printed via hobbies.join(", ")

Для булевого значения красивее использовать тернарный оператор внутри строки: ${isStudent ? "да" : "нет"}.

For the boolean, a ternary operator inside the string reads nicer: ${isStudent ? "yes" : "no"}.

Task 2. Guess the result
Легко Easy 15 мин
Закрепить правила преобразования типов: сначала угадать ответ, потом проверить в консоли. Reinforce type-conversion rules: first guess the answer, then check in the console.

Главное правило: + со строкой склеивает, остальные операторы (-, *, /) приводят к числу. true → 1, false → 0, null → 0, undefined → NaN.

Main rule: + with a string concatenates; other operators (-, *, /) coerce to number. true → 1, false → 0, null → 0, undefined → NaN.

If you skip conversion, "10" * "5" works (minus/multiply coerce automatically), but "10" + "5" gives "105". The habit of writing Number() upfront saves you from bugs.

    a = a + b;
b = a - b;
a = a - b;
  3. Через деструктуризацию массива (современный способ, ES6+): 
    [a, b] = [b, a];
  1. With a temporary variable (classic):
